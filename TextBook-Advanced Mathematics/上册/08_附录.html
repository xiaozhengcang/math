附录

附录包含初等数学关键公式速查、基本初等函数图形、几种工科与物理学中常用的经典曲线（如摆线、星形线、心形线、双纽线、阿基米德螺线）以及常用积分表.

附录Ⅰ 初等数学几个内容简介

常用乘法公式：$(a \pm b)^3 = a^3 \pm 3a^2 b + 3ab^2 \pm b^3, \quad a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$.

三角函数积化和差与和差化积公式：

$\sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha + \beta) + \sin(\alpha - \beta)], \quad \cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha + \beta) + \cos(\alpha - \beta)]$

附录Ⅱ与Ⅲ 常用曲线

(1) 摆线（旋轮线）：$\begin{cases} x = a(t - \sin t) \\ y = a(1 - \cos t) \end{cases}$

(2) 星形线：$x^{2/3} + y^{2/3} = a^{2/3}$ 或 $\begin{cases} x = a \cos^3 t \\ y = a \sin^3 t \end{cases}$

(3) 心形线：极坐标方程 $r = a(1 + \cos\theta)$ 或 $r = a(1 - \cos\theta)$

(4) 伯努利双纽线：$r^2 = a^2 \cos 2\theta$

附录Ⅳ 常用微积分积分表

$\int \frac{dx}{a^2 + x^2} = \frac{1}{a}\arctan\frac{x}{a} + C$

$\int \frac{dx}{\sqrt{a^2 - x^2}} = \arcsin\frac{x}{a} + C$

$\int \frac{dx}{\sqrt{x^2 \pm a^2}} = \ln\left|x + \sqrt{x^2 \pm a^2}\right| + C$

$\int \sqrt{a^2 - x^2} dx = \frac{x}{2}\sqrt{a^2 - x^2} + \frac{a^2}{2}\arcsin\frac{x}{a} + C$
