部分习题参考答案与提示

本章汇集《高等数学》（第八版）上册第一章至第七章各小节习题及各章总习题的详细参考答案、推导解析与解题分析提示。

第一章 函数与极限 参考答案

习题 1-1

1. (1) $(-2, +\infty)$；(2) $[-2, 2]$；(3) $(1, +\infty)$；(4) $[-1, 3]$.

总习题一

1. (1) 原式 $= \lim_{x \to 0} \frac{2x}{x(\sqrt{1+x} + \sqrt{1-x})} = \frac{2}{2} = 1$；(2) 原式 $= \lim_{x \to 0} \frac{\frac{1}{2}x^2}{x^2} = \frac{1}{2}$；(3) 原式 $= \lim_{x \to \infty}\left[\left(1 + \frac{2}{x-1}\right)^{\frac{x-1}{2}}\right]^{\frac{2x}{x-1}} = e^2$.

2. $\lim_{x \to 0^-} f(x) = 1, \lim_{x \to 0^+} f(x) = 1, f(0) = 1$，故在 $x = 0$ 处连续.

第二章 导数与微分 参考答案

总习题二

1. (1) 对数求导法：$y' = x^{\sin x}\left(\cos x \ln x + \frac{\sin x}{x}\right)$；(2) $y' = \frac{1}{\sqrt{1+x^2}-x}\left(\frac{x}{\sqrt{1+x^2}} - 1\right) = -\frac{1}{\sqrt{1+x^2}}$；(3) 两边求导 $e^y y' + y + x y' = 0 \implies y'|_{x=0} = -\frac{1}{e}$.

2. 切线方程为 $x - y - a\left(\frac{\pi}{2} - 2\right) = 0$；$\frac{d^2y}{dx^2}|_{t=\pi/2} = -\frac{1}{a}$.

第三章 微分中值定理与导数的应用 参考答案

总习题三

1. 洛必达法则：$\lim_{x \to 0} \frac{1 - \cos x}{3x^2} = \lim_{x \to 0} \frac{\frac{1}{2}x^2}{3x^2} = \frac{1}{6}$.

3. 驻点 $x = -1, x = 3$. 比较端点与驻点函数值，最大值为 $f(-1) = 10$，最小值为 $f(3) = -22$.

第四章 不定积分 参考答案

总习题四

1. (1) $x \sin x + \cos x + C$；(2) $-\sqrt{1 - x^2} + C$；(3) $x \ln x - x + C$；(4) $\frac{1}{2}\arctan\frac{x+1}{2} + C$.

2. 分部积分两次得 $\int e^x \sin x dx = \frac{1}{2}e^x (\sin x - \cos x) + C$.

第五章 定积分 参考答案

总习题五

1. (1) $[x e^x - e^x]_0^1 = 1$；(2) $\frac{\pi}{2}$；(3) 几何意义为四分之一圆面积 $\frac{\pi a^2}{4}$.

2. 洛必达法则：$\lim_{x \to 0} \frac{\cos(x^2)}{1} = 1$.

第六章 定积分的应用 参考答案

总习题六

1. 交点 $(0, 0)$ 与 $(2, 2)$，面积 $A = \int_0^2 (\sqrt{2x} - x)dx = \left[\frac{2\sqrt{2}}{3}x^{3/2} - \frac{x^2}{2}\right]_0^2 = \frac{8}{3} - 2 = \frac{2}{3}$.

2. 旋转体体积 $V = \pi \int_{-a}^a b^2\left(1 - \frac{x^2}{a^2}\right)dx = \frac{4}{3}\pi a b^2$.

3. 星形线弧长 $s = 4 \int_0^{\pi/2} 3a \sin t \cos t\, dt = 6a$.

第七章 微分方程 参考答案

总习题七

1. 一阶线性公式解得通解 $y = \frac{x^3}{4} + \frac{C}{x}$，由 $y(1) = 0$ 得 $C = -\frac{1}{4}$，特解为 $y = \frac{x^3}{4} - \frac{1}{4x}$.

2. 特征方程 $(r - 2)^2 = 0$，通解为 $y = (C_1 + C_2 x)e^{2x}$.

3. 特征方程 $r^2 + 9 = 0 \implies r = \pm 3i$，通解 $y = C_1 \cos 3x + C_2 \sin 3x$. 代入初值得特解 $y = \cos 3x + \sin 3x$.
