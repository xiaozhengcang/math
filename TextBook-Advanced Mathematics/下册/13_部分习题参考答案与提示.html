第十三章 部分习题参考答案与提示

本章汇集《高等数学》（第八版）下册第八章至第十二章各小节习题及各章总习题的详细参考答案、关键计算推导与提示。

第八章 向量代数与空间解析几何 参考答案

习题 8-1

1. $2\boldsymbol{a} - 3\boldsymbol{b} = (-4, -7, 9)$，模为 $\sqrt{(-4)^2 + (-7)^2 + 9^2} = \sqrt{146}$，方向余弦为 $\left(-\frac{4}{\sqrt{146}}, -\frac{7}{\sqrt{146}}, \frac{9}{\sqrt{146}}\right)$.

2. 中点坐标为 $\left(\frac{3}{2}, \frac{1}{2}, 4\right)$，两点间距离 $d = \sqrt{(2-1)^2 + (-1-2)^2 + (5-3)^2} = \sqrt{1 + 9 + 4} = \sqrt{14}$.

3. 由 $\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$，$\cos^2 60^\circ + \cos^2 45^\circ + \cos^2\gamma = 1 \implies \frac{1}{4} + \frac{1}{2} + \cos^2\gamma = 1 \implies \cos\gamma = -\frac{1}{2}$（钝角），故夹角为 $120^\circ$.

习题 8-2

1. $\boldsymbol{a} \cdot \boldsymbol{b} = 1\times 3 + 2\times 0 + (-1)\times 2 = 1$；$\boldsymbol{a} \times \boldsymbol{b} = (4, -5, -6)$；$\cos\theta = \frac{1}{\sqrt{6}\sqrt{13}} = \frac{1}{\sqrt{78}}$.

2. 位移 $\vec{AB} = (2, 2, 1)$，做功 $W = \boldsymbol{F} \cdot \vec{AB} = 2\times 2 + 3\times 2 + 4\times 1 = 14$.

习题 8-3

1. $3(x - 2) + 2(y + 1) - 4(z - 3) = 0 \implies 3x + 2y - 4z + 8 = 0$.

3. 距离 $d = \frac{|2(1) - 2(2) + (-1) + 5|}{\sqrt{2^2 + (-2)^2 + 1^2}} = \frac{2}{3}$.

习题 8-4

1. 对称式：$\frac{x - 1}{2} = \frac{y + 2}{-1} = \frac{z - 4}{3}$；参数方程：$x = 1 + 2t, y = -2 - t, z = 4 + 3t$.

3. 将参数方程代入平面方程解得交点为 $(3, 2, 3)$.

第九章 多元函数微分法及其应用 参考答案

习题 9-2

1. (1) $\frac{\partial z}{\partial x} = 3x^2 y - y^3, \frac{\partial z}{\partial y} = x^3 - 3y^2 x$；(2) $\frac{\partial z}{\partial x} = \frac{1}{y}e^{x/y}, \frac{\partial z}{\partial y} = -\frac{x}{y^2}e^{x/y}$；(3) $\frac{\partial u}{\partial x} = y x^{y-1}, \frac{\partial u}{\partial y} = x^y \ln x$.

习题 9-3

1. (1) $dz = 2x y^3 dx + 3x^2 y^2 dy$；(3) $du = e^{xyz}(yz dx + xz dy + xy dz)$.

总习题九

2. 切平面方程为 $x - 4y + 6z - 21 = 0$，法线方程为 $\frac{x - 1}{1} = \frac{y + 2}{-4} = \frac{z - 2}{6}$.

3. 方向导数为 $\frac{18}{3} = 6$，最大变化率为 $|\nabla u| = \sqrt{2^2 + 4^2 + 6^2} = 2\sqrt{14}$.

4. 设长宽高为 $x, y, z$，表面积 $2(xy + yz + zx) = S$，由对称性或拉格朗日乘数法当 $x = y = z = \sqrt{\frac{S}{6}}$ 为正方体时体积最大，最大体积为 $V = \left(\frac{S}{6}\right)^{3/2}$.

第十章 重积分 参考答案

总习题十

1. 交换积分次序：$\int_0^1 dx \int_0^x e^{x^2} dy = \int_0^1 x e^{x^2} dx = \left.\frac{1}{2}e^{x^2}\right|_0^1 = \frac{e - 1}{2}$.

2. 极坐标计算：$\int_0^{2\pi} d\theta \int_0^R \sqrt{R^2 - r^2} r\, dr = 2\pi \cdot \left[-\frac{1}{3}(R^2 - r^2)^{3/2}\right]_0^R = \frac{2}{3}\pi R^3$.

3. 公共体积为 $V = \frac{16}{3}\pi a^3 \left(1 - \frac{\sqrt{3}}{8}\right)$.

第十一章 曲线积分与曲面积分 参考答案

总习题十一

1. 格林公式：$\iint_D [1 - (-1)] dx dy = 2 \iint_D dx dy = 2\pi a^2$.

2. 原函数为 $u(x, y, z) = x^2 y + xz + y^2 z + C$.

3. 高斯公式：$\iiint_\Omega (1 + 1 + 1) dv = 3 V_\Omega = 3 \cdot \frac{4}{3}\pi abc = 4\pi abc$.

第十二章 无穷级数 参考答案

总习题十二

1. (1) 比值法：$\lim \frac{u_{n+1}}{u_n} = \lim \frac{1}{(1 + 1/n)^n} = \frac{1}{e} < 1$，故收敛；(2) 由莱布尼茨定理交错级数收敛；(3) 根值法 $\lim \sqrt[n]{u_n} = \frac{1}{2} < 1$，故收敛.

2. 收敛区间为 $[-2, 2)$，和函数为 $s(x) = -\ln\left(1 - \frac{x}{2}\right)$.

4. 傅里叶级数展开为 $x = 2 \sum_{n=1}^\infty \frac{(-1)^{n-1}}{n}\sin nx$，令 $x = \frac{\pi}{2}$ 代入即得 $\frac{\pi}{4} = 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \dots$.
