第一章 集合与映射

P.1 ~ P.20 · 可数性基石与代数不等式
定理 1.1.1

可列个可列集的并集仍为可列集

🏷️ 套路 20：Cantor 对角线抽取法
设 $A_1, A_2, \dots, A_n, \dots$ 是可数个可列集，则其可列并集 $\bigcup_{n=1}^\infty A_n$ 仍然是一个可列集。
⚡ 证明精粹与关键步骤
  • 网格排布：将每个可列集 $A_n$ 的元素排成无穷二维矩阵：第 $n$ 行为 $a_{n1}, a_{n2}, a_{n3}, \dots$。
  • 蛇形遍历：按照对角线指标和 $n + k = 2, 3, 4, \dots$ 的顺序依次走蛇形路线编排序号（遇重复元素则跳过）。
  • 建立双射：该遍历法则建立起二维矩阵元素与自然数集 $\mathbb{N}^*$ 之间的一一对应，从而证得其为可列集。
💡 套路点评：典型的“二维网格转一维对角线折叠法”。将无限维度的并集通过斜向对角线计数，化无序为有序。
定理 1.1.2

实数区间 $(-\infty, +\infty)$ 是不可列集

🏷️ 套路 20：Cantor 对角线抽取法 🏷️ 反证法
任何非空开区间 $(a, b)$ 以及全实数集 $\mathbb{R} = (-\infty, +\infty)$ 均为不可列集（基数为连续统势 $c$）。
⚡ 证明精粹与关键步骤
  • 反证假设：假设 $(0, 1)$ 是可列集，则其所有实数可按序号排成序列：$x_1, x_2, \dots, x_n, \dots$。
  • 无限十进制展开：设第 $n$ 个数为 $x_n = 0.a_{n1}a_{n2}\dots a_{nn}\dots$（规定不采用无限循环 9 的形式）。
  • 对角线构造逃逸数：构造实数 $b = 0.b_1b_2\dots b_n\dots$，规定若对角线第 $n$ 位 $a_{nn} = 1$ 则取 $b_n = 2$；若 $a_{nn} \ne 1$ 则取 $b_n = 1$。
  • 导出矛盾：新数 $b \in (0, 1)$，但由于 $b$ 的第 $n$ 位小数与 $x_n$ 的第 $n$ 位必不相等，故 $b \ne x_n$（对一切 $n \in \mathbb{N}^*$），这与 $x_n$ 包含 $(0, 1)$ 中所有数矛盾！
💡 套路点评：分析学最著名的“Cantor 对角线逐位否定论据”。利用对角线位数的变异，构造出一个永远无法被列举网罗的“逃逸点”。
定理 1.2.1

绝对值三角不等式

🏷️ 套路 01：ε-δ 放缩之母机
对任意实数 $a, b \in \mathbb{R}$，恒有： $$\big| |a| - |b| \big| \le |a \pm b| \le |a| + |b|$$
⚡ 证明精粹与关键步骤
  • 右边放大：由 $-|a| \le a \le |a|$ 与 $-|b| \le b \le |b|$ 两式相加，得 $-(|a| + |b|) \le a + b \le |a| + |b| \implies |a + b| \le |a| + |b|$。
  • 左边缩小：恒等代换 $a = (a - b) + b \implies |a| \le |a - b| + |b| \implies |a| - |b| \le |a - b|$。交换 $a, b$ 位置同理得证反向，综上加绝对值。
💡 套路点评：数学分析一切“作差放缩”、“$\varepsilon/2$ 拆分”的绝对力量源泉，整部分析学的三角不等式母机。
定理 1.2.2

算术-几何平均值不等式（均值不等式）

🏷️ 套路 08：凸性切线放缩法 🏷️ 柯西反向归纳法
对任意正实数 $a_1, a_2, \dots, a_n > 0$，恒有： $$\frac{a_1 + a_2 + \dots + a_n}{n} \ge \sqrt[n]{a_1 a_2 \cdots a_n}$$ 等号当且仅当 $a_1 = a_2 = \dots = a_n$ 时成立。
⚡ 证明精粹与关键步骤
  • 现代切线放缩证法：考察严格凹函数 $f(t) = \ln t$ 在 $t=1$ 处的切线不等式 $\ln t \le t - 1$（当且仅当 $t=1$ 取等）。
  • 均值代换：记算术平均 $A = \frac{1}{n}\sum_{i=1}^n a_i$。代入 $t_i = \frac{a_i}{A}$，则 $\ln\frac{a_i}{A} \le \frac{a_i}{A} - 1$。
  • 累加求和：$n$ 个不等式相加：$\sum_{i=1}^n \ln\frac{a_i}{A} \le \sum_{i=1}^n \frac{a_i}{A} - n = \frac{nA}{A} - n = 0$。
  • 指数还原：$\ln\left( \prod_{i=1}^n \frac{a_i}{A} \right) \le 0 \implies \prod_{i=1}^n a_i \le A^n \implies \sqrt[n]{\prod a_i} \le A$。证毕。
💡 套路点评：用套路 08 的切线放缩 $\ln t \le t - 1$（悬空铁锅法则）秒杀初等归纳法长篇累牍的证明，极为干净利落。

第二章 数列极限

P.21 ~ P.59 · 实数完备性六大定理与收敛准则
定理 2.1.1

确界存在定理（实数系连续性公理）

🏷️ 实数系完备性第一基石
非空有上界的数集必有上确界（最小上界）；非空有下界的数集必有下确界（最大下界）。
⚡ 证明精粹与关键步骤
  • 逐位截断构造：设非空集合 $S$ 有上界 $M$。利用无限小数展开法：整数部分取 $S$ 元素的最大可能整数 $a_0$；
  • 逐级细化小数位：十分位取使存在 $S$ 元素不小于该前缀的最大数字 $a_1\dots$，逐位构造实数 $\beta = a_0.a_1a_2\dots$；
  • 验证两项确界性质：(1) 对一切 $x \in S$，恒有 $x \le \beta$（$\beta$ 为上界）；(2) 对任意 $\varepsilon > 0$，取充分大位数位使得 $10^{-k} < \varepsilon$，构造保证存在某 $x \in S$ 满足 $x > \beta - 10^{-k} > \beta - \varepsilon$（$\beta$ 为最小上界）。
💡 套路点评：实数“没有缝隙”的基石陈述。将集合的界通过无限小数的逐位截断逼近固定为一个唯一的实数确界。
定理 2.2.1

极限的唯一性定理

🏷️ 套路 01：ε/2 分拆法 🏷️ 反证法
若数列 $\{x_n\}$ 存在极限，则其极限值必定是唯一的。
⚡ 证明精粹与关键步骤
  • 反设两极限相异：假设 $\lim x_n = a$ 且 $\lim x_n = b$，且 $a \ne b$。
  • 选取对半固定误差：取固定正数 $\varepsilon_0 = \frac{|a - b|}{2} > 0$。
  • 邻域重叠矛盾：由定义存在 $N$，当 $n > N$ 时同时有 $|x_n - a| < \varepsilon_0$ 且 $|x_n - b| < \varepsilon_0$。
  • 三角不等式撞车：$|a - b| \le |a - x_n| + |x_n - b| < \varepsilon_0 + \varepsilon_0 = |a - b|$，导出矛盾 $|a - b| < |a - b|$。
💡 套路点评：标准的“$\varepsilon/2$ 距离隔离法”。取两个假想极限点间距的一半作为标尺，利用三角不等式逼出不可调和的距离矛盾。
定理 2.2.2

收敛数列的有界性定理

🏷️ 套路 01：局部有界（取 max 控制有限项）
任何收敛的数列必定是有界数列。
⚡ 证明精粹与关键步骤
  • 固定粗步长：设 $\lim x_n = a$。在定义中初选 $\varepsilon = 1$。
  • 后段截获局部界：存在 $N$，当 $n > N$ 时，恒有 $|x_n - a| < 1 \implies |x_n| < |a| + 1$。
  • 有限项取最大值：令 $M = \max\{ |x_1|, |x_2|, \dots, |x_N|, |a| + 1 \}$，则对一切自然数 $n$，均有 $|x_n| \le M$。
💡 套路点评：“有限项取 max，无限项借极限邻域有界”。这是分析学控制未知干扰因子的标准化操作。
定理 2.2.3

极限的保号性与保序性定理

🏷️ 套路 01：ε 分半中介阻隔法
若 $\lim x_n = a, \lim y_n = b$ 且 $a > b$，则必存在正整数 $N$，当 $n > N$ 时恒有 $x_n > y_n$。
⚡ 证明精粹与关键步骤
  • 构造缓冲间隙：令 $\varepsilon = \frac{a - b}{2} > 0$。
  • 邻域分离：当 $n > N$ 时，$x_n > a - \varepsilon = \frac{a + b}{2}$；同时 $y_n < b + \varepsilon = \frac{a + b}{2}$。
  • 传递得证：$x_n > \frac{a + b}{2} > y_n \implies x_n > y_n$。
💡 套路点评：在两个极限点中间强行插进一条中介隔离带 $\frac{a+b}{2}$，让两个数列分别在隔离带两侧活动。
定理 2.2.5

数列极限的四则运算法则

🏷️ 套路 01：ε/2 分拆与局部有界放缩
若 $\lim x_n = a, \lim y_n = b$，则 $\lim(x_n \pm y_n) = a \pm b$，$\lim(x_n y_n) = ab$，且当 $b \ne 0$ 时 $\lim \frac{x_n}{y_n} = \frac{a}{b}$。
⚡ 证明精粹与关键步骤
  • 乘法拆分：$|x_n y_n - ab| = |x_n(y_n - b) + b(x_n - a)| \le |x_n||y_n - b| + |b||x_n - a|$。
  • 局部有界锁定系数：由收敛有界性知 $|x_n| \le M$。将总误差分配给两项：$M \cdot \frac{\varepsilon}{2M} + |b| \cdot \frac{\varepsilon}{2(|b|+1)} < \varepsilon$。
  • 除法保护分母：先取 $\varepsilon_0 = \frac{|b|}{2}$，使当 $n$ 充分大时分母满足 $|y_n| > \frac{|b|}{2}$，避免除以零且放缩倒数。
💡 套路点评：乘积拆分与分母下界保护是数析最经典的“预处理两阶段放缩”。
定理 2.3.3

Stolz-Cesàro 定理（离散版洛必达法则）

🏷️ 套路 07：Stolz-Cesàro 定理 🏷️ 套路 01：分段放缩法
设数列 $\{y_n\}$ 严格单调增加且 $\lim_{n \to \infty} y_n = +\infty$。若 $\lim_{n \to \infty} \frac{x_n - x_{n-1}}{y_n - y_{n-1}} = a$，则成立： $$\lim_{n \to \infty} \frac{x_n}{y_n} = a$$
⚡ 证明精粹与关键步骤
  • 化归差分：不妨设 $a = 0$。对任意 $\varepsilon > 0$，存在 $N$，当 $k > N$ 时 $|x_k - x_{k-1}| < \frac{\varepsilon}{2}(y_k - y_{k-1})$。
  • 裂项求和与分段拆开：将分子写为 $x_n = x_N + \sum_{k=N+1}^n (x_k - x_{k-1})$。两端同除以 $y_n$： $$\left| \frac{x_n}{y_n} \right| \le \frac{|x_N|}{y_n} + \frac{\varepsilon}{2}\frac{y_n - y_N}{y_n} \le \frac{|x_N|}{y_n} + \frac{\varepsilon}{2}$$
  • 大头稀释：因为 $y_n \to +\infty$，固定分子 $x_N$ 在 $n$ 充分大时 $\frac{|x_N|}{y_n} < \frac{\varepsilon}{2}$。两段相加小于 $\varepsilon$。
💡 套路点评：“前段固定项被分母稀释为零，后段无穷项受 $\varepsilon$ 均匀控制”，分段放缩法的传世经典。
定理 2.4.1

单调有界数列收敛定理

🏷️ 套路 03：单调有界收敛定理
任何单调有界的实数列必有有限极限（递增有上界必收敛于上确界，递减有下界必收敛于下确界）。
⚡ 证明精粹与关键步骤
  • 确界定候选值：设 $x_n$ 单调增且有上界。由确界存在定理，设 $a = \sup\{x_n\}$。
  • 利用确界逼近性：对任意 $\varepsilon > 0$，$a - \varepsilon$ 不是上界，故必存在某一项 $x_N$ 满足 $x_N > a - \varepsilon$。
  • 单调性锁定全尾部：由单调增加性，当 $n > N$ 时，$a - \varepsilon < x_N \le x_n \le a < a + \varepsilon \implies |x_n - a| < \varepsilon$。
💡 套路点评：利用单调性消灭一切可能的振荡，利用确界保证不会越界，实数完备性最实用的一张王牌。
定理 2.4.2

闭区间套定理

🏷️ 套路 03：单调有界收敛 🏷️ 套路 09：区间套锁定单一实数
设闭区间列 $\{[a_n, b_n]\}$ 满足 $[a_1, b_1] \supseteq [a_2, b_2] \supseteq \dots$ 且 $\lim_{n \to \infty}(b_n - a_n) = 0$，则所有闭区间的交集恰好包含唯一实数 $\xi$。
⚡ 证明精粹与关键步骤
  • 端点单调有界：左端点 $a_n$ 递增有上界 $b_1 \implies \lim a_n = \xi$；右端点 $b_n$ 递减有下界 $a_1 \implies \lim b_n = \eta$。
  • 长度趋零合二为一：$\eta - \xi = \lim (b_n - a_n) = 0 \implies \xi = \eta$。
  • 唯一性保证：显然 $a_n \le \xi \le b_n$ 对一切 $n$ 成立。若有两个点，两点间距将小于任意区间长度，产生矛盾。
💡 套路点评：“俄罗斯套娃无穷缩限”。在二分搜索、零点定理和致密性证明中作为最底层的定点工具。
定理 2.4.5

Bolzano-Weierstrass 致密性定理

🏷️ 套路 12：Bolzano-Weierstrass 致密性定理
任何有界实数列必定包含至少一个收敛的子序列。
⚡ 证明精粹与关键步骤
  • 初选有界大区间：设 $\{x_n\} \subset [a_1, b_1]$。
  • 无限次二分折半：取中点将区间对半平分。由抽屉原理，左右两半中至少有一半包含数列的无穷多项，记为 $[a_2, b_2]$；
  • 构筑区间套定极限：无限迭代得到闭区间套 $[a_k, b_k]$，由区间套定理交出唯一实数 $\xi$；
  • 抽取子序列：在每个小区间按自然下标递增依次抽取元素 $x_{n_k} \in [a_k, b_k]$，由夹逼准则必有 $x_{n_k} \to \xi$。
💡 套路点评：通过“抽屉原理 + 闭区间套”在杂乱无章的有界序列中强行抽取出整齐收敛的子列队伍，现代拓扑紧性的源头。
定理 2.4.7

Cauchy 收敛原理

🏷️ 套路 01：ε/2 分拆传递 🏷️ 套路 12：致密性提取子列
数列 $\{x_n\}$ 收敛的充分必要条件是：对任意给定的 $\varepsilon > 0$，存在正整数 $N$，当 $n, m > N$ 时恒有 $|x_n - x_m| < \varepsilon$（即 $\{x_n\}$ 为柯西列）。
⚡ 证明精粹与关键步骤
  • 必要性：若 $x_n \to a$，由三角不等式 $|x_n - x_m| \le |x_n - a| + |x_m - a| < \varepsilon/2 + \varepsilon/2 = \varepsilon$。
  • 充分性第一步（有界）：取 $\varepsilon = 1$ 可推得柯西列必有界。
  • 充分性第二步（提取子列）：由 Bolzano-Weierstrass 定理，必有收敛子序列 $x_{n_k} \to a$。
  • 充分性第三步（子列拉动全列）：对柯西准则令 $m = n_k$ 充分大，利用三角不等式 $|x_n - a| \le |x_n - x_{n_k}| + |x_{n_k} - a| < \varepsilon/2 + \varepsilon/2 = \varepsilon$，推导全列 $x_n \to a$。
💡 套路点评：无需预先知道极限值 $a$ 是多少即可判定收敛的终极准则。用子序列收敛结合柯西内聚性“以点带面”拉动整体收敛。

第三章 函数极限与连续函数

P.60 ~ P.102 · 归结原则、闭区间四大定理与一致连续
定理 3.1.5

Heine 定理（归结原则）

🏷️ 套路 11：Heine 归结原则 🏷️ 套路 04：反设 ∃ ε₀ 令 δ=1/n 提取子列
$\lim_{x \to x_0} f(x) = A$ 的充分必要条件是：对于任何满足 $x_n \ne x_0$ 且 $\lim_{n \to \infty} x_n = x_0$ 的数列 $\{x_n\}$，相应的函数值数列均有 $\lim_{n \to \infty} f(x_n) = A$。
⚡ 证明精粹与关键步骤
  • 必要性：直接将函数极限定义中的 $\delta$ 作为数列的收敛指标即可。
  • 充分性（经典反证法）：假设结论不成立，即 $f(x) \not\to A$。
  • 反设 1/n 取点列：存在 $\varepsilon_0 > 0$，对每个 $\delta_n = 1/n$，必存在点 $x_n$ 满足 $0 < |x_n - x_0| < 1/n$，但是 $|f(x_n) - A| \ge \varepsilon_0$。
  • 逻辑崩溃：构造出的点列 $x_n \to x_0$，但其函数值数列永远与 $A$ 保持 $\varepsilon_0$ 以上的距离，与充分性假设矛盾！
💡 套路点评：连接连续函数与离散数列的巍峨立交桥。充分性的证明把套路 04（令 $\delta = 1/n$ 抓现行）发挥得淋漓尽致。
定理 3.4.1

闭区间连续函数之有界性定理

🏷️ 套路 12：Bolzano-Weierstrass 致密性 🏷️ 套路 04：无界发散子列反证法
在闭区间 $[a, b]$ 上的连续函数 $f(x)$ 必在该区间上有界。
⚡ 证明精粹与关键步骤
  • 反设函数无界：对每个正整数 $n$，均存在 $x_n \in [a, b]$ 满足 $|f(x_n)| > n$。
  • 致密性提取子列：点列 $\{x_n\}$ 落在紧集 $[a, b]$ 内，由 Bolzano-Weierstrass 定理必有收敛子列 $x_{n_k} \to x_0 \in [a, b]$。
  • 连续性撞车：由连续性 $\lim f(x_{n_k}) = f(x_0)$（有限固定实数）；然而根据假设 $|f(x_{n_k})| > n_k \to +\infty$，有限值与无穷大产生不可调和的矛盾！
💡 套路点评：“无界就找点列趋向无穷，紧集就抽子列收敛定点”，两路夹攻引爆有限与无限的悖论。
定理 3.4.2

最大值与最小值定理（Weierstrass 最值定理）

🏷️ 确界存在定理 🏷️ 套路 02：辅助函数倒数反证法
在闭区间 $[a, b]$ 上的连续函数 $f(x)$ 必在该区间上达到其最大值与最小值。
⚡ 证明精粹与关键步骤
  • 锁定上确界：由定理 3.4.1，$f$ 有界，故值域集存在上确界 $M = \sup_{x \in [a, b]} f(x)$。
  • 反设永远达不到最大值：假设对所有 $x \in [a, b]$ 均有 $f(x) < M$。
  • 构造倒数辅助函数：令 $g(x) = \frac{1}{M - f(x)}$。因为分母非零且连续，故 $g(x)$ 在 $[a, b]$ 上连续，必有界：$g(x) \le K$。
  • 逼退上确界矛盾：$M - f(x) \ge 1/K \implies f(x) \le M - 1/K$，这与 $M$ 是最小上界绝对矛盾！故必存在 $\xi$ 使 $f(\xi) = M$。
💡 套路点评：构造倒数函数 $g(x) = \frac{1}{M - f(x)}$ 是分析学证明“确界可达”的绝妙巧思。
定理 3.4.3

零点存在定理（Bolzano 零点定理）

🏷️ 套路 09：零点存在定理与区间二分法
设 $f(x)$ 在闭区间 $[a, b]$ 上连续，且两端点函数值异号（即 $f(a)f(b) < 0$），则开区间 $(a, b)$ 内必存在至少一点 $\xi$ 使得 $f(\xi) = 0$。
⚡ 证明精粹与关键步骤
  • 二分排查法：设 $f(a) < 0, f(b) > 0$。取中点 $c_1 = \frac{a+b}{2}$。若 $f(c_1) = 0$ 证毕；若非零，取端点异号的半边作为 $[a_1, b_1]$；
  • 无限套娃：重复折半构造出闭区间套 $[a_n, b_n]$，满足 $f(a_n) < 0, f(b_n) > 0$ 且长度趋于 0；
  • 区间套定零点：区间套交出唯一公共点 $\xi$。由保序性 $f(\xi) = \lim f(a_n) \le 0$，且 $f(\xi) = \lim f(b_n) \ge 0$，唯一可能只有 $f(\xi) = 0$。
💡 套路点评：现代数值计算中“二分搜索算法”的数学原点。
定理 3.4.6

Cantor 一致连续性定理

🏷️ 套路 15：Heine-Borel 有限覆盖法 🏷️ 套路 04：反设 δ=1/n 提取子列反证法
若函数 $f(x)$ 在闭区间 $[a, b]$ 上连续，则 $f(x)$ 在 $[a, b]$ 上必定是一致连续的。
⚡ 证明精粹与关键步骤
  • 反证法套用套路 04：若非一致连续，存在 $\varepsilon_0 > 0$，对每个 $\delta_n = 1/n$，存在点对 $x_n, y_n \in [a, b]$ 满足 $|x_n - y_n| < 1/n$ 但 $|f(x_n) - f(y_n)| \ge \varepsilon_0$。
  • 致密性提取公共极限：由 Bolzano-Weierstrass 定理，存在收敛子列 $x_{n_k} \to x_0 \in [a, b]$。因 $|y_{n_k} - x_{n_k}| < 1/n_k \to 0$，亦有 $y_{n_k} \to x_0$。
  • 连续性击溃误差下界：由函数连续性，$\lim [f(x_{n_k}) - f(y_{n_k})] = f(x_0) - f(x_0) = 0$，与恒有差值 $\ge \varepsilon_0$ 发生剧烈矛盾！
💡 套路点评：闭区间紧致性赋予连续函数的最高特权。此定理直接保证了后续第七章“闭区间连续函数必定黎曼可积”的宏伟结论。

第四章 微分

P.103 ~ P.146 · 微分可导等价、链式法则与 Leibniz 乘积求导
定理 4.1.1

一元函数可微与可导等价定理

🏷️ 阶数局部展开与等价转化
函数 $y = f(x)$ 在点 $x$ 处可微的充分必要条件是它在点 $x$ 处可导，且微分即为 $\mathrm{d}y = f'(x)\Delta x$。
⚡ 证明精粹与关键步骤
  • 必要性：由可微定义 $\Delta y = A\Delta x + o(\Delta x)$，两边同除以 $\Delta x$ 取极限：$\lim \frac{\Delta y}{\Delta x} = A + \lim \frac{o(\Delta x)}{\Delta x} = A$，故导数存在且 $f'(x) = A$。
  • 充分性：若 $\lim \frac{\Delta y}{\Delta x} = f'(x)$，记误差无穷小 $\alpha = \frac{\Delta y}{\Delta x} - f'(x) \to 0$。去分母整理得 $\Delta y = f'(x)\Delta x + \alpha\Delta x = f'(x)\Delta x + o(\Delta x)$，满足可微定义。
💡 套路点评：微分学最基本的定义化归。一元微积分中“可导”与“可微”是一体两面。
定理 4.3.2

乘积求导法则（Leibniz 乘积律）

🏷️ 套路 01：作差添项拆分法
若 $f(x)$ 与 $g(x)$ 均可导，则积函数 $f(x)g(x)$ 亦可导，且 $[f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)$。
⚡ 证明精粹与关键步骤
  • 插入交叉过渡项：$\Delta(fg) = f(x+\Delta x)g(x+\Delta x) - f(x)g(x) = [f(x+\Delta x) - f(x)]g(x+\Delta x) + f(x)[g(x+\Delta x) - g(x)]$。
  • 可导保证连续：因 $g$ 可导，故 $g$ 必连续，有 $\lim_{\Delta x \to 0} g(x+\Delta x) = g(x)$。
  • 除以步长取极限：除以 $\Delta x$ 逐项取极限直接得出 $f'(x)g(x) + f(x)g'(x)$。
💡 套路点评：添加中介项 $f(x+\Delta x)g(x)$ 作差，是代数与分析中解构乘积变化率的标配手法。
定理 4.4.1

复合函数求导法则（链式法则 Chain Rule）

🏷️ 局部线性微分展开（避零处理法）
设 $u = g(x)$ 在 $x_0$ 可导，而 $y = f(u)$ 在 $u_0 = g(x_0)$ 可导，则复合函数 $y = f(g(x))$ 在 $x_0$ 可导且 $(f \circ g)'(x_0) = f'(u_0)g'(x_0)$。
⚡ 证明精粹与关键步骤
  • 微分展开规避分母为零：直接写 $\frac{\Delta y}{\Delta x} = \frac{\Delta y}{\Delta u} \frac{\Delta u}{\Delta x}$ 当 $\Delta u = 0$ 时会除以零失效。
  • 构造连续辅助项：改用 $f$ 在 $u_0$ 的可微式：$\Delta y = [f'(u_0) + \alpha(\Delta u)]\Delta u$，其中规定当 $\Delta u = 0$ 时 $\alpha(0) = 0$。
  • 两边同除取极限：$\frac{\Delta y}{\Delta x} = [f'(u_0) + \alpha(\Delta u)]\frac{\Delta u}{\Delta x} \to f'(u_0) g'(x_0)$。
💡 套路点评：现代微分算子、神经网络反向传播（Backprop / Autodiff）的理论心脏。构造连续误差项 $\alpha$ 规避了除以零的严密性漏洞。
定理 4.5.2

Leibniz 高阶乘积求导公式

🏷️ 数学归纳法 + 组合系数恒等式
若 $f(x)$ 与 $g(x)$ 均 $n$ 阶可导，则积函数亦 $n$ 阶可导，且成立： $$[f(x)g(x)]^{(n)} = \sum_{k=0}^n \binom{n}{k} f^{(k)}(x) g^{(n-k)}(x)$$
⚡ 证明精粹与关键步骤
  • 数学归纳法验证基底：$n=1$ 时即为普通乘积法则，二项式系数 $\binom{1}{0}=\binom{1}{1}=1$ 成立。
  • 归纳假设求导：对 $n$ 阶假设式逐项求导，产生相邻二项式系数求和：$\binom{n}{k-1} + \binom{n}{k} = \binom{n+1}{k}$。
  • 归纳闭环：合并同阶导数项，即得 $n+1$ 阶二项式展开形态。
💡 套路点评：分析学与组合数学二项式定理同构的优美范例。

第五章 微分中值定理及其应用

P.147 ~ P.202 · Fermat、Rolle、Lagrange、Cauchy、Taylor 与凸性
定理 5.1.1

Fermat 引理（极值点处驻点定理）

🏷️ 极限单侧保号性对夹法
设 $f(x)$ 在点 $x_0$ 的某邻域内有定义，在 $x_0$ 处可导，且在 $x_0$ 处取得极值，则必有 $f'(x_0) = 0$。
⚡ 证明精粹与关键步骤
  • 极大值单侧差商分析：设 $x_0$ 为极大值点。当 $\Delta x > 0$ 时，$\frac{f(x_0+\Delta x) - f(x_0)}{\Delta x} \le 0 \implies f'_+(x_0) \le 0$。
  • 左侧差商反向保号：当 $\Delta x < 0$ 时，分子 $\le 0$ 分母 $< 0$，差商 $\ge 0 \implies f'_-(x_0) \ge 0$。
  • 可导迫使两端归零：由于可导保证 $f'(x_0) = f'_+(x_0) = f'_-(x_0)$，夹在 $\le 0$ 与 $\ge 0$ 之间唯一可能就是 $f'(x_0) = 0$。
💡 套路点评：一切微分中值定理和最优化梯度下降算法（必要条件 $\nabla f = 0$）的发祥地。
定理 5.1.2

Rolle 定理（罗尔中值定理）

🏷️ 最值定理 + Fermat 引理
若 $f(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，且端点值相等 $f(a) = f(b)$，则必存在 $\xi \in (a, b)$ 使得 $f'(\xi) = 0$。
⚡ 证明精粹与关键步骤
  • 最值定理定界：由定理 3.4.2，$f$ 在 $[a, b]$ 上必有最大值 $M$ 和最小值 $m$。
  • 常数平凡情形：若 $M = m$，则 $f(x) \equiv C$ 恒为常数，导数处处为 0，任取一点即可。
  • 非平凡内部取值：若 $M > m$，因两端点相等 $f(a) = f(b)$，故最大值或最小值至少有一个在开区间内部某点 $\xi \in (a, b)$ 达到。
  • 引理降维收网：该内部点是极值点且可导，由 Fermat 引理必有 $f'(\xi) = 0$。
💡 套路点评：微分学所有中值定理的母定理。通过端点相等阻断边界最值，迫使极值点掉落开区间内部。
定理 5.1.3

Lagrange 中值定理（有限增量定理）

🏷️ 套路 02：辅助函数构造（旋转倾斜割线法）
若 $f(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，则至少存在一点 $\xi \in (a, b)$ 使得： $$f(b) - f(a) = f'(\xi)(b - a)$$
⚡ 证明精粹与关键步骤
  • 求割线斜率：连接端点 $(a, f(a))$ 与 $(b, f(b))$ 的割线方程为 $y = f(a) + \frac{f(b)-f(a)}{b-a}(x - a)$。
  • 构造垂直偏差函数：构造曲线与割线垂直偏差辅助函数： $$\varphi(x) = f(x) - f(a) - \frac{f(b) - f(a)}{b - a}(x - a)$$
  • 应用 Rolle 定理：显然 $\varphi(a) = \varphi(b) = 0$。由 Rolle 定理必存在 $\xi \in (a, b)$ 使 $\varphi'(\xi) = 0$。
  • 展开得证：$\varphi'(\xi) = f'(\xi) - \frac{f(b)-f(a)}{b-a} = 0 \implies f(b) - f(a) = f'(\xi)(b - a)$。
💡 套路点评：微积分大厦的承重墙。把割线作差平移构造辅助函数，把一般的倾斜运动转化为 Rolle 定理的水平运动。
定理 5.1.8

Jensen 凸函数不等式

🏷️ 套路 08：凸性切线放缩法 🏷️ 数学归纳法
若 $f(x)$ 在区间 $I$ 上为下凸函数，则对任意点 $x_1, \dots, x_n \in I$ 及任意权重 $\lambda_1, \dots, \lambda_n > 0$（满足 $\sum \lambda_i = 1$），恒有： $$f\left( \sum_{i=1}^n \lambda_i x_i \right) \le \sum_{i=1}^n \lambda_i f(x_i)$$
⚡ 证明精粹与关键步骤
  • 定位加权平均中心：设重心 $\bar{x} = \sum_{i=1}^n \lambda_i x_i \in I$。
  • 在重心处作切线（支撑超平面）：由凸函数性质，曲线处处高于重心切线：$f(x_i) \ge f(\bar{x}) + f'(\bar{x})(x_i - \bar{x})$。
  • 乘权重加权求和：两端同乘正权重 $\lambda_i$ 并求和： $$\sum \lambda_i f(x_i) \ge \sum \lambda_i f(\bar{x}) + f'(\bar{x}) \sum \lambda_i (x_i - \bar{x}) = f(\bar{x}) + f'(\bar{x})(\bar{x} - \bar{x}) = f(\bar{x})$$
💡 套路点评：运用套路 08 切线支撑不等式，一次求和直接消去一阶导数干扰项，优美至极。
定理 5.1.9

Cauchy 柯西中值定理

🏷️ 套路 02：行列式自归零辅助函数法
若 $f(x), g(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导且 $g'(x) \ne 0$，则必存在 $\xi \in (a, b)$ 使得： $$\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(\xi)}{g'(\xi)}$$
⚡ 证明精粹与关键步骤
  • 构造对角交叉辅助函数：令 $F(x) = [f(b) - f(a)]g(x) - [g(b) - g(a)]f(x)$。
  • 检验两端点自归零：$F(a) = f(b)g(a) - f(a)g(b)$，且 $F(b) = f(b)g(a) - f(a)g(b)$，端点天然相等！
  • 应用 Rolle 定理：存在 $\xi \in (a, b)$ 使 $F'(\xi) = [f(b) - f(a)]g'(\xi) - [g(b) - g(a)]f'(\xi) = 0$。除以非零项即得。
💡 套路点评：通过二阶行列式交叉构造辅助函数，几何上相当于将参数平面曲线 $(g(t), f(t))$ 的割线转化为切线斜率。
定理 5.4.1

Taylor 定理（带有 Lagrange 余项的泰勒公式）

🏷️ 套路 05：Taylor 展开与局部阶数估计 🏷️ 套路 02：高阶 Rolle 辅助函数构造
若 $f(x)$ 在含 $x_0, x$ 的闭区间上 $n+1$ 阶可导，则存在 $\xi$ 介于 $x_0$ 与 $x$ 之间，成立： $$f(x) = \sum_{k=0}^n \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k + \frac{f^{(n+1)}(\xi)}{(n+1)!}(x - x_0)^{n+1}$$
⚡ 证明精粹与关键步骤
  • 设待定余项常数 $K$：令余项为 $R_n(x) = K(x - x_0)^{n+1}$。
  • 构造关于动点 $t$ 的辅助函数： $$\Phi(t) = f(x) - \sum_{k=0}^n \frac{f^{(k)}(t)}{k!}(x - t)^k - K(x - t)^{n+1}$$
  • 检验两端点：$\Phi(x) = 0$，且按 $K$ 的定义 $\Phi(x_0) = 0$。
  • 神奇求导错位相消：对 $t$ 求导时，前一项导数与后一项展开式导数宛如多米诺骨牌全部抵消，只留下一头一尾： $$\Phi'(t) = -\frac{f^{(n+1)}(t)}{n!}(x - t)^n + (n+1)K(x - t)^n = 0 \implies K = \frac{f^{(n+1)}(\xi)}{(n+1)!}$$
💡 套路点评：把动点 $t$ 移入展开式基准点，利用求导裂项相消的“神之一手”，逼出拉格朗日余项。

第七章 定积分与微积分基本定理

P.234 ~ P.298 · 黎曼积分理论、可积准则与 Newton-Leibniz
定理 7.1.1 / 7.1.2

Darboux 与振幅可积充分必要条件

🏷️ 确界夹逼准则 🏷️ 套路 01：总振幅误差度量
有界函数 $f(x)$ 在 $[a, b]$ 上可积 $\iff \underline{I} = \overline{I}$（上积分等于下积分）$\iff \lim_{\lambda \to 0} \sum_{i=1}^n \omega_i \Delta x_i = 0$（振幅和趋向于零）。
⚡ 证明精粹与关键步骤
  • 公共加细网格：对任意两个划分 $P_1, P_2$，通过公共加细 $P^* = P_1 \cup P_2$ 证明下和恒不超过上和：$\underline{S}(P_1) \le \overline{S}(P_2)$。
  • 上积分与下积分夹逼：从而下积分 $\underline{I} \le \overline{I}$ 上积分恒成立。
  • 振幅转化为上下和差：$\sum \omega_i \Delta x_i = \sum (M_i - m_i)\Delta x_i = \overline{S}(P) - \underline{S}(P)$，两边夹逼趋向于 0 等价于上下积分离合为一。
💡 套路点评：将极其抽象的黎曼和任意介点 $\xi_i$，通过上确界和下确界夹在两道铁轨中间，转化为纯粹的几何总振幅面积控制。
推论 7.1.1

闭区间连续函数必可积定理

🏷️ 套路 15：Cantor 一致连续性定理
定义在闭区间 $[a, b]$ 上的任何连续函数必定是 Riemann 可积的。
⚡ 证明精粹与关键步骤
  • 请出 Cantor 一致连续性：由定理 3.4.6，闭区间连续必一致连续。
  • 均匀控制微小振幅：对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $|x' - x''| < \delta$ 时，恒有 $|f(x') - f(x'')| < \frac{\varepsilon}{b - a}$。
  • 全局振幅受控可积：取细度 $\lambda < \delta$ 的划分，每个小区间内振幅 $\omega_i \le \frac{\varepsilon}{b-a}$。总振幅和： $$\sum_{i=1}^n \omega_i \Delta x_i \le \frac{\varepsilon}{b - a}\sum \Delta x_i = \frac{\varepsilon}{b - a}(b - a) = \varepsilon$$ 由振幅可积准则，函数必可积！
💡 套路点评：Cantor 定理在积分学中的最璀璨落地。把原本不确定的局部振幅，用一致连续强行压平到 $\frac{\varepsilon}{b-a}$。
推论 7.1.2

闭区间单调函数必可积定理

🏷️ 裂项求和对消法
定义在闭区间 $[a, b]$ 上的任何单调函数必定是 Riemann 可积的（哪怕有可数无穷多个间断点！）。
⚡ 证明精粹与关键步骤
  • 等距划分化归：不妨设 $f$ 单调增。采用等距划分 $\Delta x_i = \frac{b - a}{n}$。
  • 振幅裂项多米诺骨牌相消：由于单调递增，每一段上的最大值和最小值就在端点达到：$\omega_i = f(x_i) - f(x_{i-1})$。
  • 中间项全灭：总振幅和写为： $$\sum \omega_i \Delta x_i = \frac{b - a}{n}\sum_{i=1}^n [f(x_i) - f(x_{i-1})] = \frac{b - a}{n}[f(b) - f(a)]$$
  • 极速归零：只要令 $n \to \infty$，该总振幅和直接趋于 0，证明可积。
💡 套路点评：单调性让每一段的振幅化为一前一后的函数差，求和时首尾相消，展现惊人的代数对称美。
定理 7.3.1

变上限积分的导数定理

🏷️ 连续性局部展开 + 积分中值
设 $f(x)$ 在 $[a, b]$ 上可积，作函数 $F(x) = \int_a^x f(t)\mathrm{d}t$。则 $F(x)$ 在 $[a, b]$ 上连续；若 $f(x)$ 在点 $x_0$ 处连续，则 $F(x)$ 在 $x_0$ 处可导，且 $F'(x_0) = f(x_0)$。
⚡ 证明精粹与关键步骤
  • 差商展开为积分：$\frac{F(x_0 + \Delta x) - F(x_0)}{\Delta x} = \frac{1}{\Delta x}\int_{x_0}^{x_0 + \Delta x} f(t)\mathrm{d}t$。
  • 连续性局部常数化：由 $f$ 在 $x_0$ 连续，对任意 $\varepsilon > 0$，存在 $\delta > 0$，当 $|t - x_0| < \delta$ 时 $|f(t) - f(x_0)| < \varepsilon$。
  • 积分放缩：把 $f(x_0)$ 写成 $\frac{1}{\Delta x}\int_{x_0}^{x_0+\Delta x} f(x_0)\mathrm{d}t$。则： $$\left| \frac{F(x_0 + \Delta x) - F(x_0)}{\Delta x} - f(x_0) \right| \le \frac{1}{|\Delta x|}\int_{x_0}^{x_0+\Delta x} |f(t) - f(x_0)|\mathrm{d}t < \frac{\varepsilon |\Delta x|}{|\Delta x|} = \varepsilon$$
  • 得导数：即 $\lim_{\Delta x \to 0} \frac{\Delta F}{\Delta x} = f(x_0) \implies F'(x_0) = f(x_0)$。
💡 套路点评：微分与积分互为逆运算的关键锁钥！证明了任何连续函数必定拥有原函数。
定理 7.3.2

微积分基本定理（Newton-Leibniz 公式）

🏷️ 变上限原函数 + Lagrange 中值定理推论
设 $f(x)$ 在 $[a, b]$ 上连续，$F(x)$ 是 $f(x)$ 在 $[a, b]$ 上的任意一个原函数，则成立： $$\int_a^b f(x)\mathrm{d}x = F(b) - F(a)$$
⚡ 证明精粹与关键步骤
  • 确立变上限标准原函数：令 $\Phi(x) = \int_a^x f(t)\mathrm{d}t$。由定理 7.3.1 知 $\Phi'(x) = f(x)$。
  • 两原函数相差常数：设 $F(x)$ 为任意原函数，则 $[\Phi(x) - F(x)]' = f(x) - f(x) \equiv 0$。由 Lagrange 中值定理推论，必存在常数 $C$ 满足 $\Phi(x) = F(x) + C$。
  • 定常数求终值：代入 $x = a \implies \Phi(a) = \int_a^a = 0 = F(a) + C \implies C = -F(a)$。
  • 代入上限收网：代入 $x = b \implies \int_a^b f(x)\mathrm{d}x = \Phi(b) = F(b) - F(a)$。
💡 套路点评：整个高等数学中最重要的一行公式。将难以求解的分割求和极限，一举化归为寻找原函数的简单代数差。

定理 8.2.1

无穷限反常积分之 Cauchy 收敛原理

🏷️ 套路 01：Cauchy 准则尾部切片控制
反常积分 $\int_a^{+\infty} f(x)\mathrm{d}x$ 收敛的充要条件是：对任意 $\varepsilon > 0$，存在 $A_0 \ge a$，当 $A_2 > A_1 > A_0$ 时恒有： $$\left| \int_{A_1}^{A_2} f(x)\mathrm{d}x \right| < \varepsilon$$
⚡ 证明精粹与关键步骤
  • 化归函数极限：定义变上限连续函数 $I(A) = \int_a^A f(x)\mathrm{d}x$。
  • 反常积分即极限：$\int_a^{+\infty} f = \lim_{A \to +\infty} I(A)$。
  • 应用函数极限 Cauchy 准则：函数极限存在的充要条件即为柯西准则：对任意两动点 $|I(A_2) - I(A_1)| = |\int_{A_1}^{A_2} f(x)\mathrm{d}x| < \varepsilon$。
💡 套路点评：反常积分条件收敛与绝对收敛理论的总纲领。
定理 8.2.2 / 8.2.3

非负函数反常积分比较与 Cauchy 判别法

🏷️ 套路 03：单调有界收敛定理
设 $f(x) \ge 0$。若 $f(x) \le K \varphi(x)$ 且 $\int_a^{+\infty} \varphi$ 收敛，则 $\int_a^{+\infty} f$ 必收敛；特别地，以 $\int_1^{+\infty} \frac{1}{x^p}\mathrm{d}x$（$p > 1$ 收敛）为标尺。
⚡ 证明精粹与关键步骤
  • 非负性诱导单调增：因被积函数 $f(x) \ge 0$，故 $I(A) = \int_a^A f(x)\mathrm{d}x$ 关于 $A$ 严格单调增加。
  • 收敛积分给出上界天花板：$\int_a^A f(x)\mathrm{d}x \le K \int_a^A \varphi(x)\mathrm{d}x \le K \int_a^{+\infty} \varphi(x)\mathrm{d}x = M < \infty$。
  • 单调有界定理生效：单调递增且有上界的函数在 $A \to +\infty$ 时极限必然存在！
💡 套路点评：将积分收敛性化归为单调函数的天花板封顶法（套路 03）。
定理 8.2.4

积分第二中值定理（Bonnet 与 Du Bois-Reymond 公式）

🏷️ 套路 13：第二积分中值定理（提取单调因子） 🏷️ 套路 10：Abel 分部求和展开
设 $f(x)$ 在 $[a, b]$ 上可积，$g(x)$ 在 $[a, b]$ 上单调。若 $g(x) \ge 0$ 且单调递减，则存在 $\xi \in [a, b]$ 使得： $$\int_a^b f(x)g(x)\mathrm{d}x = g(a^+) \int_a^\xi f(x)\mathrm{d}x$$
⚡ 证明精粹与关键步骤
  • 阶梯函数与 Abel 变换：先将可积函数 $f$ 用阶梯函数逼近，积分化为离散和 $\sum f_k g_k \Delta x_k$。
  • 应用 Abel 变换提取首项：由套路 10，离散分部求和后，单调递减非负权重使得余项差分同号并被确界夹死在 $g(a^+) \cdot [m, M]$ 之间。
  • 连续介值落地：积分原函数连续满足介值性，必定能找到某个瞬时中值点 $\xi$ 使等式成立。
💡 套路点评：把难啃的平缓衰减项 $g(x)$ 像吸铁石一样直接吸出积分号外，是啃下 Dirichlet 积分 $\int_0^\infty \frac{\sin x}{x}\mathrm{d}x$ 的终极神器。
定理 8.2.5

反常积分之 Dirichlet 与 Abel 判别法

🏷️ 套路 13：第二积分中值定理 🏷️ 套路 01：Cauchy 准则
若下列条件之一成立，则 $\int_a^{+\infty} f(x)g(x)\mathrm{d}x$ 收敛：
(1) Dirichlet 判别法：原函数 $\int_a^A f(x)\mathrm{d}x$ 在 $[a, +\infty)$ 上有界，且 $g(x)$ 在 $[a, +\infty)$ 上单调递减趋于 0；
(2) Abel 判别法：反常积分 $\int_a^{+\infty} f(x)\mathrm{d}x$ 收敛，且 $g(x)$ 在 $[a, +\infty)$ 上单调有界。
⚡ 证明精粹与关键步骤
  • 考察尾部切片：检验 Cauchy 准则项：$\left| \int_{A_1}^{A_2} f(x)g(x)\mathrm{d}x \right|$。
  • 施展第二积分中值定理：由定理 8.2.4，存在 $\xi \in [A_1, A_2]$，使得： $$\int_{A_1}^{A_2} f(x)g(x)\mathrm{d}x = g(A_1)\int_{A_1}^\xi f(x)\mathrm{d}x$$
  • 有界配对压制为零：在 Dirichlet 条件下，原函数有界 $|\int_{A_1}^\xi f| \le 2M$，而 $g(A_1) \to 0$。只要 $A_1$ 足够大，直接放大控制： $$\left| \int_{A_1}^{A_2} f(x)g(x)\mathrm{d}x \right| \le g(A_1) \cdot 2M < \varepsilon$$ 由 Cauchy 收敛原理，反常积分必收敛！
💡 套路点评：第二积分中值定理与柯西收敛准则天衣无缝的组合拳。一击驯服强振荡反常积分。
