不定积分线性性质与有理真分式部分分式分解定理

定理 6.1.1 不定积分的线性性定理

🏷️ 套路 03: 构造辅助量与目标恒等变形 不定积分线性微分算子逆原函数同余类常数吸收性
# 定理 6.1.1
📜 原文定理内容 (Verbatim Theorem)
定理 6.1.1（线性性） 若函数 $f(x)$ 和 $g(x)$ 的原函数都存在，则对任意常数 $k_1$ 和 $k_2$，函数 $k_1 f(x) + k_2 g(x)$ 的原函数也存在，且有 $$ \int [k_1 f(x) + k_2 g(x)]\,\mathrm{d}x = k_1 \int f(x)\,\mathrm{d}x + k_2 \int g(x)\,\mathrm{d}x. $$ 此式应理解为等式两端所表示的函数族相同．另外，当 $k_1 = k_2 = 0$ 时，等式右端应理解为常数 $C$．
🔍 原书完整证明 (Verbatim Original Proof)

证 设 $F(x)$ 和 $G(x)$ 分别为 $f(x)$ 和 $g(x)$ 的一个原函数，那么对任意常数 $k_1$ 和 $k_2$，$k_1 F(x) + k_2 G(x)$ 是 $k_1 f(x) + k_2 g(x)$ 的一个原函数，因此有

$$ \int [k_1 f(x) + k_2 g(x)]\,\mathrm{d}x = k_1 F(x) + k_2 G(x) + C, $$

与

$$ \begin{aligned} k_1 \int f(x)\,\mathrm{d}x + k_2 \int g(x)\,\mathrm{d}x &= k_1 (F(x) + C_1) + k_2 (G(x) + C_2) \\ &= k_1 F(x) + k_2 G(x) + (k_1 C_1 + k_2 C_2). \end{aligned} $$

由于上面两式中的 $C, C_1, C_2$ 都代表任意常数，所以上面两等式的右端所表示的函数族相同，于是有

$$ \int [k_1 f(x) + k_2 g(x)]\,\mathrm{d}x = k_1 \int f(x)\,\mathrm{d}x + k_2 \int g(x)\,\mathrm{d}x. $$

💡 大白话点评与证明内幕 🔗 对应实战套路：套路 03: 构造辅助量与目标恒等变形
🎯 一句话精髓： 线性算子伪逆在同余类意义下的保结构映射：微分算子的线性性反向投射至原函数族，形成函数等价类的线性闭包。
💬 大白话版：
不定积分本质是求导运算 $D = \frac{\mathrm{d}}{\mathrm{d}x}$ 的逆映射。证明不定积分的线性性，最根本的手法是求导验证：设 $F, G$ 分别为 $f, g$ 的原函数，对线性组合 $k_1 F(x) + k_2 G(x)$ 求导，由一阶导数的线性性（定理 4.3.1），导数严格等于 $k_1 f(x) + k_2 g(x)$。这表明 $k_1 F + k_2 G$ 确实是新函数的原函数。需要特别强调的是：不定积分并非单一数值，而是以任意常数 $C$ 为模的函数等价类（即集合同余类 $\{F(x) + C \mid C \in \mathbb{R}\}$）。公式中的等号表示两个函数集合相等，任意常数 $C$ 在加减与数乘下具有完全的代数吸收性。
🍎 形象理解：
函数向量空间中平行纤维丛的仿射投影：原函数族是一簇在纵向相差常数高度的等距平行曲线族（几何纤维丛）。微分算子将整簇平行曲线投射到唯一的导函数向量上；反向的不定积分则将函数空间的线性运算完全保真地还原为平行纤维丛之间的线性平移叠加。
🔑 证明核心关键点 (Key Insights)
  • 求导验证法：证明两个不定积分表达式相等，充要条件是验证两端任意代表元的导数在区间上处处恒等。
  • 同余类等式本质：等号两端并非单纯的数值相等，而是集合相等的同余记号，常数 $C$ 吸收了数乘倍数与加法常数。
  • 积分技术的大前提：是一切换元积分法与分部积分法得以展开的底层线性空间代数根基。

定理 6.3.1 有理真分式实根部分分式分解定理

🏷️ 套路 03: 构造辅助量与目标恒等变形 有理函数积分部分分式分解因式定理降次待定系数消除极点
# 定理 6.3.1
📜 原文定理内容 (Verbatim Theorem)
设有理函数 $\dfrac{p(x)}{q(x)}$ 是真分式，多项式 $q(x)$ 有 $k$ 重实根 $\alpha$，即 $q(x) = (x - \alpha)^k q_1(x), q_1(\alpha) \neq 0$．则存在实数 $\lambda$ 与多项式 $p_1(x)$，$p_1(x)$ 的次数低于 $(x - \alpha)^{k-1}q_1(x)$ 的次数，成立 $$ \frac{p(x)}{q(x)} = \frac{\lambda}{(x - \alpha)^k} + \frac{p_1(x)}{(x - \alpha)^{k-1}q_1(x)}. $$
🔍 原书完整证明 (Verbatim Original Proof)

证 令 $\dfrac{p(\alpha)}{q_1(\alpha)} = \lambda$，则 $x = \alpha$ 是多项式 $p(x) - \lambda q_1(x)$ 的根，设

$$ p(x) - \lambda q_1(x) = (x - \alpha)p_1(x), $$

就得到

$$ \frac{p(x)}{q(x)} = \frac{\lambda}{(x - \alpha)^k} + \frac{p_1(x)}{(x - \alpha)^{k-1}q_1(x)}. $$

证毕

💡 大白话点评与证明内幕 🔗 对应实战套路：套路 03: 构造辅助量与目标恒等变形
🎯 一句话精髓： 多项式代数环的因式整除与奇点阶数逐级剥离：通过在极点处赋值使得残余分子产生公因式 $(x-\alpha)$，完成有理分式降次。
💬 大白话版：
有理函数积分的核心是将复杂的有理真分式 $\frac{p(x)}{(x-\alpha)^k q_1(x)}$ 拆解为最简单的单项式之和。定理证明展现了多项式代数的极致精巧：设定待定常数 $\lambda = \frac{p(\alpha)}{q_1(\alpha)}$（因 $q_1(\alpha) \ne 0$，此商良定唯一）。作差得到的分子多项式 $p(x) - \lambda q_1(x)$ 在 $x = \alpha$ 时代入刚好为零！根据多项式因式定理，该多项式必定含有公因式 $(x-\alpha)$，即能分解为 $(x-\alpha)p_1(x)$。分子分母的公因式 $(x-\alpha)$ 当场约去，使得分母中的重根幂次从 $k$ 降为 $k-1$！重复此过程 $k$ 次，所有重实根被彻底剥离为单个负整数幂项，从而将高阶积分完全转化为初等幂函数积分。
🍎 形象理解：
极点奇异性强度的局域展开与剥离：在实轴上的极点 $\alpha$ 附近，高阶极点 $(x-\alpha)^{-k}$ 占据主导。常数 $\lambda$ 恰好度量了该奇点在此最高阶处的局域奇性强度；减去该主部项后，局部奇点阶数降为 $k-1$，在几何相空间中奇性被逐级弱化直至消失。
🔑 证明核心关键点 (Key Insights)
  • 待定系数唯一性的代数构造：令 $\lambda = \frac{p(\alpha)}{q_1(\alpha)}$，迫使 $x=\alpha$ 成为分子多项式的根。
  • 因式定理核心应用：$p(x) - \lambda q_1(x) = (x-\alpha)p_1(x)$，直接完成多项式整除降次。
  • 离散阶数递推完全性：经有限次 $k$ 步循环，有理分母完全分解为不可再降的单项幂，为初等积分铺平道路。

定理 6.3.2 有理真分式共轭复根部分分式分解定理

🏷️ 套路 03: 构造辅助量与目标恒等变形 有理函数积分共轭复根二次不可约因式复数赋值与实数域整除
# 定理 6.3.2
📜 原文定理内容 (Verbatim Theorem)
设有理函数 $\dfrac{p(x)}{q(x)}$ 是真分式，多项式 $q(x)$ 有 $l$ 重共轭复根 $\beta \pm \mathrm{i}\gamma$，即 $q(x) = (x^2 + 2\xi x + \eta^2)^l q^*(x), q^*(\beta \pm \mathrm{i}\gamma) \neq 0$．则存在实数 $\mu, \nu$ 和多项式 $p^*(x)$，$p^*(x)$ 的次数低于 $(x^2 + 2\xi x + \eta^2)^{l-1}q^*(x)$ 的次数，成立 $$ \frac{p(x)}{q(x)} = \frac{\mu x + \nu}{(x^2 + 2\xi x + \eta^2)^l} + \frac{p^*(x)}{(x^2 + 2\xi x + \eta^2)^{l-1}q^*(x)}. $$
🔍 原书完整证明 (Verbatim Original Proof)

证 令

$$ \frac{p(\beta + \mathrm{i}\gamma)}{q^*(\beta + \mathrm{i}\gamma)} = \mu(\beta + \mathrm{i}\gamma) + \nu, $$

其中 $\mu, \nu$ 为实数，则

$$ \frac{p(\beta - \mathrm{i}\gamma)}{q^*(\beta - \mathrm{i}\gamma)} = \mu(\beta - \mathrm{i}\gamma) + \nu. $$

于是 $x = \beta \pm \mathrm{i}\gamma$ 是多项式 $p(x) - (\mu x + \nu)q^*(x)$ 的根，设

$$ p(x) - (\mu x + \nu)q^*(x) = (x^2 + 2\xi x + \eta^2)p^*(x), $$

就得到

$$ \frac{p(x)}{q(x)} = \frac{\mu x + \nu}{(x^2 + 2\xi x + \eta^2)^l} + \frac{p^*(x)}{(x^2 + 2\xi x + \eta^2)^{l-1}q^*(x)}. $$

证毕

💡 大白话点评与证明内幕 🔗 对应实战套路：套路 03: 构造辅助量与目标恒等变形
🎯 一句话精髓： 共轭复数对称性在实代数环中的不可约整除：通过复数赋值联立实部虚部解出线性分子，将二次不可约重因子逐阶消去。
💬 大白话版：
当分母含有实数域上不可约的二次重因子 $(x^2 + 2\xi x + \eta^2)^l$ 时（对应一对共轭复根 $\beta \pm \mathrm{i}\gamma$），如何不引入虚数单位 $\mathrm{i}$ 而在纯实数域内完成分解？定理给出了剥离一次式分子 $\frac{\mu x + \nu}{(x^2 + 2\xi x + \eta^2)^l}$ 的普适方案。证明极其精妙地借道复数域：将复根 $z_0 = \beta + \mathrm{i}\gamma$ 代入等式 $\frac{p(z_0)}{q^*(z_0)} = \mu z_0 + \nu$。该复数等式拆分为实部与虚部两个实线性方程，由于虚部 $\gamma \ne 0$，系数行列式非零，恰好唯一解出两个实数常数 $\mu$ 与 $\nu$！此时新分子多项式在 $\beta + \mathrm{i}\gamma$ 处为零；由实多项式的共轭对称性，它在其共轭点 $\beta - \mathrm{i}\gamma$ 处也必须为零。于是该实多项式必定能被二次实不可约多项式 $(x^2 + 2\xi x + \eta^2)$ 完全整除！分子分母约分后，二次因子的幂次成功从 $l$ 降为 $l-1$！
🍎 形象理解：
复平面共轭镜像对的实轴二元降次：互为共轭的一对复极点在复平面上关于实轴镜像对称。单独的一次复数因子无法在实数轴维持实系数，将其合并为二次因式后，一次式分子 $\mu x + \nu$ 恰好提供了匹配该对称极点对的二维自由度，在实相空间中对应阻尼对数项与 $\arctan$ 反三角项。
🔑 证明核心关键点 (Key Insights)
  • 复数赋值确立二元待定系数：利用实部虚部线性方程的非奇异性，唯一解出实系数对 $(\mu, \nu)$。
  • 共轭成对零点与多项式整除定理：实系数多项式若以复数为根，必以其共轭复数为根，从而整除二次多项式 $(x-z_0)(x-\bar{z}_0) = x^2+2\xi x+\eta^2$。
  • 有理函数不定积分终极结论：任何实系数有理函数的不定积分，皆可严格表示为有理分式、自然对数 $\ln$ 与反三角函数 $\arctan$ 的有限次代数叠加！
