📖 定义 16.2.1 分段单调函数与分段光滑函数

核心概念定义 分段单调分段光滑有限跳跃间断点
# 定义 16.2.1
📜 原文定义陈述 (Verbatim Definition)

设函数 $f$ 在 $[a, b]$（或 $(a, b)$）上有定义．如果在 $[a, b]$（或 $(a, b)$）上存在有限个点 $a = x_0 < x_1 < \cdots < x_N = b$，使得 $f$ 在每个区间 $(x_{i-1}, x_i)$（$i = 1, 2, \ldots, N$）上是单调函数，则称 $f$ 在 $[a, b]$（或 $(a, b)$）上分段单调．

📖 定义 16.3.1 内积空间与最佳正交投影

核心概念定义 内积空间范数模长最佳平方逼近正交投影
# 定义 16.3.1
📜 原文定义陈述 (Verbatim Definition)

设 $S$ 是一个定义了内积运算 $(\cdot, \cdot)$ 的线性空间，取 $S$ 中的范数为 $\|\cdot\| = \sqrt{(\cdot, \cdot)}$，$T$ 是 $S$ 的一个 $n$ 维子空间，记 $T$ 的一组正交基为 $\varphi_1, \varphi_2, \ldots, \varphi_n$，即 $T = \mathrm{span}\{\varphi_1, \varphi_2, \ldots, \varphi_n\}$．若对于 $x \in S$，有 $x_T = c_1\varphi_1 + c_2\varphi_2 + \cdots + c_n\varphi_n \in T$，使得

$$\|x - x_T\| \le \|x - y\|, \quad \forall y \in T,$$

则称 $x_T$ 是 $x$ 在 $T$ 中的最佳平方逼近元素．

📖 定义 16.3.2 平方平均收敛 (L² 模收敛)

核心概念定义 平方平均收敛L²空间能量守恒Parseval
# 定义 16.3.2
📜 原文定义陈述 (Verbatim Definition)

若函数序列 $\{\varphi_n(x)\}$ 满足 $\lim_{n\to\infty}\|f(x) - \varphi_n(x)\|^2 = 0$，这里 $f(x)$ 是某一个固定函数，则称 $\{\varphi_n(x)\}$ 按范数 $\|\cdot\|$ 平方收敛于 $f(x)$．

📖 定义 16.4.1 分段可导函数

核心概念定义 分段可导左右导数存在光滑拼合
# 定义 16.4.1
📜 原文定义陈述 (Verbatim Definition)

设函数 $f$ 在 $[a, b]$ 上除有限个点 $a = x_0 < x_1 < \cdots < x_N = b$ 外连续（在 $x_0 = a$ 只要求右极限存在，在 $x_N = b$ 只要求左极限存在），并且极限

$$\lim_{h\to 0^-}\frac{f(x_0 + h) - f(x_0^+)}{h} \quad \text{和} \quad \lim_{h\to 0^+}\frac{f(x_0 + h) - f(x_0^+)}{h}$$

都存在，那么称 $f$ 在 $[a, b]$ 上分段可导．

📖 定义 16.4.2 函数的连续卷积运算 (Convolution)

核心概念定义 连续卷积f*g线性时不变系统平滑滤波器
# 定义 16.4.2
📜 原文定义陈述 (Verbatim Definition)

设函数 $f$ 和 $g$ 在 $(-\infty, +\infty)$ 上定义，且积分

$$(f * g)(x) = \int_{-\infty}^{+\infty} f(x-t)g(t)\,\mathrm{d}t$$

存在，则称函数 $f * g$ 为 $f$ 和 $g$ 的卷积．显然，卷积具有对称性，即 $f * g = g * f$．

定理 16.2.1 Riemann 引理

🏷️ 套路 15: 正交基投影与函数空间 Fourier 分解 Fourier级数正交函数系Dirichlet核Riemann-Lebesgue引理Parseval等式
# 定理 16.2.1
📜 原文定理内容 (Verbatim Theorem)

设函数 $\varphi(x)$ 在 $[0, b]$ 上可积或绝对可积，则成立

$$\lim_{p\to+\infty}\int_0^b \varphi(x)\sin px\,\mathrm{d}x = \lim_{p\to+\infty}\int_0^b \varphi(x)\cos px\,\mathrm{d}x = 0.$$
🔍 原书完整证明 (Verbatim Original Proof)
证

先考虑 $\varphi(x)$ 有界的情况，这时 $\varphi(x)$ Riemann 可积．对于任意给定的 $\varepsilon > 0$，由定理 7.1.3，存在着一种划分 $0 = x_0 < x_1 < \cdots < x_N = b$，满足

$$\sum_{i=1}^N (M_i - m_i)(x_i - x_{i-1}) < \varepsilon,$$

对于这种固定的划分，记 $m_i$ 是 $\varphi(x)$ 在 $[x_{i-1}, x_i]$ 中的下确界，并取实数 $P > 0$，使得当 $p > P$ 时，对任意 $i$，

$$\left|\frac{\cos px_{i-1} - \cos px_i}{p}\right| < \frac{\varepsilon}{N(|m_i|+1)}.$$

于是，对于任意给定的 $\varepsilon > 0$，存在实数 $P > 0$，当 $p > P$ 时，有

$$\left|\int_0^b \varphi(x)\sin px\,\mathrm{d}x\right| \le \sum_{i=1}^N\int_{x_{i-1}}^{x_i}|\varphi(x) - m_i|\cdot|\sin px|\,\mathrm{d}x + \left|\sum_{i=1}^N m_i\int_{x_{i-1}}^{x_i}\sin px\,\mathrm{d}x\right| < \varepsilon + \varepsilon = 2\varepsilon.$$

再考虑 $\varphi(x)$ 无界的情况，这时 $\varphi(x)$ 绝对可积．不妨假设 $b$ 是 $\varphi(x)$ 的唯一奇点．由无界函数反常积分绝对收敛的定义，对于任意给定的 $\varepsilon > 0$，存在 $\delta > 0$，当 $\eta < \delta$ 时，

$$\int_{b-\eta}^b |\varphi(x)|\,\mathrm{d}x < \varepsilon.$$

固定 $\delta$，则 $\varphi(x)$ 在 $[0, b-\delta]$ 上 Riemann 可积，应用上面的结论，存在实数 $P > 0$，当 $p > P$ 时，

$$\left|\int_0^{b-\delta}\varphi(x)\sin px\,\mathrm{d}x\right| < \varepsilon.$$

因此，

$$\left|\int_0^b\varphi(x)\sin px\,\mathrm{d}x\right| \le \left|\int_0^{b-\delta}\varphi(x)\sin px\,\mathrm{d}x\right| + \int_{b-\delta}^b|\varphi(x)|\,\mathrm{d}x < 2\varepsilon.$$

所以无论对哪一种情况，都有 $\lim_{p\to+\infty}\int_0^b \varphi(x)\sin px\,\mathrm{d}x = 0$．同理可证 $\lim_{p\to+\infty}\int_0^b \varphi(x)\cos px\,\mathrm{d}x = 0$．证毕

# 推论 16.2.1
📜 原文定理内容 (Verbatim Theorem)

可积或绝对可积函数 $f(x)$ 的 Fourier 级数在 $x$ 点是否收敛只与 $f(x)$ 在 $(x - \delta, x + \delta)$ 的性质有关，这里 $\delta$ 是任意小的正常数．

🔍 原书完整证明 (Verbatim Original Proof)
证

因为 $\dfrac{f(x+u) + f(x-u)}{2\sin\frac{u}{2}}$ 关于 $u$ 在 $[\delta, \pi]$ 可积或绝对可积，由 Riemann 引理，

$$\lim_{m\to\infty}\frac{1}{\pi}\int_\delta^\pi [f(x+u) + f(x-u)]\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u = 0.$$

因此，若将 $S_m(x)$ 的表达式中积分区间分成 $[0, \delta]$ 和 $[\delta, \pi]$ 两部分，则当 $m \to \infty$ 时，$S_m(x)$ 的敛散性显然只与

$$\frac{1}{\pi}\int_0^\delta [f(x+u) + f(x-u)]\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u$$

有关，而这个积分只涉及 $f(x)$ 在 $(x-\delta, x+\delta)$ 的性质．证毕

# 定理 16.2.2
📜 原文定理内容 (Verbatim Theorem)

设函数 $f(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积，且满足下列两个条件之一，则 $f(x)$ 的 Fourier 级数在点 $x$ 处收敛于 $\dfrac{f(x^+) + f(x^-)}{2}$．

(1)（Dirichlet-Jordan 判别法）$f(x)$ 在点 $x$ 的某个邻域 $O(x, \delta)$ 上是分段单调有界函数；

(2)（Dini-Lipschitz 判别法）$f(x)$ 在点 $x$ 处满足指数为 $\alpha \in (0, 1]$ 的 Hölder 条件，即对于充分小的正数 $h$，存在常数 $L > 0$ 和 $\alpha \in (0, 1]$，使得成立

$$|f(x+h) - f(x^+)| + |f(x-h) - f(x^-)| \le L h^\alpha.$$

（当 $\alpha = 1$ 时也称为 Lipschitz 条件．）

定理 16.2.3 Dirichlet 引理

🏷️ 套路 15: 正交基投影与函数空间 Fourier 分解 Fourier级数正交函数系Dirichlet核Riemann-Lebesgue引理Parseval等式
# 定理 16.2.3
📜 原文定理内容 (Verbatim Theorem)

设函数 $\varphi(u)$ 在 $[0, \delta]$ 上单调，则成立

$$\lim_{p\to+\infty}\int_0^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u = 0.$$
🔍 原书完整证明 (Verbatim Original Proof)
证

不妨设 $\varphi(x)$ 单调增加．于是对任意给定的 $\varepsilon > 0$，存在 $\eta \in (0, \delta)$，当 $u \in (0, \eta)$ 时，$0 \le \varphi(u) - \varphi(0^+) < \varepsilon$．将积分分为两部分

$$\int_0^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u = \int_0^\eta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u + \int_\eta^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u.$$

对等式右边的第一项，由积分第二中值定理，存在 $\xi \in [0, \eta]$，

$$\left|\int_0^\eta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u\right| \le \frac{\varepsilon}{\eta}\left|\int_0^\xi \sin pu\,\mathrm{d}u\right| \le \frac{\varepsilon}{\eta}\cdot\frac{2}{p}.$$

利用含参变量积分中已经得到的结论，可知存在与 $p$ 无关的常数 $K$，使得 $\left|p\int_0^\xi\sin pu\,\mathrm{d}u\right| \le K$，即

$$\left|\int_0^\eta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u\right| < K\varepsilon.$$

而对右边的第二项，由于 $\dfrac{\varphi(u) - \varphi(0^+)}{u}$ 在 $[\eta, \delta]$ 上显然是可积或绝对可积的，由 Riemann 引理，存在常数 $P > 0$，当 $p > P$ 时，有

$$\left|\int_\eta^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u\right| < \varepsilon.$$

综合上述两项估计，即知结论成立．Dirichlet 引理也经常表达为等价形式

$$\lim_{p\to+\infty}\int_0^\delta \varphi(u)\frac{\sin pu}{u}\,\mathrm{d}u = \varphi(0^+)\cdot\frac{\pi}{2}.$$

如果 $\varphi(u)$ 是分段单调有界函数，易知 Dirichlet 引理依然成立．证毕

# 定理 16.3.2
📜 原文定理内容 (Verbatim Theorem)

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积，

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx),$$

则 $f(x)$ 的 Fourier 级数可以逐项积分，即对于任意 $c, x \in [-\pi, \pi]$，

$$\int_c^x f(t)\,\mathrm{d}t = \frac{a_0}{2}(x - c) + \sum_{n=1}^\infty\left[a_n\int_c^x\cos nt\,\mathrm{d}t + b_n\int_c^x\sin nt\,\mathrm{d}t\right].$$
🔍 原书完整证明 (Verbatim Original Proof)
证（仅对 $f(x)$ 有有限个第一类不连续点的情况）

$$F(x) = \int_c^x \left[f(t) - \frac{a_0}{2}\right]\mathrm{d}t.$$

$F(x)$ 是周期为 $2\pi$ 的连续函数，且由定理 7.3.1 可知，在 $f(x)$ 的连续点，成立 $F'(x) = f(x) - \dfrac{a_0}{2}$，而在 $f(x)$ 的第一类不连续点，$F(x)$ 的两个单侧导数都存在．由 Dini-Lipschitz 判别法的推论，$F(x)$ 可展开为收敛的 Fourier 级数

$$F(x) = \frac{A_0}{2} + \sum_{n=1}^\infty (A_n\cos nx + B_n\sin nx).$$

利用分部积分法，即有

$$A_n = \frac{1}{\pi}\int_{-\pi}^\pi F(x)\cos nx\,\mathrm{d}x = \frac{1}{\pi}\left[\frac{F(x)\sin nx}{n}\Big|_{-\pi}^\pi - \frac{1}{n}\int_{-\pi}^\pi f(x)\sin nx\,\mathrm{d}x\right] = -\frac{b_n}{n}.$$

类似可得 $B_n = \dfrac{a_n}{n}$．于是

$$F(x) = \frac{A_0}{2} + \sum_{n=1}^\infty\left(-\frac{b_n}{n}\cos nx + \frac{a_n}{n}\sin nx\right).$$

令 $x = c$，有

$$0 = \frac{A_0}{2} + \sum_{n=1}^\infty\left(-\frac{b_n}{n}\cos nc + \frac{a_n}{n}\sin nc\right).$$

两式相减并整理，即得到

$$F(x) - F(c) = \int_c^x\left[f(t) - \frac{a_0}{2}\right]\mathrm{d}t = \sum_{n=1}^\infty\left(\frac{b_n(\cos nc - \cos nx)}{n} + \frac{a_n(\sin nx - \sin nc)}{n}\right) = \int_c^x\sum_{n=1}^\infty (a_n\cos nt + b_n\sin nt)\,\mathrm{d}t.$$

证

# 引理 16.3.1

证

引理 16.3.2 Wirtinger

# 引理 16.3.2
📜 原文定理内容 (Verbatim Theorem)

设 $f(x)$ 在 $[-\pi, \pi]$ 上连续，$f(-\pi) = f(\pi)$，$\int_{-\pi}^\pi f(x)\,\mathrm{d}x = 0$，且除了有限个点外 $f(x)$ 可导，但在不可导的点，$f(x)$ 的单侧导数存在．进一步假设，$f(x)$ 的导数 $f'(x)$ 在 $[-\pi, \pi]$ 上可积或平方可积，则

$$\int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x \le \int_{-\pi}^\pi [f'(x)]^2\,\mathrm{d}x,$$

等号成立当且仅当 $f(x) = a\cos x + b\sin x$（$a, b$ 为常数）．

🔍 原书完整证明 (Verbatim Original Proof)
证

$$\int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x = \pi\sum_{n=1}^\infty (a_n^2 + b_n^2),$$ $$\int_{-\pi}^\pi [f'(x)]^2\,\mathrm{d}x = \pi\sum_{n=1}^\infty n^2(a_n^2 + b_n^2) \ge \pi\sum_{n=1}^\infty (a_n^2 + b_n^2).$$
