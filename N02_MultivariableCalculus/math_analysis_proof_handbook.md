## 手册导读：分析学证明的底层心法

数学分析与初等代数最大的区别在于：**代数追求精确相等，分析追求可控误差**。  
分析学中几乎没有一个结论是通过一步到位的“恒等变形”得到的，它的通用工作流是：
1. **抓主部**：识别主要贡献项；
2. **放误差**：用三角不等式把次要的杂项拆开；
3. **设阈值**：通过调节变量邻域，让误差项萎缩到任意给定的正数 ε 之下。

牢记解题反射弧：**遇极限先分拆，遇中值造原函；遇递推证单界，要否定抓子列。**

## 第一梯队：T0 顶级基石

### 1. ε-δ / ε-N 分拆与局部有界放缩法

* **使用频度**：90%（分析理论大题第一主力）
* **核心主场**：证明极限四则运算法则、复合函数极限、黎曼可积判定、连续性定义。

#### 大白话通俗理解
> **“买菜凑整与画圈隔离”**：  
> 你想证明两样东西最终差距小于一分钱（ε）。通常这个差距是由两个原因引起的（比如单价在变，重量也在变）。  
> 1. **ε/2 法**：把一分钱拆成五厘钱。只要第一项误差小于五厘，第二项误差也小于五厘，两项合起来绝对不超过一分钱。  
> 2. **局部有界法**：如果式子里夹杂着一个未知变化的干扰因数（比如自变量 x 本身），我们不要管它在全球怎么跑，先在目标点附近画一个半径为 1 的小圈圈，把它关在圈里。圈内它是有限的常数（有界），这就消除了不稳定因素。最后通过“取最小值（min）”同时兼顾小圈圈和精度要求。

#### 严密数学描述
欲证 lim_{x → x₀} f(x) = A。对任意给定的 ε > 0：
1. 作差分解：|f(x) - A| ≤ |g(x)| · |h(x)|；
2. 先固定初选步长 δ₁ > 0（通常取 δ₁ = 1），当 0 < |x - x₀| < δ₁ 时，控制未知因子有界：|g(x)| ≤ M；
3. 对剩下的因子求解精度要求：寻找 δ₂ > 0，当 0 < |x - x₀| < δ₂ 时，|h(x)| < ε / M；
4. 综合选取 **δ = min{δ₁, δ₂}**，保证两项控制同时生效，推导 |f(x) - A| < M · (ε / M) = ε。

#### 经典实战例题与逐步拆解
* **题目**：用 ε-δ 语言证明：lim_{x → 2} (x² + 3x) = 10。
* **拆解证明**：
  * **第一步：作差拆项**  
    目标差值为：|(x² + 3x) - 10| = |(x - 2)(x + 5)| = |x - 2| · |x + 5|。  
    此时 |x - 2| 是能够被我们主动控制的无限小量，而 |x + 5| 是干扰因子。
  * **第二步：画圈隔离（局部有界）**  
    先取 δ₁ = 1。当 0 < |x - 2| < 1 时，可知 1 < x < 3。  
    因此 6 < x + 5 < 8，即 |x + 5| < 8。
  * **第三步：配平精度要求**  
    为了让整个积小于 ε，我们需要让 |x - 2| · 8 < ε，即 |x - 2| < ε / 8。  
    故令 δ₂ = ε / 8。
  * **第四步：规范写出证明**  
    任取 ε > 0，取 **δ = min{1, ε / 8}**。  
    当 0 < |x - 2| < δ 时，既满足 |x + 5| < 8，又满足 |x - 2| < ε / 8。  
    因此：|(x² + 3x) - 10| = |x - 2| · |x + 5| < (ε / 8) · 8 = ε。  
    证毕。

#### 避坑指南
* 绝对不能写出含有自变量 x 的 δ（例如“令 δ = ε / |x + 5|”是严重原则性错误）。δ 只能依赖于 ε 和 x₀，绝不能依赖自变量 x。

### 2. 微分中值定理与辅助函数构造法（积分因子逆推）

* **使用频度**：98%（微分学压轴证明大题几乎必考）
* **核心主场**：证明含有导数与原函数关系的等式、多导数中值点共存问题。

#### 大白话通俗理解
> **“反向侦探法 / 逆推老祖宗”**：  
> 题目要你证明存在一个点 ξ 使得某条奇怪的导数等式成立（例如 ξf'(ξ) + 2f(ξ) = 0）。直接看毫无头绪。  
> 怎么办？把这个待证式子当成一道微分方程，在草稿纸上解出它的原函数 F(x)。这个 F(x) 就是我们要找的“辅助函数”。只要这个老祖宗在区间的两个端点值相等（F(a) = F(b)），罗尔（Rolle）定理就会从天而降，自动保证中间一定有个点导数归零。

#### 严密数学描述
常见的微分方程反推映射表：
* 若待证式为 f'(ξ) + g(ξ)f(ξ) = 0：两边同乘积分因子 e^{∫ g(x)dx}，令 **F(x) = e^{∫ g(x)dx} · f(x)**。
* 若待证式为 xf'(ξ) + nf(ξ) = 0：两边同乘 xⁿ⁻¹，令 **F(x) = xⁿ · f(x)**。
* 若待证式为 f'(ξ) + k·f(ξ) = 0：令 **F(x) = e^{kx} · f(x)**。
* 若待证式为 f'(ξ) - f(ξ)·tan(ξ) = 0：令 **F(x) = f(x) · cos(x)**。
* 若待证式为 f''(ξ) + f'(ξ)g(ξ) = 0：令 **F(x) = f'(x) · e^{∫ g(x)dx}**。

#### 经典实战例题与逐步拆解
* **题目**：设 f(x) 在 [0, 1] 上连续，在 (0, 1) 内可导，且 f(0) = f(1) = 0。证明：对任意实数 k，存在 ξ ∈ (0, 1)，使得 f'(ξ) + k·f(ξ) = 0。
* **拆解证明**：
  * **第一步：逆推辅助函数**  
    解常微分方程 y' + ky = 0：通解为 y · e^{kx} = C。  
    因此设辅助函数为：**F(x) = e^{kx} · f(x)**。
  * **第二步：验证 Rolle 定理三大条件**  
    1. 连续性：e^{kx} 与 f(x) 在 [0, 1] 上皆连续，故 F(x) 在 [0, 1] 上连续；  
    2. 可导性：在 (0, 1) 内 F'(x) = k·e^{kx}·f(x) + e^{kx}·f'(x) = e^{kx}[f'(x) + k·f(x)] 存在；  
    3. 端点值：F(0) = e⁰ · f(0) = 0，F(1) = eᵏ · f(1) = 0，故 F(0) = F(1) = 0。
  * **第三步：收网**  
    由 Rolle 定理，必存在 ξ ∈ (0, 1) 使得 F'(ξ) = 0。  
    即 e^{kξ}[f'(ξ) + k·f(ξ)] = 0。  
    因指数函数 e^{kξ} > 0 恒不为 0，两边同除即得：f'(ξ) + k·f(ξ) = 0。  
    证毕。

#### 避坑指南
* 若题目中出现两个不同的中值（例如出现 ξ 和 η），切记不可直接设同一个辅助函数用一次 Rolle。通常要对两个子区间分别用 Lagrange 中值定理，或者直接使用 Cauchy 中值定理：f'(ξ) / g'(ξ) = [f(b) - f(a)] / [g(b) - g(a)]。

### 3. 单调有界收敛定理（递推数列三步法）

* **使用频度**：92%（数列极限压轴或首道大题必考）
* **核心主场**：各类非线性递推数列 xₙ₊₁ = f(xₙ) 的收敛性证明与极限值计算。

#### 大白话通俗理解
> **“单向电梯封顶法”**：  
> 一个人只能往上走（单调递增），头顶上还有一层水泥天花板挡着（有上界），那他无论跑得多慢，最终必然会无限贴近某个极限位置，绝对不可能无限往上飞，也绝不可能掉下来振荡。

#### 严密数学描述
1. **数学归纳法证有界**：找到合理的界 M（通常由令递推式两边取极限 L = f(L) 预估求出），用归纳法验证对所有 n，xₙ ≤ M（或 xₙ ≥ m）；
2. **符号差分或比值法证单调**：
   * 作差法：考察 xₙ₊₁ - xₙ = f(xₙ) - xₙ 的符号；
   * 或归纳法：若 x₂ ≥ x₁ 且 f(x) 单调增，则立刻可递推导出对任意 n 均有 xₙ₊₁ ≥ xₙ；
3. **单调有界定理落地**：由单调有界准则，必存在极限 lim_{n→∞} xₙ = L；
4. **方程定值**：在递推关系两端同时令 n → ∞，解代数方程 L = f(L)，结合有界性排除不合题意的增根。

#### 经典实战例题与逐步拆解
* **题目**：已知 x₁ = √2，递推关系为 xₙ₊₁ = √(2 + xₙ)（n ≥ 1）。证明：数列 {xₙ} 收敛，并求其极限。
* **拆解证明**：
  * **第一步：草稿纸预判极限**  
    令 L = √(2 + L) ⇒ L² - L - 2 = 0 ⇒ (L - 2)(L + 1) = 0。因项均为正，预判 L = 2。
  * **第二步：归纳法证上界（xₙ < 2）**  
    1. 当 n = 1 时，x₁ = √2 < 2，成立；  
    2. 假设当 n = k 时，xₖ < 2 成立，则 xₖ₊₁ = √(2 + xₖ) < √(2 + 2) = 2。  
    由数学归纳法，对任意自然数 n，均有 xₙ < 2（有上界）。
  * **第三步：作差法证单调增（xₙ₊₁ > xₙ）**  
    考察差值：xₙ₊₁² - xₙ² = (2 + xₙ) - xₙ² = -(xₙ - 2)(xₙ + 1)。  
    因为 0 < xₙ < 2，所以 xₙ - 2 < 0，且 xₙ + 1 > 0。  
    因此 xₙ₊₁² - xₙ² > 0。又因各项均为正数，故 xₙ₊₁ > xₙ。  
    数列 {xₙ} 严格单调递增。
  * **第四步：下结论并定值**  
    由单调有界收敛定理，数列 {xₙ} 必收敛。设 lim_{n→∞} xₙ = L。  
    在 xₙ₊₁ = √(2 + xₙ) 两边同时取极限：L = √(2 + L)。  
    解得 L = 2（负根 -1 舍去，因各项非负）。  
    极限值为 2。证毕。

#### 避坑指南
* 严禁在**未证明极限存在之前**直接写“设 lim xₙ = L，在等式两边取极限”。如果数列发散（如 xₙ₊₁ = 2xₙ - 1，令 L = 2L - 1 解得 L = 1，但初值取 2 时数列发散到无穷），直接设极限必得零分。必须“先证收敛，再求极限”。

### 4. 反证法 + 反设 ∃ ε₀ 并令 δ = 1/n 提取矛盾点列

* **使用频度**：86%（否定性命题、非一致性证明绝对王者）
* **核心主场**：证明函数非一致连续、函数在区间无界、函数列非一致收敛、极限不存在。

#### 大白话通俗理解
> **“卧底抓现行法”**：  
> 对方声称“天下无贼”（对于任何精度要求，处处都能满足一致连续或有界）。  
> 我们的反驳套路极其机械有力：  
> 我不需要驳倒所有情况，我只要反设“存在一个固定的偷窃漏洞 ε₀”。  
> 然后我拿一个越来越紧的放大镜去看（令搜索半径 δ 分别取 1, 1/2, 1/3, ..., 1/n）。  
> 只要对方说的是假话，那么在每个 1/n 邻域里，我都必定能抓到一个“违规小偷 xₙ”。  
> 当 n 趋向于无穷时，这些小偷点靠得无限近，但是他们的违规事实（|f(xₙ) - f(yₙ)| ≥ ε₀）却被抓了现行，当场逻辑爆炸。

#### 严密数学描述
一致连续性定义：∀ ε > 0, ∃ δ > 0, ∀ x, y (|x - y| < δ ⇒ |f(x) - f(y)| < ε)。  
* **逻辑否定（反命题）**：  
  **∃ ε₀ > 0, ∀ δ > 0, ∃ x, y 满足 |x - y| < δ，但 |f(x) - f(y)| ≥ ε₀**。  
* **套路化提取点列**：  
  令 δ 分别取 1/n（n = 1, 2, 3, ...）。  
  根据否定命题，对每个 1/n，必定存在一对点 xₙ, yₙ，满足：  
  |xₙ - yₙ| < 1/n，但是 |f(xₙ) - f(yₙ)| ≥ ε₀。  
* 显然 lim_{n→∞} |xₙ - yₙ| = 0，而函数值差却被正数 ε₀ 死死顶住无法归零，矛盾达成！

#### 经典实战例题与逐步拆解
* **题目**：证明函数 f(x) = 1 / x 在开区间 (0, 1) 上**非一致连续**。
* **拆解证明**：
  * **第一步：构造反设与固定误差**  
    反设 f(x) 在 (0, 1) 上一致连续。  
    取固定的正数 ε₀ = 1。
  * **第二步：针对 δₙ = 1/n 构造抓现行点列**  
    根据一致连续假设，对该 ε₀ = 1，必定存在某个对应的 δ > 0。  
    现在我们不管这个 δ 是多大，直接在 (0, 1) 内选取两个特殊的点列：  
    令 **xₙ = 1 / n**，令 **yₙ = 1 / (2n)**（其中 n 是充分大的正整数）。
  * **第三步：验证自变量靠近，函数值远离**  
    1. 自变量距离：|xₙ - yₙ| = |1/n - 1/(2n)| = 1 / (2n)。只要 n 充分大，完全可以让 1 / (2n) < δ；  
    2. 函数值差值：|f(xₙ) - f(yₙ)| = |n - 2n| = n。  
       只要 n ≥ 1，恒有 |f(xₙ) - f(yₙ)| = n ≥ 1 = ε₀。
  * **第四步：引出逻辑荒谬**  
    这说明无论 δ 多么微小，只要取足够大的 n，就能在距离小于 δ 的范围内找到函数值差大于等于 1 的两个点。  
    这与一致连续的定义直接矛盾！  
    故 f(x) = 1/x 在 (0, 1) 上绝非一致连续。证毕。

#### 避坑指南
* 构造点列 xₙ, yₙ 时，两点都必须严格落在原函数的**定义域内部**。例如在 (0, 1) 区间，不能取 xₙ = 0。

## 第二梯队：T1 核心高频

### 5. Taylor 展开与局部阶数估计法

* **使用频度**：82%（高阶导数估计、精细不等式主力）
* **核心主场**：含有高阶导数 f''(x) 或 f⁽ⁿ⁾(x) 的不等式证明、未定式极限的渐近展开。

#### 大白话通俗理解
> **“高精度显微镜与剥洋葱”**：  
> 如果一个函数具有多阶导数，那它在局部就可以被近似看作一个多项式加上一点点余项。你要求估计一次导数 f'(x)，只要在 x 前后各走一步（比如踩在 x + h 和 x - h 两个脚印上），把函数展开到二次方带拉格朗日余项。把两个式子一减，二次项直接对消，一次导数 f'(x) 就被孤立出来了，剩下的一览无余。

#### 严密数学描述
在点 x 处，对增量 h 展开到 2 阶（带 Lagrange 余项）：  
f(x + h) = f(x) + f'(x)·h + (1/2) f''(ξ₁) · h²（ξ₁ 在 x 与 x + h 之间）  
将 f'(x) 解出：  
f'(x) = [f(x + h) - f(x)] / h - (1/2) f''(ξ₁) · h  
利用绝对值三角不等式放大，最后选取使上界最小的最佳步长 h。

#### 经典实战例题与逐步拆解
* **题目**：设 f(x) 在 ℝ 上二阶可导，且对所有 x ∈ ℝ，均有 |f(x)| ≤ M₀，|f''(x)| ≤ M₂（M₀, M₂ 为常数）。证明：对所有 x ∈ ℝ，恒有 |f'(x)| ≤ 2√(M₀ · M₂)。
* **拆解证明**：
  * **第一步：在 x 处对任意 h > 0 进行 Taylor 展开**  
    f(x + h) = f(x) + f'(x)h + (1/2)f''(ξ)h²。
  * **第二步：变形分离出 f'(x)**  
    f'(x) · h = f(x + h) - f(x) - (1/2)f''(ξ)h²。  
    两边除以 h：  
    f'(x) = [f(x + h) - f(x)] / h - (1/2)f''(ξ)h。
  * **第三步：三角不等式放大**  
    |f'(x)| ≤ [|f(x + h)| + |f(x)|] / h + (1/2)|f''(ξ)|h  
    ≤ 2M₀ / h + (1/2)M₂ · h。  
    注意：此不等式对**任意正数 h > 0** 均成立！
  * **第四步：利用均值不等式求极小值（选最佳步长）**  
    令 g(h) = 2M₀ / h + (M₂ / 2)h。  
    由均值不等式，当 2M₀ / h = (M₂ / 2)h 时，即 h = 2√(M₀ / M₂) 时取得最小值：  
    |f'(x)| ≤ 2 · √[ (2M₀ / h) · ( (M₂ / 2)h ) ] = 2 · √(M₀ · M₂)。  
    证毕。

#### 避坑指南
* 展开的阶数必须与已知条件中出现的最高阶导数匹配。若题目只给了二阶导数信息，切勿写 Peano 余项 o(h²)，因为 Peano 余项只代表局部趋势，无法全局估计常数上界，必须写 Lagrange 余项 (1/2)f''(ξ)h²。

### 6. Weierstrass M 判别法（优级数法）

* **使用频度**：78%（函数项级数与反常积分一致收敛第一准则）
* **核心主场**：证明 ∑ uₙ(x) 或 ∫ f(x, t) dt 在某个区间上一维或多维一致收敛。

#### 大白话通俗理解
> **“大哥罩着小弟”**：  
> 每一个带自变量的函数项 uₙ(x) 就像一个不老实的小孩，到处乱动。  
> 如果你能给每个小孩都找一个强壮的常数“大哥” Mₙ，把小孩彻底压制住（对区间内所有的 x，恒有 |uₙ(x)| ≤ Mₙ）。  
> 只要这些常数大哥们组成的纯数字级数 ∑ Mₙ 能够收敛，那这帮乱蹦乱跳的小孩加在一起，就绝对不可能翻天，整个级数必定妥妥地一致收敛。

#### 严密数学描述
设函数项级数 ∑_{n=1}^∞ uₙ(x) 定义在区间 I 上。  
1. 寻找与 x 无关的正项常数序列 {Mₙ}，使得对所有 x ∈ I，所有 n ∈ ℕ，均有：**|uₙ(x)| ≤ Mₙ**；  
2. 验证正项级数 **∑_{n=1}^∞ Mₙ 收敛**；  
3. 则由 Weierstrass 判别法，原级数 ∑_{n=1}^∞ uₙ(x) 在区间 I 上绝对且一致收敛。

#### 经典实战例题与逐步拆解
* **题目**：证明函数项级数 ∑_{n=1}^∞ sin(nx) / (n² + x⁴) 在整个实数轴 ℝ 上一致收敛。
* **拆解证明**：
  * **第一步：寻找不依赖于 x 的绝对值上界**  
    对任意 x ∈ ℝ，分子的正弦函数恒有 |sin(nx)| ≤ 1。  
    分母由于 x⁴ ≥ 0，显然有 n² + x⁴ ≥ n²。  
    因此，对任意 x ∈ ℝ：  
    |uₙ(x)| = |sin(nx) / (n² + x⁴)| ≤ 1 / n²。
  * **第二步：确立常数级数**  
    令常数 Mₙ = 1 / n²。
  * **第三步：验证常数级数收敛性**  
    数项级数 ∑_{n=1}^∞ (1 / n²) 是 p = 2 的 p-级数，显然收敛。
  * **第四步：得出结论**  
    由 Weierstrass M-判别法，原级数在 ℝ 上一致收敛。证毕。

#### 避坑指南
* M 判别法是一致收敛的**充分非必要条件**。如果 M 判别法失效（比如级数是条件收敛的，如 ∑ (-1)ⁿ / (n + x)），并不代表它不一致收敛，此时应迅速切换到 Abel 判别法或 Dirichlet 判别法。

### 7. Stolz-Cesàro 定理（离散版洛必达法则）

* **使用频度**：70%（数列极限求值/证明大招）
* **核心主场**：计算形如 lim (aₙ / bₙ) 的未定式，特别是分母严格单调递增趋向于 +∞（即 “*/+∞” 型）或 “0/0” 型。

#### 大白话通俗理解
> **“看增量决定总量”**：  
> 如果两个人在长跑，只要最后每一秒钟两人增加的距离比值趋向于一个定值 L，那么他们跑过的总路程比值也必然会趋向于 L。通过用前后两项作差（离散求导），往往能瞬间把极其复杂的累加和化简为初等式。

#### 严密数学描述
若数列 {bₙ} 严格单调递增，且 lim_{n→∞} bₙ = +∞。  
若极限 **lim_{n→∞} (aₙ - aₙ₋₁) / (bₙ - bₙ₋₁) = L**（L 可为有限数或 ±∞），  
则原极限必存在，且 **lim_{n→∞} (aₙ / bₙ) = L**。

#### 经典实战例题与逐步拆解
* **题目**：求极限 lim_{n→∞} (1³ + 2³ + ... + n³) / n⁴。
* **拆解证明**：
  * **第一步：检验 Stolz 定理适用条件**  
    设 aₙ = 1³ + 2³ + ... + n³，bₙ = n⁴。  
    显然 {bₙ} 是严格单调递增的数列，且 lim_{n→∞} bₙ = +∞，符合 */+∞ 型条件。
  * **第二步：计算差分比值**  
    aₙ - aₙ₋₁ = n³。  
    bₙ - bₙ₋₁ = n⁴ - (n - 1)⁴ = 4n³ - 6n² + 4n - 1。
  * **第三步：求差分后的极限**  
    lim_{n→∞} (aₙ - aₙ₋₁) / (bₙ - bₙ₋₁) = lim_{n→∞} n³ / (4n³ - 6n² + 4n - 1)。  
    分子分母同除以 n³：  
    = lim_{n→∞} 1 / (4 - 6/n + 4/n² - 1/n³) = 1 / 4。
  * **第四步：得出原极限**  
    由 Stolz-Cesàro 定理，原极限 lim_{n→∞} (aₙ / bₙ) = 1/4。

#### 避坑指南
* 严禁在分母非单调、或者分母不趋向于正无穷的情况下滥用。此外，差分极限不存在（若振荡）时，不能反推原极限不存在。

### 8. 凸性切线放缩与基本不等式法

* **使用频度**：65%（不等式压轴利器）
* **核心主场**：证明各类解析不等式、加权平均、积分不等式。

#### 大白话通俗理解
> **“悬空铁锅法则”**：  
> 一个凸函数（二阶导大于 0）的形状就像一口向上的铁锅。你在铁锅的任何一个点贴一条切线，整口大铁锅全部悬空在切线的上方！因此，“函数本身永远大于等于它的切线方程”。许多惊艳的不等式，本质上就是挑了一个绝妙的切点画了一条切线。

#### 严密数学描述
若 f(x) 在区间上二阶导数 f''(x) ≥ 0（凸函数），则对该区间内的任意点 x₀，其切线为切线下界：  
**f(x) ≥ f(x₀) + f'(x₀)(x - x₀)**  
* 黄金切线不等式 1：考虑下凸函数 f(t) = -ln(t)，在 t = 1 处作切线，立刻导出 **ln(t) ≤ t - 1**（当且仅当 t = 1 时取等号）。  
* 黄金切线不等式 2：考虑下凸函数 f(t) = eᵗ，在 t = 0 处作切线，立刻导出 **eᵗ ≥ 1 + t**。

#### 经典实战例题与逐步拆解
* **题目**：利用凸性切线不等式证明算术-几何均值不等式：对任意正数 a, b，均有 (a + b)/2 ≥ √(ab)。
* **拆解证明**：
  * **第一步：请出黄金切线不等式**  
    由于 ln(x) 在 (0, +∞) 内是严格凹函数（二阶导 -1/x² < 0），其图像永远在切线下方。  
    在 x = 1 处的切线给出：**ln(t) ≤ t - 1**，即 **t ≥ 1 + ln(t)**。
  * **第二步：选定巧夺天工的代换**  
    令算术平均 A = (a + b)/2。  
    分别将 t₁ = a / A 和 t₂ = b / A 代入上述切线不等式：  
    a / A ≥ 1 + ln(a / A)  
    b / A ≥ 1 + ln(b / A)
  * **第三步：两式相加**  
    (a + b) / A ≥ 2 + ln(a / A) + ln(b / A)。  
    因为 A = (a + b)/2，所以左边 (a + b) / A = 2。  
    不等式变为：  
    2 ≥ 2 + ln[ (a · b) / A² ]。  
    两边减去 2：  
    0 ≥ ln[ (a · b) / A² ] ⇒ (a · b) / A² ≤ 1 ⇒ A² ≥ ab。  
    两边开平方即得：(a + b)/2 ≥ √(ab)。证毕。

### 9. 零点存在定理与区间二分法

* **使用频度**：55%（连续函数性质题必考）
* **核心主场**：证明高次代数方程、超越方程、不动点 f(x) = x 的根的存在性。

#### 大白话通俗理解
> **“无断流跨河必踩水”**：  
> 一条河左岸在水面以上（f(a) > 0），右岸在水面以下（f(b) < 0）。只要脚下的路是连续不断的，你从左岸走到右岸，就必须而且必定踩到水面刚好为零的点（零点存在）。如果想精确抓出这个点，每次都挑正中间一分为二，步步紧逼。

#### 严密数学描述
若 f(x) 在闭区间 [a, b] 上连续，且端点异号：**f(a) · f(b) < 0**。  
则必存在至少一个中值点 **ξ ∈ (a, b)，使得 f(ξ) = 0**。

#### 经典实战例题与逐步拆解
* **题目**：设 f(x) 在 [0, 1] 上连续，且其值域落在 [0, 1] 内（即对所有 x ∈ [0, 1]，0 ≤ f(x) ≤ 1）。证明：必存在不动点 ξ ∈ [0, 1]，使得 f(ξ) = ξ。
* **拆解证明**：
  * **第一步：构造辅助函数（将等式化为零点）**  
    待证式为 f(ξ) - ξ = 0。令 **g(x) = f(x) - x**。
  * **第二步：验证连续性与端点符号**  
    因为 f(x) 连续，x 连续，故 g(x) 在 [0, 1] 上连续。  
    考察两个端点：  
    1. 当 x = 0 时，g(0) = f(0) - 0 = f(0)。因为 f(0) ∈ [0, 1]，所以 g(0) ≥ 0；  
    2. 当 x = 1 时，g(1) = f(1) - 1。因为 f(1) ∈ [0, 1]，所以 g(1) ≤ 0。
  * **第三步：分类闭环**  
    * 若 g(0) = 0，则 ξ = 0 即为所求；  
    * 若 g(1) = 0，则 ξ = 1 即为所求；  
    * 若 g(0) > 0 且 g(1) < 0，则 g(x) 在 [0, 1] 端点异号。  
    由零点存在定理，必存在 ξ ∈ (0, 1) 使得 g(ξ) = 0，即 f(ξ) = ξ。  
    综合上述，必存在 ξ ∈ [0, 1] 满足 f(ξ) = ξ。证毕。

### 10. Abel 分部求和变换（Dirichlet / Abel 判别）

* **使用频度**：45%（条件收敛级数、Fourier 级数压轴必备）
* **核心主场**：证明带震荡因子的级数 ∑ aₙbₙ 或反常积分的敛散性。

#### 大白话通俗理解
> **“离散版的移花接木”**：  
> 两个数列乘在一起求和，一个在上蹿下跳震荡（如 sin(nx) 或 (-1)ⁿ），另一个在单调衰减。直接算会累死。  
> Abel 变换的妙处在于：把震荡的那个数列先做前 n 项累加（部分和），只要它的累加和始终被关在一个盒子里（有界），我们把求和的压力转移给衰减的项做差分（前后相减）。由于差分项是同号的，级数就被强行变成了绝对收敛，瞬间驯服！

#### 严密数学描述
令 Aₙ = ∑_{k=1}ⁿ aₖ，规定 A₀ = 0。则对任意数列 {bₙ}，恒有**分部求和恒等式**：  
**∑_{k=1}ⁿ aₖ bₖ = Aₙ bₙ - ∑_{k=1}^{n-1} Aₖ (bₖ₊₁ - bₖ)**  
由此诞生两大经典判别法：
* **Dirichlet 判别法**：若 Aₙ = ∑ aₖ 的部分和序列有界，且 bₙ 单调趋于 0，则 ∑ aₙbₙ 收敛。
* **Abel 判别法**：若 ∑ aₙ 收敛，且 bₙ 单调有界，则 ∑ aₙbₙ 收敛。

#### 经典实战例题与逐步拆解
* **题目**：证明级数 ∑_{n=1}^∞ sin(nx) / n 当 x ≠ 2kπ（k ∈ ℤ）时收敛。
* **拆解证明**：
  * **第一步：拆分为两项乘积**  
    设 aₙ = sin(nx)，bₙ = 1 / n。
  * **第二步：验证 bₙ 的单调衰减性**  
    显然 bₙ = 1/n > 0 单调递减，且 lim_{n→∞} bₙ = 0。
  * **第三步：证明 aₙ 的部分和序列有界**  
    考察三角级数和：Aₙ(x) = ∑_{k=1}ⁿ sin(kx)。  
    利用三角积化和差公式乘以 2sin(x/2)：  
    2sin(x/2) · Aₙ(x) = ∑_{k=1}ⁿ 2sin(kx)sin(x/2) = ∑_{k=1}ⁿ [cos(k - 1/2)x - cos(k + 1/2)x]。  
    中间项全部裂项抵消，得到：  
    2sin(x/2) · Aₙ(x) = cos(x/2) - cos(n + 1/2)x。  
    两边取绝对值放大：  
    |Aₙ(x)| = |cos(x/2) - cos(n + 1/2)x| / |2sin(x/2)| ≤ 2 / (2|sin(x/2)|) = 1 / |sin(x/2)|。  
    因为 x ≠ 2kπ，sin(x/2) ≠ 0，故对任意固定的 x，|Aₙ(x)| ≤ 1 / |sin(x/2)|（与 n 无关的有限界）。
  * **第四步：应用定理下结论**  
    由 Dirichlet 判别法，原级数 ∑ sin(nx)/n 收敛。证毕。

### 11. Heine 归结原则（双点列否证极限）

* **使用频度**：42%（证明极限不存在的终极武器）
* **核心主场**：证明带有高频震荡特性的函数（如 sin(1/x)）在奇点处极限不存在。

#### 大白话通俗理解
> **“条条大路通罗马的反面”**：  
> 什么是函数极限存在？就是不管你沿着哪条小路走向目标点，风景（函数值）都必须一致。  
> 那么怎么证明极限不存在？最省力的办法就是找**两条不同的小路（两个不同的点列 xₙ 和 yₙ）**，虽然两组点最后都走到了同一个目的地，但是沿着第一条路走看到的风景是 1，沿着第二条路走看到的风景是 0。当场揭穿谎言。

#### 严密数学描述
**归结原则**：lim_{x → x₀} f(x) = A 的充要条件是：对任意满足 xₙ ≠ x₀ 且 lim_{n→∞} xₙ = x₀ 的数列 {xₙ}，都有 lim_{n→∞} f(xₙ) = A。  
* **证否套路**：只需找到两个数列 {xₙ} 和 {yₙ}，使得：  
  lim xₙ = x₀ 且 lim yₙ = x₀，但 **lim f(xₙ) ≠ lim f(yₙ)**。

#### 经典实战例题与逐步拆解
* **题目**：证明当 x → 0 时，极限 lim_{x → 0} sin(1 / x) 不存在。
* **拆解证明**：
  * **第一步：挑选让函数值恒为 0 的点列**  
    令 1 / xₙ = nπ ⇒ **xₙ = 1 / (nπ)**（n = 1, 2, ...）。  
    当 n → ∞ 时，显然 xₙ → 0。  
    此时函数值数列为：f(xₙ) = sin(nπ) = 0。  
    故 lim_{n→∞} f(xₙ) = 0。
  * **第二步：挑选让函数值恒为 1 的点列**  
    令 1 / yₙ = 2nπ + π/2 ⇒ **yₙ = 1 / (2nπ + π/2)**（n = 1, 2, ...）。  
    当 n → ∞ 时，同样有 yₙ → 0。  
    此时函数值数列为：f(yₙ) = sin(2nπ + π/2) = 1。  
    故 lim_{n→∞} f(yₙ) = 1。
  * **第三步：依据 Heine 原理定性**  
    存在两个同趋于 0 的数列 {xₙ} 与 {yₙ}，其函数值极限不相等（0 ≠ 1）。  
    由 Heine 归结原则，lim_{x → 0} sin(1/x) 不存在。证毕。

### 12. Bolzano-Weierstrass 致密性定理（子列紧性法）

* **使用频度**：38%（抽象理论大题、拓扑性质反证法核心）
* **核心主场**：证明闭区间上连续函数的有界性、最大最小值存在性。

#### 大白话通俗理解
> **“闹市区必有人扎堆”**：  
> 在一个有限大小的院子里（有界集），如果塞进去无穷多个人（无穷数列），空间就那么大，不可能所有人之间都隔得老远，必然至少有一个角落挤满了人。也就是说，这群人里肯定能挑出一排人（子序列），他们正整齐划一地走向某个拥挤点（收敛子列）。

#### 严密数学描述
**致密性定理**：任何**有界数列**必至少包含一个**收敛子序列**。  
* 反证法连击套路：假设函数 f 在闭区间 [a, b] 上无界 ⇒ 对每个正整数 n，都能找到一个点 xₙ 使得 |f(xₙ)| > n ⇒ 产生有界点列 {xₙ} ⊂ [a, b] ⇒ 提取收敛子列 xₙₖ → x₀ ∈ [a, b] ⇒ 连续性保证 f(xₙₖ) → f(x₀)（有限常数）⇒ 与 |f(xₙₖ)| > nₖ → ∞ 瞬间撞车！

#### 经典实战例题与逐步拆解
* **题目**：设 f(x) 在闭区间 [a, b] 上连续。证明：f(x) 在 [a, b] 上必有界。
* **拆解证明**：
  * **第一步：反设结论不成立**  
    反设 f(x) 在 [a, b] 上无界。
  * **第二步：构造发散点列**  
    对每一个正整数 n = 1, 2, 3, ...，必存在某个 xₙ ∈ [a, b]，使得：  
    |f(xₙ)| > n。
  * **第三步：应用 Bolzano-Weierstrass 抽取子列**  
    由于所有点 xₙ 都落在闭区间 [a, b] 内，数列 {xₙ} 显然是有界数列。  
    由致密性定理，必存在一个收敛子序列 {xₙₖ}，使得：  
    lim_{k→∞} xₙₖ = x₀。  
    又因 a ≤ xₙₖ ≤ b，由极限的保序性，极限点 x₀ 必落在闭区间内：x₀ ∈ [a, b]。
  * **第四步：利用连续性产生矛盾**  
    因为 f(x) 在 [a, b] 上连续，所以它在 x₀ 处也连续。由连续定义：  
    lim_{k→∞} f(xₙₖ) = f(x₀)（一个有限的固定实数）。  
    然而根据第二步的构造，恒有 |f(xₙₖ)| > nₖ。  
    当 k → ∞ 时，nₖ → ∞，推导出 |f(xₙₖ)| → +∞。  
    有限实数与正无穷大矛盾！  
    因此，反设不成立，f(x) 在 [a, b] 上必定有界。证毕。

### 13. 第二积分中值定理（提取单调因子）

* **使用频度**：32%（强振荡反常积分的绝对救星）
* **核心主场**：证明像 Dirichlet 积分 ∫₀^∞ sin(x)/x dx 这样条件收敛的积分。

#### 大白话通俗理解
> **“把衰减的大山拽出积分号”**：  
> 积分号里面如果有一个衰减很慢的单调函数（比如 1/x）和一个正负快速狂跳的周期函数（如 sin(x)），乘在一起很难算。第二积分中值定理允许我们像施展定身术一样，把单调衰减函数在端点的值强行拔出积分号，里面只剩下那个规整的跳动函数在某个截断区间 [a, ξ] 上的积分。跳动函数的积分是天然有界的，局面瞬间受控！

#### 严密数学描述
设 g(x) 在 [a, b] 上单调。
* **Bonnet 公式（单调非负减）**：若 g(x) 单调递减且 g(x) ≥ 0，则存在 ξ ∈ [a, b]，使得：  
  **∫ₐᵇ f(x)g(x) dx = g(a⁺) · ∫ₐ^ξ f(x) dx**
* **Du Bois-Reymond 公式**：若 g(x) 仅单调，则存在 ξ ∈ [a, b]，使得：  
  **∫ₐᵇ f(x)g(x) dx = g(a) · ∫ₐ^ξ f(x) dx + g(b) · ∫_ξᵇ f(x) dx**

#### 经典实战例题与逐步拆解
* **题目**：证明反常积分 ∫₁^∞ sin(x) / x dx 收敛。
* **拆解证明**：
  * **第一步：转化为 Cauchy 收敛准则**  
    要证反常积分收敛，等价于证明：对任意 ε > 0，存在 A₀ > 1，当 A₂ > A₁ > A₀ 时，恒有：  
    |∫_{A₁}^{A₂} sin(x) / x dx| < ε。
  * **第二步：使用第二积分中值定理抽离 1/x**  
    在区间 [A₁, A₂] 上，考察函数 g(x) = 1/x 与 f(x) = sin(x)。  
    显然 g(x) = 1/x 在该区间上单调递减且恒为正（g(x) ≥ 0）。  
    由第二积分中值定理（Bonnet 公式），必存在中值 ξ ∈ [A₁, A₂]，使得：  
    ∫_{A₁}^{A₂} sin(x) / x dx = (1 / A₁) · ∫_{A₁}^ξ sin(x) dx。
  * **第三步：内部积分直接积分并放缩**  
    ∫_{A₁}^ξ sin(x) dx = -cos(x) |_{A₁}^ξ = cos(A₁) - cos(ξ)。  
    两边取绝对值：  
    |∫_{A₁}^{A₂} sin(x) / x dx| = (1 / A₁) · |cos(A₁) - cos(ξ)| ≤ (1 / A₁) · (1 + 1) = 2 / A₁。
  * **第四步：控制精度**  
    任取 ε > 0，只需令 A₀ = 2 / ε。  
    当 A₂ > A₁ > A₀ 时，恒有 |∫_{A₁}^{A₂} sin(x)/x dx| ≤ 2 / A₁ < 2 / A₀ = ε。  
    由 Cauchy 收敛准则，原反常积分收敛。证毕。

### 14. 含参变量积分求导法（Feynman 积分技巧）

* **使用频度**：28%（定积分计算与证明王炸技巧）
* **核心主场**：计算无法用初等函数求原函数的高难度反常积分（如泊松积分、狄利克雷积分）。

#### 大白话通俗理解
> **“降维偷家与借刀杀人”**：  
> 原积分直接算根本积不出来（比如分母有个讨厌的自变量 x 消不掉）。我们给被积函数挂一个虚拟参数 t（变成含参变量积分 I(t)）。然后利用导数与积分交换次序，在积分号里面先对这个参数 t 求导。求导往往能奇迹般地把分母那个恶心的 x 瞬间削掉！积分迎刃而解之后，再对 t 积分回去，常数用特值一卡，原积分束手就擒。

#### 严密数学描述
设 I(t) = ∫ₐᵇ f(x, t) dx。在满足被积函数及其偏导连续、反常积分一致收敛的前提下：  
**I'(t) = d/dt [ ∫ₐᵇ f(x, t) dx ] = ∫ₐᵇ [ ∂f(x, t) / ∂t ] dx**

#### 经典实战例题与逐步拆解
* **题目**：计算狄利克雷积分 I = ∫₀^∞ sin(x) / x dx。
* **拆解证明**：
  * **第一步：挂载阻尼收敛参数 t**  
    引入辅助参数 t ≥ 0，构造含参变量反常积分：  
    **I(t) = ∫₀^∞ e^{-tx} · (sin(x) / x) dx**。  
    注意：当 t = 0 时，I(0) 就是我们要求的原积分 I；当 t → +∞ 时，由于 e^{-tx} 极速压制，lim_{t→+∞} I(t) = 0。
  * **第二步：积分号下求导**  
    对参数 t 求导（因 t > 0 时满足一致收敛条件可交换顺序）：  
    I'(t) = ∫₀^∞ ∂/∂t [ e^{-tx} (sin(x)/x) ] dx = ∫₀^∞ -x · e^{-tx} · (sin(x)/x) dx  
    = - ∫₀^∞ e^{-tx} sin(x) dx。  
    看！恶心的分母 x 被完美干掉了！
  * **第三步：分部积分计算初等积分**  
    利用两次分部积分（或微积分经典公式）：  
    ∫ e^{-tx} sin(x) dx = e^{-tx} [ -t sin(x) - cos(x) ] / (1 + t²)。  
    代入端点 0 到 +∞：  
    I'(t) = - [ 0 - (-1 / (1 + t²)) ] = **- 1 / (1 + t²)**。
  * **第四步：积分回弹定常数**  
    对 I'(t) 积分还原：  
    I(t) = ∫ -1 / (1 + t²) dt = -arctan(t) + C。  
    令 t → +∞：0 = -π/2 + C ⇒ **C = π/2**。  
    所以 I(t) = π/2 - arctan(t)。  
    最后令 t = 0，代入所求：  
    I = I(0) = π/2 - arctan(0) = **π/2**。计算完毕。

### 15. Heine-Borel 有限覆盖定理（局部拓广法）

* **使用频度**：18%（实数完备性压轴大题）
* **核心主场**：紧集理论、闭区间上性质由局部向整体推广的严格证明。

#### 大白话通俗理解
> **“无限把小遮阳伞中挑出有限把”**：  
> 闭区间是一个非常“紧致牢固”的地块。假设在区间上的每一个点，你都撑开了一把小小的遮阳伞（每个点都有一个局部开邻域）。哪怕你撑开了千千万万、无穷无尽把伞（无限开覆盖），有限覆盖定理霸气地宣布：根本不需要那么多！我保证只需要从中挑选出屈指可数的几十把或几百把伞（有限子覆盖），就能严丝合缝地把整个闭区间全部罩住！这就把无限化为了有限。

#### 严密数学描述
若开区间族 {U_α} 覆盖了闭区间 [a, b]（即 [a, b] ⊂ ⋃_α U_α），则必定能从中挑选出**有限个**开区间 U_α₁, U_α₂, ..., U_αₘ，使得：  
**[a, b] ⊂ U_α₁ ∪ U_α₂ ∪ ... ∪ U_αₘ**。

#### 经典实战例题与逐步拆解
* **题目**：利用有限覆盖定理证明 Cantor 定理：若 f(x) 在闭区间 [a, b] 上连续，则 f(x) 在 [a, b] 上必一致连续。
* **拆解证明**：
  * **第一步：写出局部连续性并开伞**  
    任取 ε > 0。对 [a, b] 内的任意一点 x，由 f 在 x 处的连续性，存在一个与 x 相关的 δ(x) > 0，使得：  
    当 |t - x| < δ(x) 且 t ∈ [a, b] 时，恒有 |f(t) - f(x)| < ε / 2。  
    以每个点 x 为中心，以 **δ(x) / 2** 为半径作开区间：U_x = (x - δ(x)/2, x + δ(x)/2)。
  * **第二步：形成全区间的开覆盖**  
    显然，当 x 遍历 [a, b] 时，所有开区间的并集覆盖了闭区间：  
    [a, b] ⊂ ⋃_{x ∈ [a,b]} U_x。
  * **第三步：应用有限覆盖定理抽伞**  
    由 Heine-Borel 有限覆盖定理，必定存在有限个点 x₁, x₂, ..., xₘ，使得：  
    [a, b] ⊂ U_{x₁} ∪ U_{x₂} ∪ ... ∪ U_{xₘ}。
  * **第四步：取有限个步长的最小值（锁死全局 δ）**  
    令 **δ = min{ δ(x₁)/2, δ(x₂)/2, ..., δ(xₘ)/2 }**。注意：有限个数的最小值必定严格大于 0！
  * **第五步：验证全局一致连续**  
    对 [a, b] 内任意两点 x', x''，若 |x' - x''| < δ。  
    由于 x' 必定落在某个伞内，设 x' ∈ U_{xₖ}，即 |x' - xₖ| < δ(xₖ)/2。  
    那么根据三角不等式，x'' 距离这个伞的中心：  
    |x'' - xₖ| ≤ |x'' - x'| + |x' - xₖ| < δ + δ(xₖ)/2 ≤ δ(xₖ)/2 + δ(xₖ)/2 = δ(xₖ)。  
    看！x' 和 x'' 同时落在了 xₖ 的完整控制半径 δ(xₖ) 之内！  
    因此由第一步的连续性：  
    |f(x') - f(xₖ)| < ε/2，且 |f(x'') - f(xₖ)| < ε/2。  
    再次使用三角不等式拼合：  
    |f(x') - f(x'')| ≤ |f(x') - f(xₖ)| + |f(xₖ) - f(x'')| < ε/2 + ε/2 = ε。  
    这证明了与位置无关的全局 δ 存在，即 f(x) 一致连续。证毕。

### 16. 上下极限（lim sup / lim inf）夹逼法

* **使用频度**：16%（抽象级数、高级分析必备）
* **核心主场**：证明幂级数收敛半径（Cauchy-Hadamard 定理）、摆动数列的极限存在性。

#### 大白话通俗理解
> **“关门打狗 / 天花板和地板撞在一起”**：  
> 有些数列上蹿下跳，没有单调性，直接算极限无从下手。但任何有界数列，它的“波峰最高上界（上极限）”和“波谷最低下界（下极限）”是雷打不动绝对存在的。如果你能从左右两侧施加压力，证明最高波峰不超过 L，同时最低波谷不低于 L，那天花板和地板就会狠狠撞在同一水平线上，中间哪怕再怎么摆动的数列也只能被活活压平在 L 处！

#### 严密数学描述

* 下极限：lim inf_{n→∞} xₙ = lim_{n→∞} (inf_{k≥n} xₖ)；
* **极限定理**：**lim_{n→∞} xₙ = L ⇔ lim sup xₙ = lim inf xₙ = L**。

### 17. 压缩映射原理与不动点迭代法

* **使用频度**：14%（隐函数定理微观证明、微分方程存在唯一性）
* **核心主场**：证明方程 f(x) = x 根的存在唯一性、级数逼近。

#### 大白话通俗理解
> **“弹性皮筋自动缩心”**：  
> 想象一张弹性橡皮膜，一个变换把它拉伸平移后，任意两点之间的距离都按一个小于 1 的固定比例 k 缩短（收缩映射）。只要你把这个变换反复迭代（抓着任意一个点不停地映射），所有点最终都会像漩涡一样，被吸到唯一一个原地不动的“靶心”（不动点）。

#### 严密数学描述
在完备度量空间（如实数闭区间）上，若映射 T 满足：存在常数 0 < k < 1，使得对所有 x, y，均有：  
**|T(x) - T(y)| ≤ k · |x - y|**  
则 T 在该集合上有且仅有唯一不动点 x* 满足 **T(x*) = x***。

#### 经典实战例题与逐步拆解
* **题目**：证明方程 x = cos(x) 在区间 [0, 1] 内有且仅有一个实根。
* **拆解证明**：
  * **第一步：建立映射并验证自映射条件**  
    设 T(x) = cos(x)。  
    当 x ∈ [0, 1] 时，因 0 ≤ cos(1) ≤ cos(x) ≤ cos(0) = 1，故 T([0, 1]) ⊆ [0, 1]（映射后还在 [0, 1] 内部）。
  * **第二步：利用中值定理验证压缩性**  
    对 [0, 1] 内任意两点 x, y，由 Lagrange 中值定理：  
    |T(x) - T(y)| = |cos(x) - cos(y)| = |-sin(ξ)| · |x - y| = sin(ξ) · |x - y|（ξ 介于 x, y 之间）。  
    因为 ξ ∈ (0, 1)，正弦函数在 (0, 1) 单调递增，故：  
    sin(ξ) ≤ sin(1)。  
    已知 1 弧度约 57.3°，sin(1) ≈ 0.8415 < 1。  
    令常数 k = sin(1) < 1，则对所有 x, y ∈ [0, 1]，恒有：  
    |T(x) - T(y)| ≤ k · |x - y|。
  * **第三步：应用不动点定理下结论**  
    根据 Banach 压缩映射原理，T(x) 在 [0, 1] 上有且仅有唯一的不动点 x*，即 x* = cos(x*)。  
    原方程在 [0, 1] 内存在且仅存在唯一实根。证毕。

### 21. Darboux 导数介值定理

* **使用频度**：6%（导函数病态间断点判断）

#### 大白话通俗理解
> **“导数不能瞬移闪现”**：  
> 很多人以为“只有连续函数才满足介值定理”。大错特错！导函数 f'(x) 即使充满了密密麻麻的振荡间断点（不连续），它也**绝对遵守介值定理**！如果导数昨天是 1，今天是 3，那它在中间某一瞬间的导数值必然踩过 2。它绝不能从 1 直接跳跃跳过 2 到达 3。所以导函数绝不可能有第一类间断点。

#### 严密数学描述

| **反常积分被积函数快速正负振荡** | **第二积分中值定理**提单调因子 | Dirichlet 判别法 |
| **闭区间连续函数证明有界/最值** | **反证法 + Bolzano-Weierstrass 致密性** | Heine-Borel 有限覆盖定理 |
| **复杂积分且被积函数含分母多项式** | **含参变量积分求导法**（Feynman 技巧） | 留数定理（复分析交叉） |

### 2. 考场答题逻辑自查清单
1. **δ 独立性**：你的 δ 里面有没有偷带未知自变量 x？（有则必错，δ 只能包含 ε 与 x₀）
2. **闭区间与开区间**：使用最大最小值定理、Cantor 定理时，前提集合是否为**闭区间**？开区间需警惕端点极限。
3. **极限先决条件**：是否在未证明数列收敛前，就擅自令 lim xₙ = L 代入求解？（严惩漏洞）
4. **子列属于域**：构造抓现行点列 xₙ 时，点列各项是否严格落在**原定义域内部**？
5. **常数级数判敛**：使用 M 判别法时，放缩出的常数级数 ∑ Mₙ 是否真的收敛？（切勿放缩过头）
