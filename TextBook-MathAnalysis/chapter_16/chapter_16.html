第十六章 Fourier 级数

§1 函数的 Fourier 级数展开

周期为 $2\pi$ 的函数的 Fourier 展开

古往今来，从 Archimedes 开始的众多大数学家，一直在孜孜不倦地寻找用简单函数较好地近似代替复杂函数的途径——除了理论上的需要之外，它对实际应用领域的意义更是不可估量．但在微积分发明之前，这个问题一直没能获得本质上的突破．

人们最熟悉的简单函数无非两类：幂函数和三角函数．英国数学家 Taylor 在 18 世纪初找到了用幂函数的（无限）线性组合表示一般函数 $f(x)$ 的方法，即通过 Taylor 展开将函数化成幂级数形式

$$f(x) = \sum_{n=0}^\infty \frac{f^{(n)}(x_0)}{n!}(x-x_0)^n,$$

经过理论上的完善之后，它很快成为了微分学（乃至整个函数论）的重要工具之一．这方面内容已在前面有关章节中作了介绍．

但是，函数的 Taylor 展开在应用中有一定的局限性．首先我们在实际问题中总是（也只能）使用 Taylor 级数的部分和，即 $f(x)$ 的 $n$ 次 Taylor 多项式

$$T_n(x) = \sum_{k=0}^n \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k$$

来近似地代替函数 $f(x)$，这时候它要求 $f(x)$ 有至少 $n$ 阶的导数，这一条件对许多实际问题来说是过于苛刻的（特别是在发现了许多不可导甚至不连续的重要函数之后）；同时，一般来说 Taylor 多项式仅在点 $x_0$ 附近与 $f(x)$ 吻合得较为理想，也就是说，它只有局部性质．为此有必要寻找函数的新的级数展开方法．

形如

$$\frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$$

的函数项级数称为三角级数，其中 $a_0$，$a_n$ 和 $b_n$（$n = 1, 2, \ldots$）为常数．

19 世纪初，法国数学家和工程师 Fourier 在研究热传导问题时，找到了在有限区间上用三角级数表示一般函数 $f(x)$ 的方法，即把 $f(x)$ 展开成所谓的 Fourier 级数．

与 Taylor 展开相比，Fourier 展开对于 $f(x)$ 的要求要宽容得多，并且它的部分和在整个区间都与 $f(x)$ 吻合得较为理想．因此，Fourier 级数是比 Taylor 级数更有力、适用性更广的工具，它在声学、光学、热力学、电学等研究领域极有价值，在微分方程求解方面更是起着基本的作用．可以说，Fourier 级数理论在整个现代分析学中占有核心的地位．

本章只介绍有关 Fourier 级数的一些基本知识，大致包括三个方面：

  • 如何将一个给定的函数 $f(x)$ 展开为 Fourier 级数（称 Fourier 展开）；
  • Fourier 级数的收敛条件；
  • Fourier 级数的性质及某些相关问题．

以下我们总是设 $f(x)$ 在 $[-\pi, \pi]$ 上 Riemann 可积或在反常积分意义下绝对可积（方便起见，以下简称为"可积或绝对可积"），然后按 $f(x)$ 在 $[-\pi, \pi)$ 上的值周期延拓到 $(-\infty, +\infty)$，换句话说，$f(x)$ 是定义在整个实数范围上的以 $2\pi$ 为周期的周期函数．（本章中除非特别说明，我们总是如此假定，但在实际计算时，对 $f(x)$ 的延拓可以仅仅是观念上的．）

Fourier 展开的基础是三角函数的正交性．在例 7.3.17 中已证明了函数族 $1, \sin x, \cos x, \sin 2x, \cos 2x, \ldots, \sin nx, \cos nx, \ldots$ 是任意一个长度为 $2\pi$ 的区间上的正交函数列，即

$$\int_{-\pi}^\pi \cos mx\cos nx\,\mathrm{d}x = \int_{-\pi}^\pi \sin mx\sin nx\,\mathrm{d}x = \pi\delta_{m,n}, \quad m, n \in \mathbb{N}^*,$$ $$\int_{-\pi}^\pi \cos mx\cdot\sin nx\,\mathrm{d}x = 0, \quad m = 0, 1, 2, \ldots,\quad n \in \mathbb{N}^*,$$ $$\int_{-\pi}^\pi 1\cdot\cos mx\,\mathrm{d}x = 2\pi\delta_{m,0}, \quad m = 0, 1, 2, \ldots,$$

其中 $\delta_{m,n} = \begin{cases}1, & m = n, \\ 0, & m \ne n.\end{cases}$

下面我们先来讨论这样一个问题：假定 $f(x)$ 可以表示成如下形式的级数

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx),$$

也就是说假定等式右边的三角级数收敛于 $f(x)$，该如何来确定三角级数中的系数 $a_n$ 和 $b_n$？为了回答这一问题，我们将等式两边同乘以 $\cos mx$（$m = 0, 1, 2, 3, \ldots$），然后对等式两边在 $[-\pi, \pi]$ 上积分，假定等式右边的三角级数可以逐项积分，并利用上述三角函数的正交性，得

$$\int_{-\pi}^\pi f(x)\cos mx\,\mathrm{d}x = \frac{a_0}{2}\int_{-\pi}^\pi \cos mx\,\mathrm{d}x + \sum_{n=1}^\infty\left[a_n\int_{-\pi}^\pi\cos nx\cos mx\,\mathrm{d}x + b_n\int_{-\pi}^\pi\sin nx\cos mx\,\mathrm{d}x\right] = a_m\pi,$$

从而得到（将下标 $m$ 改写为 $n$）

$$a_n = \frac{1}{\pi}\int_{-\pi}^\pi f(x)\cos nx\,\mathrm{d}x, \quad n = 0, 1, 2, \ldots$$

将等式两边同乘以 $\sin mx$（$m = 1, 2, \ldots$）后在 $[-\pi, \pi]$ 上积分，同理可得到

$$b_n = \frac{1}{\pi}\int_{-\pi}^\pi f(x)\sin nx\,\mathrm{d}x, \quad n = 1, 2, \ldots$$

上面两式称为 Euler-Fourier 公式．注意我们将三角级数的常数项写成 $\dfrac{a_0}{2}$ 而不是 $c_0$，就是为了使系数 $a_n$（$n = 0, 1, 2, \ldots$）有上述统一的表达式．

反过来，设周期为 $2\pi$ 的函数 $f(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积，则利用 Euler-Fourier 公式就可求出系数 $a_n$，$b_n$，并记

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx).$$

右端的三角级数称为 $f(x)$ 的 Fourier 级数，相应的 $a_n$ 和 $b_n$ 称为 $f(x)$ 的 Fourier 系数．

要特别指出的是，目前在 $f(x)$ 和它的 Fourier 级数之间不能用等号而只能用"$\sim$"，因为我们不知道右端的三角级数是否收敛；即使收敛，也不知道它是否收敛到 $f(x)$ 本身．这些问题我们将在下一节讨论．

例 16.1.1

求 $f(x) = \begin{cases}-1, & x \in [-\pi, 0), \\ 1, & x \in [0, \pi)\end{cases}$ 的 Fourier 级数．

解

先计算 $f(x)$ 的 Fourier 系数．

$$a_0 = \frac{1}{\pi}\int_{-\pi}^\pi f(x)\,\mathrm{d}x = 0.$$

对 $n = 1, 2, \ldots$，

$$a_n = \frac{1}{\pi}\int_{-\pi}^\pi f(x)\cos nx\,\mathrm{d}x = \frac{1}{\pi}\int_0^\pi\cos nx\,\mathrm{d}x - \frac{1}{\pi}\int_{-\pi}^0\cos nx\,\mathrm{d}x = 0.$$ $$b_n = \frac{1}{\pi}\int_{-\pi}^\pi f(x)\sin nx\,\mathrm{d}x = \frac{2}{\pi}\int_0^\pi\sin nx\,\mathrm{d}x = \frac{2}{\pi}\cdot\frac{-\cos nx}{n}\Big|_0^\pi = \frac{2[1-(-1)^n]}{n\pi} = \begin{cases}\dfrac{4}{(2k-1)\pi}, & n = 2k-1, \\ 0, & n = 2k.\end{cases}$$

于是得到 $f(x)$ 的 Fourier 级数

$$f(x) \sim \sum_{n=1}^\infty \frac{(-1)^{n-1}+1}{n\pi}\cdot\frac{2}{\pi}\cdot 2\sin nx = \frac{4}{\pi}\left(\sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \cdots + \frac{\sin(2k-1)x}{2k-1} + \cdots\right).$$

$f(x)$ 的图形在电工学中称为方波（见图 16.1.1(a)），上式表明它可以由一系列的正弦波（即函数 $A\sin(\omega x + \varphi)$ 表示的图形）叠加来得到．但显然，当 $x = 0$ 和 $\pm\pi$ 时，右端级数的和为 $0$，不等于 $f(x)$ 的值 $\pm 1$．

图 16.1.1(b) 给出了在 $[-\pi, \pi]$ 上 $f(x)$ 的 Fourier 级数的前若干项之和的逼近情况，图中的 $S_n$ 表示

$$S_n(x) = \frac{a_0}{2} + \sum_{k=1}^n (a_k\cos kx + b_k\sin kx),$$

这就是 $f(x)$ 的 Fourier 级数的部分和．

正弦级数和余弦级数

由定积分的性质，若 $f(x)$ 是奇函数，那么显然有 $a_n = 0$，而

$$b_n = \frac{2}{\pi}\int_0^\pi f(x)\sin nx\,\mathrm{d}x, \quad n = 1, 2, \ldots$$

这时，相应的 Fourier 级数为

$$f(x) \sim \sum_{n=1}^\infty b_n\sin nx.$$

形如 $\sum_{n=1}^\infty b_n\sin nx$ 的三角级数称为正弦级数，如在例 16.1.1 中，令 $g(x) = f(x) - 1$（即 $f(x)$ 往下移动 $1$），则 $g(x)$ 是奇函数，从上面的结果看到，它的 Fourier 级数确为正弦级数．

同样，若 $f(x)$ 是偶函数，那么有 $b_n = 0$ 和

$$a_n = \frac{2}{\pi}\int_0^\pi f(x)\cos nx\,\mathrm{d}x, \quad n = 0, 1, 2, \ldots$$

相应的 Fourier 级数为

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty a_n\cos nx.$$

形如 $\dfrac{a_0}{2} + \sum_{n=1}^\infty a_n\cos nx$ 的三角级数称为余弦级数．

反过来，在实际问题中，出于某种特定的用途，也经常需要将一个函数展开成正弦级数或余弦级数．

例 16.1.2

将 $f(x) = x$（$x \in [0, \pi]$）分别展开为余弦级数和正弦级数．

解

先考虑余弦级数的情况．按理说，这时应先进行偶延拓，但这一步同样只需在观念上进行，因为只要按余弦级数的情况计算 Fourier 系数，所得的自然就是偶延拓后的函数 $f(x)$ 的 Fourier 级数．经计算得

$$a_0 = \frac{2}{\pi}\int_0^\pi x\,\mathrm{d}x = \pi.$$

而对 $n = 1, 2, \ldots$，有

$$a_n = \frac{2}{\pi}\int_0^\pi x\cos nx\,\mathrm{d}x = \frac{2}{\pi}\cdot\frac{x\sin nx}{n}\Big|_0^\pi - \frac{2}{n\pi}\int_0^\pi\sin nx\,\mathrm{d}x = \frac{2}{\pi}\cdot\frac{\cos nx}{n^2}\Big|_0^\pi = \frac{2[(-1)^n - 1]}{n^2\pi} = \begin{cases}0, & n = 2k, \\ -\dfrac{4}{(2k-1)^2\pi}, & n = 2k-1.\end{cases}$$

于是得到 $f(x)$ 的余弦级数

$$f(x) \sim \frac{\pi}{2} - \frac{4}{\pi}\left(\cos x + \frac{\cos 3x}{3^2} + \frac{\cos 5x}{5^2} + \cdots + \frac{\cos(2k-1)x}{(2k-1)^2} + \cdots\right).$$

这是由一系列的余弦波叠加出来的锯齿波（见图 16.1.2(a)），从图 16.1.2(b) 看出，其逼近情况相当好．

再看正弦级数的情况．对 $n = 1, 2, \ldots$，

$$b_n = \frac{2}{\pi}\int_0^\pi x\sin nx\,\mathrm{d}x = \frac{2}{\pi}\left(-\frac{x\cos nx}{n}\Big|_0^\pi + \frac{1}{n}\int_0^\pi\cos nx\,\mathrm{d}x\right) = \frac{2}{\pi}\cdot\frac{(-1)^{n+1}\pi}{n} = \frac{2(-1)^{n+1}}{n}.$$

于是得到 $f(x)$ 的正弦级数

$$f(x) \sim 2\sum_{n=1}^\infty \frac{(-1)^{n+1}}{n}\sin nx = 2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \cdots + \frac{(-1)^{n+1}\sin nx}{n} + \cdots\right).$$

它的几何意义是由一系列的正弦波叠加出来的三角波（见图 16.1.3(a)），其逼近情况见图 16.1.3(b)．与例 16.1.1 类似，它在 $x = \pm\pi$ 时的值是 $0$，与 $f(x)$ 的值不相等．

请注意，这两种级数的表达形式虽然大相径庭，但我们在下一节就会知道，若限制在 $[0, \pi)$ 上，它们的确表示同一个函数．

任意周期的函数的 Fourier 展开

如果 $f(x)$ 的周期为 $2T$，作变换 $x = \dfrac{T}{\pi}t$，则

$$\varphi(t) = f\!\left(\frac{T}{\pi}t\right)$$

是定义在 $(-\infty, +\infty)$ 上的周期为 $2\pi$ 的函数．利用前面的结果，有

$$\varphi(t) \sim \frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nt + b_n\sin nt).$$

代回变量，就有

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty\left(a_n\cos\frac{n\pi}{T}x + b_n\sin\frac{n\pi}{T}x\right),$$

相应的 Fourier 系数为

$$a_n = \frac{1}{T}\int_{-T}^T f(x)\cos\frac{n\pi}{T}x\,\mathrm{d}x, \quad n = 0, 1, 2, \ldots,$$ $$b_n = \frac{1}{T}\int_{-T}^T f(x)\sin\frac{n\pi}{T}x\,\mathrm{d}x, \quad n = 1, 2, \ldots$$
例 16.1.3

求 $f(x) = \begin{cases}0, & x \in [-1, 0), \\ x, & x \in [0, 1)\end{cases}$ 的 Fourier 级数．

解

在上面的公式中令 $T = 1$，计算 $f(x)$ 的 Fourier 系数得

$$a_0 = \int_{-1}^1 f(x)\,\mathrm{d}x = \int_0^1 x\,\mathrm{d}x = \frac{1}{2}.$$

对 $n = 1, 2, \ldots$，利用分部积分法，

$$a_n = \int_{-1}^1 f(x)\cos n\pi x\,\mathrm{d}x = \int_0^1 x\cos n\pi x\,\mathrm{d}x = \frac{(-1)^n - 1}{n^2\pi^2}.$$ $$b_n = \int_{-1}^1 f(x)\sin n\pi x\,\mathrm{d}x = \int_0^1 x\sin n\pi x\,\mathrm{d}x = \frac{(-1)^{n+1}}{n\pi}.$$

于是得到 $f(x)$ 的 Fourier 级数

$$f(x) \sim \frac{1}{4} + \sum_{n=1}^\infty\frac{(-1)^n - 1}{n^2\pi^2}\cos n\pi x + \sum_{n=1}^\infty\frac{(-1)^{n+1}}{n\pi}\sin n\pi x.$$

§2 Fourier 级数的收敛判别法

Dirichlet 积分

仔细观察上一节中的几幅图像后可能会产生这样的直觉：对于一般的以 $2\pi$ 为周期的函数 $f(x)$，除了个别点之外（看来是不连续点），当 $m \to \infty$ 时，它的 Fourier 级数的部分和函数序列 $\{S_m(x)\}$，

$$S_m(x) = \frac{a_0}{2} + \sum_{n=1}^m (a_n\cos nx + b_n\sin nx),$$

是收敛于 $f(x)$ 的，下面我们从理论上来探讨这个问题．

事实上，与 Taylor 级数相比，Fourier 级数尽管具有对 $f(x)$ 的要求较弱，以及它的部分和在整个区间上与 $f(x)$ 逼近得较好等优点，但在收敛性问题的讨论上，Taylor 级数相对比较简单，因为对它只要确定收敛半径，并在收敛区间的端点讨论余项的收敛情况就行了，而 Fourier 级数却要复杂得多．

由于级数的收敛情况就是部分和函数序列的极限情况，因此，下面的讨论就从部分和函数序列 $\{S_m(x)\}$ 入手．

将 Euler-Fourier 公式

$$a_n = \frac{1}{\pi}\int_{-\pi}^\pi f(u)\cos nu\,\mathrm{d}u, \quad b_n = \frac{1}{\pi}\int_{-\pi}^\pi f(u)\sin nu\,\mathrm{d}u$$

代入 $S_m(x)$，

$$S_m(x) = \frac{1}{\pi}\int_{-\pi}^\pi f(u)\left[\frac{1}{2} + \sum_{n=1}^m\cos n(u-x)\right]\mathrm{d}u.$$

当 $\theta \ne 0$ 时，由三角函数的积化和差公式，有

$$\frac{1}{2} + \sum_{n=1}^m\cos n\theta = \frac{\sin\!\left(m+\frac{1}{2}\right)\theta}{2\sin\frac{\theta}{2}},$$

而当 $\theta = 0$ 时，若将右端理解为当 $\theta \to 0$ 时的极限值 $m + \frac{1}{2}$，则等式依然成立．因此，上式对任意 $\theta \in [-\pi, \pi]$ 都是正确的．

于是

$$S_m(x) = \frac{1}{\pi}\int_{-\pi}^\pi f(u)\frac{\sin\!\left(m+\frac{1}{2}\right)(u-x)}{2\sin\frac{u-x}{2}}\,\mathrm{d}u \xlongequal{t = u-x} \frac{1}{\pi}\int_{-\pi-x}^{\pi-x} f(x+t)\frac{\sin\!\left(m+\frac{1}{2}\right)t}{2\sin\frac{t}{2}}\,\mathrm{d}t$$ $$= \frac{1}{\pi}\int_{-\pi}^\pi f(x+u)\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u.$$

最后一个等式利用了"周期函数在任何一个长度等于其周期的区间上的积分值相等"的性质．

这样，就把部分和转化成了积分形式．这个积分称为 Dirichlet 积分，是研究 Fourier 级数敛散性的重要工具．

将积分区间 $[-\pi, \pi]$ 分成 $[-\pi, 0]$ 和 $[0, \pi]$，稍加整理，就得到了 Dirichlet 积分的惯用形式

$$S_m(x) = \frac{1}{\pi}\int_0^\pi [f(x+u) + f(x-u)]\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u.$$

由前面的三角函数关系式，有

$$\frac{1}{\pi}\int_0^\pi\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u = \frac{1}{2}.$$

因此，对任意给定的函数 $\sigma(x)$，有

$$S_m(x) - \sigma(x) = \frac{1}{\pi}\int_0^\pi [f(x+u) + f(x-u) - 2\sigma(x)]\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u.$$

这样，若记

$$\psi(u, x) = f(x+u) + f(x-u) - 2\sigma(x),$$

则 $f(x)$ 的 Fourier 级数是否收敛于某个 $\sigma(x)$ 就等价于极限

$$\lim_{m\to\infty}\frac{1}{\pi}\int_0^\pi \psi(u, x)\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u$$

是否存在且等于 $0$．

Riemann 引理及其推论

下面首先引进一个重要的结果．

定理 16.2.1（Riemann 引理）

设函数 $\varphi(x)$ 在 $[0, b]$ 上可积或绝对可积，则成立

$$\lim_{p\to+\infty}\int_0^b \varphi(x)\sin px\,\mathrm{d}x = \lim_{p\to+\infty}\int_0^b \varphi(x)\cos px\,\mathrm{d}x = 0.$$
证

先考虑 $\varphi(x)$ 有界的情况，这时 $\varphi(x)$ Riemann 可积．对于任意给定的 $\varepsilon > 0$，由定理 7.1.3，存在着一种划分 $0 = x_0 < x_1 < \cdots < x_N = b$，满足

$$\sum_{i=1}^N (M_i - m_i)(x_i - x_{i-1}) < \varepsilon,$$

对于这种固定的划分，记 $m_i$ 是 $\varphi(x)$ 在 $[x_{i-1}, x_i]$ 中的下确界，并取实数 $P > 0$，使得当 $p > P$ 时，对任意 $i$，

$$\left|\frac{\cos px_{i-1} - \cos px_i}{p}\right| < \frac{\varepsilon}{N(|m_i|+1)}.$$

于是，对于任意给定的 $\varepsilon > 0$，存在实数 $P > 0$，当 $p > P$ 时，有

$$\left|\int_0^b \varphi(x)\sin px\,\mathrm{d}x\right| \le \sum_{i=1}^N\int_{x_{i-1}}^{x_i}|\varphi(x) - m_i|\cdot|\sin px|\,\mathrm{d}x + \left|\sum_{i=1}^N m_i\int_{x_{i-1}}^{x_i}\sin px\,\mathrm{d}x\right| < \varepsilon + \varepsilon = 2\varepsilon.$$

再考虑 $\varphi(x)$ 无界的情况，这时 $\varphi(x)$ 绝对可积．不妨假设 $b$ 是 $\varphi(x)$ 的唯一奇点．由无界函数反常积分绝对收敛的定义，对于任意给定的 $\varepsilon > 0$，存在 $\delta > 0$，当 $\eta < \delta$ 时，

$$\int_{b-\eta}^b |\varphi(x)|\,\mathrm{d}x < \varepsilon.$$

固定 $\delta$，则 $\varphi(x)$ 在 $[0, b-\delta]$ 上 Riemann 可积，应用上面的结论，存在实数 $P > 0$，当 $p > P$ 时，

$$\left|\int_0^{b-\delta}\varphi(x)\sin px\,\mathrm{d}x\right| < \varepsilon.$$

因此，

$$\left|\int_0^b\varphi(x)\sin px\,\mathrm{d}x\right| \le \left|\int_0^{b-\delta}\varphi(x)\sin px\,\mathrm{d}x\right| + \int_{b-\delta}^b|\varphi(x)|\,\mathrm{d}x < 2\varepsilon.$$

所以无论对哪一种情况，都有 $\lim_{p\to+\infty}\int_0^b \varphi(x)\sin px\,\mathrm{d}x = 0$．同理可证 $\lim_{p\to+\infty}\int_0^b \varphi(x)\cos px\,\mathrm{d}x = 0$．证毕

由 Riemann 引理可以得到如下的重要结论．

推论 16.2.1（局部性原理）

可积或绝对可积函数 $f(x)$ 的 Fourier 级数在 $x$ 点是否收敛只与 $f(x)$ 在 $(x - \delta, x + \delta)$ 的性质有关，这里 $\delta$ 是任意小的正常数．

证

因为 $\dfrac{f(x+u) + f(x-u)}{2\sin\frac{u}{2}}$ 关于 $u$ 在 $[\delta, \pi]$ 可积或绝对可积，由 Riemann 引理，

$$\lim_{m\to\infty}\frac{1}{\pi}\int_\delta^\pi [f(x+u) + f(x-u)]\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u = 0.$$

因此，若将 $S_m(x)$ 的表达式中积分区间分成 $[0, \delta]$ 和 $[\delta, \pi]$ 两部分，则当 $m \to \infty$ 时，$S_m(x)$ 的敛散性显然只与

$$\frac{1}{\pi}\int_0^\delta [f(x+u) + f(x-u)]\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u$$

有关，而这个积分只涉及 $f(x)$ 在 $(x-\delta, x+\delta)$ 的性质．证毕

推论 16.2.2

设函数 $\varphi(u)$ 在 $[0, \delta]$ 上可积或绝对可积，则成立

$$\lim_{m\to\infty}\int_0^\delta \varphi(u)\frac{\sin\!\left(m+\frac{1}{2}\right)u}{2\sin\frac{u}{2}}\,\mathrm{d}u = \lim_{m\to\infty}\int_0^\delta \varphi(u)\frac{\sin\!\left(m+\frac{1}{2}\right)u}{u}\,\mathrm{d}u.$$
证

令 $g(u) = \begin{cases}\dfrac{u}{2\sin\frac{u}{2}} - 1, & u > 0, \\ 0, & u = 0,\end{cases}$ 容易验证 $g(u)$ 是 $[0, \delta]$ 上的连续函数，由 Riemann 引理，当 $m \to \infty$ 时，有

$$\int_0^\delta \varphi(u)g(u)\sin\!\left(m+\frac{1}{2}\right)u\,\mathrm{d}u = \int_0^\delta \varphi(u)g(u)\sin\!\left(m+\frac{1}{2}\right)u\,\mathrm{d}u \to 0.$$

证毕

Fourier 级数的收敛判别法

以上推论进一步告诉我们，如果对点 $x$，能找到适当的 $\sigma(x)$，使得对于充分小的正数 $\delta > 0$，有

$$\lim_{m\to\infty}\int_0^\delta \psi(u, x)\frac{\sin\!\left(m+\frac{1}{2}\right)u}{u}\,\mathrm{d}u = 0,$$

则 $f(x)$ 的 Fourier 级数在 $x$ 点必定收敛于这个 $\sigma(x)$．

我们来粗略分析一下．显而易见，对 $x \in [-\pi, \pi]$，只要存在某个 $\delta > 0$，使 $\dfrac{\psi(u, x)}{u}$ 关于 $u$ 在 $[0, \delta]$ 上可积或绝对可积（这被称为 Dini 条件），就可以由 Riemann 引理导出上面的结果．现假设点 $x$ 是 $f(x)$ 的连续点或第一类不连续点，而上述积分的极限存在与否只涉及 $\dfrac{\psi(u, x)}{u}$ 当 $u \to 0$ 时的性质，显然，要满足 Dini 条件首先必须有 $\psi(0, x) = 0$（显然当 $f(x)$ 在点 $x$ 连续时，有 $\sigma(x) = f(x)$），于是，问题最终转化为研究使得

$$\lim_{p\to+\infty}\int_0^\delta \frac{f(x+u) + f(x-u) - 2\sigma(x)}{u}\sin pu\,\mathrm{d}u = 0$$

成立的条件——这是探索 Fourier 级数收敛性的一把钥匙．

德国数学家 Dirichlet 在 1829 年——Fourier 级数问世约四分之一个世纪之后，首先得到了一个函数的 Fourier 级数的收敛条件；又过了约半个世纪，另一位德国数学家 Lipschitz 得到了与之不同的收敛条件．他们的结果经后人完善，可以表述为如下定理：

定理 16.2.2

设函数 $f(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积，且满足下列两个条件之一，则 $f(x)$ 的 Fourier 级数在点 $x$ 处收敛于 $\dfrac{f(x^+) + f(x^-)}{2}$．

(1)（Dirichlet-Jordan 判别法）$f(x)$ 在点 $x$ 的某个邻域 $O(x, \delta)$ 上是分段单调有界函数；

(2)（Dini-Lipschitz 判别法）$f(x)$ 在点 $x$ 处满足指数为 $\alpha \in (0, 1]$ 的 Hölder 条件，即对于充分小的正数 $h$，存在常数 $L > 0$ 和 $\alpha \in (0, 1]$，使得成立

$$|f(x+h) - f(x^+)| + |f(x-h) - f(x^-)| \le L h^\alpha.$$

（当 $\alpha = 1$ 时也称为 Lipschitz 条件．）

定义 16.2.1（分段单调函数）

设函数 $f$ 在 $[a, b]$（或 $(a, b)$）上有定义．如果在 $[a, b]$（或 $(a, b)$）上存在有限个点 $a = x_0 < x_1 < \cdots < x_N = b$，使得 $f$ 在每个区间 $(x_{i-1}, x_i)$（$i = 1, 2, \ldots, N$）上是单调函数，则称 $f$ 在 $[a, b]$（或 $(a, b)$）上分段单调．

定理 16.2.3（Dirichlet 引理）

设函数 $\varphi(u)$ 在 $[0, \delta]$ 上单调，则成立

$$\lim_{p\to+\infty}\int_0^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u = 0.$$
证

不妨设 $\varphi(x)$ 单调增加．于是对任意给定的 $\varepsilon > 0$，存在 $\eta \in (0, \delta)$，当 $u \in (0, \eta)$ 时，$0 \le \varphi(u) - \varphi(0^+) < \varepsilon$．将积分分为两部分

$$\int_0^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u = \int_0^\eta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u + \int_\eta^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u.$$

对等式右边的第一项，由积分第二中值定理，存在 $\xi \in [0, \eta]$，使得

$$\int_0^\eta (\varphi(u) - \varphi(0^+))\frac{\sin pu}{u}\,\mathrm{d}u = (\varphi(\eta) - \varphi(0^+))\int_\xi^\eta \frac{\sin pu}{u}\,\mathrm{d}u.$$

由于 $\left|\int_\xi^\eta \frac{\sin pu}{u}\,\mathrm{d}u\right| = \left|\int_{p\xi}^{p\eta}\frac{\sin t}{t}\,\mathrm{d}t\right| \le K$（其中 $K$ 是与 $p$ 无关的常数），所以

$$\left|\int_0^\eta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u\right| \le K\varepsilon.$$

而对右边的第二项，由于 $\dfrac{\varphi(u) - \varphi(0^+)}{u}$ 在 $[\eta, \delta]$ 上显然是可积或绝对可积的，由 Riemann 引理，存在常数 $P > 0$，当 $p > P$ 时，有

$$\left|\int_\eta^\delta \frac{\varphi(u) - \varphi(0^+)}{u}\sin pu\,\mathrm{d}u\right| < \varepsilon.$$

综合上述两项估计，即知结论成立．Dirichlet 引理也经常表达为等价形式

$$\lim_{p\to+\infty}\int_0^\delta \varphi(u)\frac{\sin pu}{u}\,\mathrm{d}u = \varphi(0^+)\cdot\frac{\pi}{2}.$$

如果 $\varphi(u)$ 是分段单调有界函数，易知 Dirichlet 引理依然成立．证毕

下面证明定理 16.2.2．

证

当 $f(x)$ 满足条件 (1) 时，由 Dirichlet 引理，

$$\lim_{p\to+\infty}\int_0^\delta \frac{f(x+u) - f(x^+)}{u}\sin pu\,\mathrm{d}u = 0, \quad \lim_{p\to+\infty}\int_0^\delta \frac{f(x-u) - f(x^-)}{u}\sin pu\,\mathrm{d}u = 0,$$

两式相加，即有 $\lim_{m\to\infty}\left[S_m(x) - \dfrac{f(x^+) + f(x^-)}{2}\right] = 0$．

当 $f(x)$ 满足条件 (2) 时，在 $(0, \delta)$ 上，有

$$\frac{|f(x+u) + f(x-u) - f(x^+) - f(x^-)|}{u} \le \frac{L u^\alpha}{u} = L u^{\alpha-1} \quad (0 < \alpha \le 1),$$

所以，$\dfrac{\psi(u, x)}{u}$ 在 $[0, \delta]$ 可积或绝对可积，由 Riemann 引理，

$$\lim_{m\to\infty}\int_0^\delta \psi(u, x)\frac{\sin\!\left(m+\frac{1}{2}\right)u}{u}\,\mathrm{d}u = 0.$$

证毕

由于"可导"强于"满足 Lipschitz 条件"，且易于验证，因此实际中往往使用如下条件 (2) 的推论（请读者自证）：

推论 16.2.3

若 $f(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积，在点 $x$ 处两个单侧导数 $f'_+(x)$ 和 $f'_-(x)$ 都存在，或更进一步，只要两个拟单侧导数

$$\lim_{h\to 0^+}\frac{f(x+h) - f(x^+)}{h} \quad \text{和} \quad \lim_{h\to 0^+}\frac{f(x-h) - f(x^-)}{h}$$

都存在，则 $f(x)$ 的 Fourier 级数在点 $x$ 处收敛于 $\dfrac{f(x^+) + f(x^-)}{2}$．

Dirichlet-Jordan 判别法和 Dini-Lipschitz 判别法都是 Fourier 级数收敛的充分条件，尽管在物理、化学、工程等领域的实际问题中，出现的函数一般都同时满足这两个判别法的条件（容易验证，上节例子和习题中的 $f(x)$ 均是如此），但可以构造例子说明它们确实是互不包含的（参见本节习题 10）．附带指出，直至今天，还没有找到一个判别 Fourier 级数敛散性的既充分又必要的条件．

定理 16.2.2 告诉我们，若收敛条件满足，则 $f(x)$ 的 Fourier 级数在连续点收敛于函数值本身，而在第一类不连续点收敛于它左右极限的算术平均值．

所以，对于连续的周期函数 $f(x)$，应将 $f(x)$ 与它的（收敛的）Fourier 级数间的"$\sim$"改为"$=$"．如例 16.1.2 中 $f(x)$ 的余弦级数可以直截了当地写成

$$\frac{\pi}{2} - \frac{4}{\pi}\left(\cos x + \frac{\cos 3x}{3^2} + \frac{\cos 5x}{5^2} + \cdots + \frac{\cos(2k-1)x}{(2k-1)^2} + \cdots\right) = x, \quad x \in [0, \pi].$$

若周期函数 $f(x)$ 有第一类不连续点，那么展成 Fourier 级数后，要对这些点予以特别说明，画图时也要将它们的函数值标为其左右极限的算术平均值．

如例 16.1.1，应该写成

$$f(x) \sim \frac{4}{\pi}\left(\sin x + \frac{\sin 3x}{3} + \cdots + \frac{\sin(2k-1)x}{2k-1} + \cdots\right) = \begin{cases}-1, & x \in (-\pi, 0), \\ 0, & x = 0, \pm\pi, \\ 1, & x \in (0, \pi).\end{cases}$$

因 $x = \dfrac{\pi}{2}$ 属于 Fourier 级数收敛范围，因此有

$$\frac{4}{\pi}\left(\sin\frac{\pi}{2} + \frac{\sin\frac{3\pi}{2}}{3} + \frac{\sin\frac{5\pi}{2}}{5} + \cdots + \frac{\sin\frac{(2k-1)\pi}{2}}{2k-1}\right) = 1,$$

整理后便有熟知的

$$\frac{\pi}{4} = 1 - \frac{1}{3} + \frac{1}{5} - \cdots + \frac{(-1)^k}{2k+1} + \cdots$$

例 16.1.2 中 $f(x)$ 的正弦级数应该写成

$$2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \cdots + \frac{(-1)^{n+1}\sin nx}{n} + \cdots\right) = \begin{cases}x, & x \in (-\pi, \pi), \\ 0, & x = 0, \pm\pi.\end{cases}$$

例 16.1.3 的式子也应相仿地写成

$$\frac{1}{4} + \sum_{n=1}^\infty\frac{(-1)^n - 1}{n^2\pi^2}\cos n\pi x + \sum_{n=1}^\infty\frac{(-1)^{n+1}}{n\pi}\sin n\pi x = \begin{cases}0, & x \in [-1, 0], \\ x, & x \in (0, 1), \\ \frac{1}{2}, & x = \pm 1.\end{cases}$$

在证实了这个 Fourier 级数收敛的前提下，可以导出一个非常重要的结果．令 $x = \frac{1}{2}$，注意到这个点是 $f(x)$ 的不连续点，其 Fourier 级数应收敛于 $\frac{f(\frac{1}{2}^+) + f(\frac{1}{2}^-)}{2} = \frac{1}{4}$；稍加整理就可得到

$$\frac{\pi^2}{8} = 1 + \frac{1}{3^2} + \frac{1}{5^2} + \cdots + \frac{1}{(2k-1)^2} + \cdots$$

由它还可以导出

$$\sum_{n=1}^\infty\frac{1}{n^2} = \frac{\pi^2}{6}, \quad \sum_{n=1}^\infty\frac{(-1)^{n+1}}{n^2} = \frac{\pi^2}{12}$$

等（留作习题）．

§3 Fourier 级数的性质

Fourier 级数的分析性质

为简单起见，假定 $f(x)$ 的周期为 $2\pi$．

首先，利用 Riemann 引理可以直接得出：

定理 16.3.1

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积，则对于 $f(x)$ 的 Fourier 系数 $a_n$ 与 $b_n$，有

$$\lim_{n\to\infty} a_n = 0, \quad \lim_{n\to\infty} b_n = 0.$$

对于函数的 Fourier 级数表示，有必要讨论它的逐项微分和逐项积分问题．关于逐项积分，Fourier 级数有非常好的性质．

定理 16.3.2（Fourier 级数的逐项积分定理）

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积，

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx),$$

则 $f(x)$ 的 Fourier 级数可以逐项积分，即对于任意 $c, x \in [-\pi, \pi]$，

$$\int_c^x f(t)\,\mathrm{d}t = \frac{a_0}{2}(x - c) + \sum_{n=1}^\infty\left[a_n\int_c^x\cos nt\,\mathrm{d}t + b_n\int_c^x\sin nt\,\mathrm{d}t\right].$$
证（仅对 $f(x)$ 有有限个第一类不连续点的情况）

考虑函数

$$F(x) = \int_c^x \left[f(t) - \frac{a_0}{2}\right]\mathrm{d}t.$$

$F(x)$ 是周期为 $2\pi$ 的连续函数，且由定理 7.3.1 可知，在 $f(x)$ 的连续点，成立 $F'(x) = f(x) - \dfrac{a_0}{2}$，而在 $f(x)$ 的第一类不连续点，$F(x)$ 的两个单侧导数都存在．由 Dini-Lipschitz 判别法的推论，$F(x)$ 可展开为收敛的 Fourier 级数

$$F(x) = \frac{A_0}{2} + \sum_{n=1}^\infty (A_n\cos nx + B_n\sin nx).$$

利用分部积分法，即有

$$A_n = \frac{1}{\pi}\int_{-\pi}^\pi F(x)\cos nx\,\mathrm{d}x = \frac{1}{\pi}\left[\frac{F(x)\sin nx}{n}\Big|_{-\pi}^\pi - \frac{1}{n}\int_{-\pi}^\pi f(x)\sin nx\,\mathrm{d}x\right] = -\frac{b_n}{n}.$$

类似可得 $B_n = \dfrac{a_n}{n}$．于是

$$F(x) = \frac{A_0}{2} + \sum_{n=1}^\infty\left(-\frac{b_n}{n}\cos nx + \frac{a_n}{n}\sin nx\right).$$

令 $x = c$，有

$$0 = \frac{A_0}{2} + \sum_{n=1}^\infty\left(-\frac{b_n}{n}\cos nc + \frac{a_n}{n}\sin nc\right).$$

两式相减并整理，即得到

$$F(x) - F(c) = \int_c^x\left[f(t) - \frac{a_0}{2}\right]\mathrm{d}t = \sum_{n=1}^\infty\left(\frac{b_n(\cos nc - \cos nx)}{n} + \frac{a_n(\sin nx - \sin nc)}{n}\right) = \int_c^x\sum_{n=1}^\infty (a_n\cos nt + b_n\sin nt)\,\mathrm{d}t.$$

证毕

这就是说，只要 $f(x)$ 可以展成 Fourier 级数 $\dfrac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$，哪怕这个级数并不表示 $f(x)$，甚至根本不收敛，它的逐项积分级数也一定能收敛于 $f(x)$ 的积分．

从定理 16.3.2 的证明，我们还顺便得到了判断一个三角级数是否为 Fourier 级数的一个必要条件．

推论 16.3.1

$\dfrac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$ 是某个在 $[-\pi, \pi]$ 上可积或绝对可积函数的 Fourier 级数的必要条件是 $\sum_{n=1}^\infty \dfrac{a_n^2 + b_n^2}{n}$ 收敛．

推论 16.3.1 的证明留作习题．因此，并不是随便拿来一个收敛的三角级数就能说它一定是某个函数的 Fourier 级数．比如三角级数 $\sum_{n=2}^\infty \dfrac{\sin nx}{\ln n}$，由 Dirichlet 判别法可知它是点点收敛的，但由于 $\sum_{n=2}^\infty \dfrac{1}{n(\ln n)^2}$ 发散，它不可能是某个可积或绝对可积函数的 Fourier 级数．

但是，Fourier 级数逐项微分的结果就远没有这么好了．一般说来，Fourier 级数是不能逐项微分的，除非是加上特别的条件．

定理 16.3.3（Fourier 级数的逐项微分定理）

设 $f(x)$ 在 $[-\pi, \pi]$ 上连续，$f(x) \sim \dfrac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$，$f(-\pi) = f(\pi)$，且除了有限个点外 $f(x)$ 可导．进一步假设 $f'(x)$ 在 $[-\pi, \pi]$ 上可积或绝对可积（注意：$f'(x)$ 在有限个点可能无定义，但这并不影响其可积性）．则 $f'(x)$ 的 Fourier 级数可由 $f(x)$ 的 Fourier 级数逐项微分得到，即

$$f'(x) \sim \sum_{n=1}^\infty (-na_n\sin nx + nb_n\cos nx).$$
证

由所给条件，此时 $f'(x)$ 可展开为 Fourier 级数，记 $f'(x)$ 的 Fourier 系数为 $a_n'$ 和 $b_n'$，则有

$$a_0' = \frac{1}{\pi}\int_{-\pi}^\pi f'(x)\,\mathrm{d}x = \frac{1}{\pi}[f(\pi) - f(-\pi)] = 0.$$ $$a_n' = \frac{1}{\pi}\int_{-\pi}^\pi f'(x)\cos nx\,\mathrm{d}x = \frac{1}{\pi}\left[f(x)\cos nx\Big|_{-\pi}^\pi + n\int_{-\pi}^\pi f(x)\sin nx\,\mathrm{d}x\right] = nb_n, \quad n = 1, 2, \ldots$$ $$b_n' = \frac{1}{\pi}\int_{-\pi}^\pi f'(x)\sin nx\,\mathrm{d}x = \frac{1}{\pi}\left[f(x)\sin nx\Big|_{-\pi}^\pi - n\int_{-\pi}^\pi f(x)\cos nx\,\mathrm{d}x\right] = -na_n, \quad n = 1, 2, \ldots$$

于是

$$f'(x) \sim \sum_{n=1}^\infty (-na_n\sin nx + nb_n\cos nx).$$

证毕

Fourier 级数的逼近性质

现在我们来讨论 Fourier 级数的逼近性质．

定义 16.3.1

设 $S$ 是一个定义了内积运算 $(\cdot, \cdot)$ 的线性空间，取 $S$ 中的范数为 $\|\cdot\| = \sqrt{(\cdot, \cdot)}$，$T$ 是 $S$ 的一个 $n$ 维子空间，记 $T$ 的一组正交基为 $\varphi_1, \varphi_2, \ldots, \varphi_n$，即 $T = \mathrm{span}\{\varphi_1, \varphi_2, \ldots, \varphi_n\}$．若对于 $x \in S$，有 $x_T = c_1\varphi_1 + c_2\varphi_2 + \cdots + c_n\varphi_n \in T$，使得

$$\|x - x_T\| \le \|x - y\|, \quad \forall y \in T,$$

则称 $x_T$ 是 $x$ 在 $T$ 中的最佳平方逼近元素．

引理 16.3.1

在上述假定下

(1) 对于任意 $x \in S$，$x$ 在 $T$ 中的最佳平方逼近元素 $x_T$ 存在且唯一；

(2) $x_T \in T$ 是 $x$ 在 $T$ 中的最佳平方逼近元素的充分必要条件是 $x - x_T \perp T$，即

$$c_k = \frac{(x, \varphi_k)}{(\varphi_k, \varphi_k)}, \quad k = 1, 2, \ldots, n;$$

(3) 最佳平方逼近的余项满足估计式

$$\|x - x_T\|^2 = \|x\|^2 - \sum_{k=1}^n c_k^2\|\varphi_k\|^2.$$
证

令 $c_k = \dfrac{(x, \varphi_k)}{(\varphi_k, \varphi_k)}$，则对于任意的 $y = d_1\varphi_1 + d_2\varphi_2 + \cdots + d_n\varphi_n \in T$，利用 $(\varphi_j, \varphi_k) = 0$（$j \ne k$）得到

$$\|x - y\|^2 = \|x\|^2 - 2\sum_{k=1}^n d_k(x, \varphi_k) + \sum_{k=1}^n d_k^2\|\varphi_k\|^2 = \|x\|^2 - \sum_{k=1}^n c_k^2\|\varphi_k\|^2 + \sum_{k=1}^n (d_k - c_k)^2\|\varphi_k\|^2.$$

于是，当且仅当 $d_k = c_k$，$k = 1, 2, \ldots, n$ 时，$\|x - y\|$ 达到最小，这就证明了 (1) 和 (3)．

再证 (2)．对于每个 $k = 1, 2, \ldots, n$，$x$ 在 $T$ 中的最佳平方逼近元素 $x_T = \sum_{j=1}^n c_j\varphi_j$ 满足

$$(x - x_T, \varphi_k) = (x, \varphi_k) - c_k\|\varphi_k\|^2 = 0.$$

反之，若 $y = d_1\varphi_1 + \cdots + d_n\varphi_n \in T$ 满足 $(x - y, \varphi_k) = 0$，$k = 1, 2, \ldots, n$，那么 $d_k = c_k$，因此 $y = x_T$．证毕

现在，具体地取 $S$ 为 $[-\pi, \pi]$ 上 Riemann 可积或在反常积分意义下平方可积（简称"可积或平方可积"）的函数 $f(x)$ 全体；$S$ 中的内积 $(\cdot, \cdot)$ 和范数 $\|\cdot\|$ 定义为

$$(f, g) = \int_{-\pi}^\pi f(x)g(x)\,\mathrm{d}x, \quad \|f\| = \sqrt{\int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x}.$$

记 $T_n$ 为 $n$ 阶三角多项式 $\dfrac{A_0}{2} + \sum_{k=1}^n (A_k\cos kx + B_k\sin kx)$ 的全体，利用前面已得到的正交性，可将 $T_n$ 表示为

$$T_n = \mathrm{span}\{1, \cos x, \sin x, \cos 2x, \sin 2x, \ldots, \cos nx, \sin nx\}.$$

这时，有 $\|1\|^2 = 2\pi$ 和 $\|\cos kx\|^2 = \|\sin kx\|^2 = \pi$，$k = 1, 2, \ldots, n$．

由 Fourier 系数的 Euler-Fourier 公式，得到 $(f, \cos kx) = \pi a_k$，$(f, \sin kx) = \pi b_k$，于是，由引理 16.3.1 即得到下面的重要结论．

定理 16.3.4（Fourier 级数的平方逼近性质）

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积或平方可积，则 $f(x)$ 在 $T_n$ 中的最佳平方逼近元素恰为 $f(x)$ 的 Fourier 级数的部分和函数

$$S_n(x) = \frac{a_0}{2} + \sum_{k=1}^n (a_k\cos kx + b_k\sin kx),$$

逼近的余项为

$$\|f - S_n\|^2 = \int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x - \pi\left[\frac{a_0^2}{2} + \sum_{k=1}^n (a_k^2 + b_k^2)\right].$$

因为 $\|f - S_n\|^2 \ge 0$，在余项中令 $n \to \infty$，即得到：

推论 16.3.2（Bessel 不等式）

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积或平方可积，则 $f(x)$ 的 Fourier 系数满足不等式

$$\frac{a_0^2}{2} + \sum_{n=1}^\infty (a_n^2 + b_n^2) \le \frac{1}{\pi}\int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x.$$

这表示 Fourier 系数的平方组成了一个收敛的级数．

进一步的研究表明，上面的不等式实际上是一个等式，称为 Parseval 等式（又称能量恒等式），它在理论和实际问题中都具有重要作用．

定理 16.3.5（Parseval 等式）

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积或平方可积，则成立等式

$$\frac{a_0^2}{2} + \sum_{n=1}^\infty (a_n^2 + b_n^2) = \frac{1}{\pi}\int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x.$$

证明从略．

定义 16.3.2

若函数序列 $\{\varphi_n(x)\}$ 满足 $\lim_{n\to\infty}\|f(x) - \varphi_n(x)\|^2 = 0$，这里 $f(x)$ 是某一个固定函数，则称 $\{\varphi_n(x)\}$ 按范数 $\|\cdot\|$ 平方收敛于 $f(x)$．

由 Parseval 等式 $\lim_{n\to\infty}\|f - S_n\|^2 = 0$，即得到一个精彩而重要的结论．

推论 16.3.3（Fourier 级数的平方收敛性质）

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积或平方可积，则 $f(x)$ 的 Fourier 级数的部分和函数序列平方收敛于 $f(x)$．

而对一致收敛，我们不加证明地引进一个同样精彩、同样重要的结论．

定理 16.3.6（Weierstrass 第二逼近定理）

对周期为 $2\pi$ 的任意一个连续函数 $f(x)$，都存在三角多项式序列

$$\left\{\varphi_n(x) = \frac{A_0^{(n)}}{2} + \sum_{k=1}^n (A_k^{(n)}\cos kx + B_k^{(n)}\sin kx)\right\},$$

使得 $\{\varphi_n(x)\}$ 在 $(-\infty, +\infty)$ 上一致收敛于 $f(x)$．

等周问题

在平面上周长相等的所有简单闭曲线中，怎样的曲线所围图形的面积最大？这就是著名的"等周问题"．早在古希腊时期，人们就已经猜测这样的曲线应该是圆周．但这一事实的严格证明是近代才给出的．确切的结论如下：

定理 16.3.7

平面上具有定长的所有简单闭曲线中，圆周所围的面积最大．换言之，若 $L$ 是平面上简单闭曲线 $C$ 的长度，$A$ 是曲线 $C$ 所围图形的面积，则

$$A \le \frac{L^2}{4\pi},$$

且等号成立时，$C$ 必须是圆周．

注 $\dfrac{L^2}{4\pi}$ 就是周长为 $L$ 的圆所围的面积．

我们现在仅限于对平面上分段光滑的简单闭曲线讨论问题．以下的证明是 Hurwitz 在 1902 年给出的．

引理 16.3.2（Wirtinger）

设 $f(x)$ 在 $[-\pi, \pi]$ 上连续，$f(-\pi) = f(\pi)$，$\int_{-\pi}^\pi f(x)\,\mathrm{d}x = 0$，且除了有限个点外 $f(x)$ 可导，但在不可导的点，$f(x)$ 的单侧导数存在．进一步假设，$f(x)$ 的导数 $f'(x)$ 在 $[-\pi, \pi]$ 上可积或平方可积，则

$$\int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x \le \int_{-\pi}^\pi [f'(x)]^2\,\mathrm{d}x,$$

等号成立当且仅当 $f(x) = a\cos x + b\sin x$（$a, b$ 为常数）．

证

由推论 16.2.3，$f(x)$ 的 Fourier 级数在 $[-\pi, \pi]$ 上点点收敛于 $f(x)$．由于 $a_0 = \dfrac{1}{\pi}\int_{-\pi}^\pi f(x)\,\mathrm{d}x = 0$，所以 $f(x) = \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$．进一步，由定理 16.3.3，$f'(x) \sim \sum_{n=1}^\infty (-na_n\sin nx + nb_n\cos nx)$．于是，由 Parseval 等式得到

$$\int_{-\pi}^\pi [f(x)]^2\,\mathrm{d}x = \pi\sum_{n=1}^\infty (a_n^2 + b_n^2),$$ $$\int_{-\pi}^\pi [f'(x)]^2\,\mathrm{d}x = \pi\sum_{n=1}^\infty n^2(a_n^2 + b_n^2) \ge \pi\sum_{n=1}^\infty (a_n^2 + b_n^2).$$

等号成立当且仅当 $n \ge 2$ 时 $a_n = b_n = 0$，即 $f(x) = a_1\cos x + b_1\sin x$．证毕

定理 16.3.7 的证明

设曲线 $C$ 以弧长参数的方程为 $x = x(s)$，$y = y(s)$，$s \in [0, L]$，且参数 $s$ 从 $0$ 变到 $L$ 时，点 $(x(s), y(s))$ 沿逆时针方向画出曲线 $C$．因为 $C$ 是闭曲线，可将该曲线的方程改写为 $x = \varphi(t)$，$y = \psi(t)$，$t \in [-\pi, \pi]$，不妨假设 $\int_{-\pi}^\pi \varphi(t)\,\mathrm{d}t = 0$．

由于 $s$ 与 $t$ 满足 $\dfrac{\mathrm{d}s}{\mathrm{d}t} = \dfrac{L}{2\pi}$，所以由弧长的微分公式得

$$\varphi'^2(t) + \psi'^2(t) = \left(\frac{\mathrm{d}s}{\mathrm{d}t}\right)^2 = \left(\frac{L}{2\pi}\right)^2.$$

对上式在 $[-\pi, \pi]$ 上取定积分得

$$\frac{L^2}{2\pi} = \int_{-\pi}^\pi [\varphi'^2(t) + \psi'^2(t)]\,\mathrm{d}t.$$

其次，$C$ 所围图形的面积 $A$ 可用曲线积分表示

$$A = \oint_C x\,\mathrm{d}y = \int_{-\pi}^\pi \varphi(t)\psi'(t)\,\mathrm{d}t,$$

因此

$$\frac{L^2}{4\pi} - A = \frac{1}{2}\int_{-\pi}^\pi [\varphi'^2(t) + \psi'^2(t)]\,\mathrm{d}t - \int_{-\pi}^\pi \varphi(t)\psi'(t)\,\mathrm{d}t = \frac{1}{2}\int_{-\pi}^\pi [\varphi(t) - \psi'(t)]^2\,\mathrm{d}t + \frac{1}{2}\int_{-\pi}^\pi [\varphi'^2(t) - \varphi^2(t)]\,\mathrm{d}t.$$

由于 $C$ 是分段光滑曲线，所以 $\varphi(t)$ 满足引理 16.3.2 的条件，因此

$$\frac{1}{2}\int_{-\pi}^\pi [\varphi'^2(t) - \varphi^2(t)]\,\mathrm{d}t \ge 0,$$ $$\frac{L^2}{4\pi} - A \ge 0.$$

等号成立当且仅当

$$\int_{-\pi}^\pi [\varphi(t) - \psi'(t)]^2\,\mathrm{d}t = 0, \quad \int_{-\pi}^\pi [\varphi'^2(t) - \varphi^2(t)]\,\mathrm{d}t = 0,$$

等价地，就是

$$\varphi(t) = a\cos t + b\sin t, \quad \psi'(t) = \varphi(t), \quad t \in [-\pi, \pi],$$

这时 $C$ 的参数方程为 $x = \varphi(t) = a\cos t + b\sin t$，$y = \psi(t) = a\sin t - b\cos t$，$t \in [-\pi, \pi]$，即 $C$ 是一个圆周．证毕

§4 Fourier 变换和 Fourier 积分

Fourier 变换及其逆变换

以上关于 Fourier 级数的论述都是对周期函数而言的，那么对于不具备周期性的函数，又该如何处理呢？

在 $(-\infty, +\infty)$ 上可积的非周期函数 $f(x)$ 可以看成是周期函数的极限情况，处理思路是这样的：

  1. 先取 $f(x)$ 在 $[-T, T]$ 上的部分（即把它视为仅定义在 $[-T, T]$ 上的函数），再以 $2T$ 为周期，将它延拓为 $(-\infty, +\infty)$ 上的周期函数 $f_T(x)$；
  2. 对得到的周期函数 $f_T(x)$ 作 Fourier 展开；
  3. 令 $T$ 趋于无穷大．

下面来导出具体过程．将 Euler 公式 $\cos\theta = \dfrac{e^{i\theta} + e^{-i\theta}}{2}$，$\sin\theta = \dfrac{e^{i\theta} - e^{-i\theta}}{2i}$ 代入周期为 $2T$ 的函数 $f_T(x)$ 的 Fourier 级数，记 $\omega_n$ 是圆频率（下面就简称为频率），$\omega_0 = \dfrac{\pi}{T}$，得到

$$f_T(x) \sim \sum_{n=-\infty}^{+\infty} c_n e^{i n\omega_0 x}, \quad c_n = \frac{1}{2T}\int_{-T}^T f_T(t)e^{-in\omega_0 t}\,\mathrm{d}t.$$

这称为 Fourier 级数的复数形式．将 $c_n$ 的表达式代入，记 $\Delta\omega = \omega_0 = \dfrac{\pi}{T}$，于是当 $T \to +\infty$ 时 $\Delta\omega \to 0$，即得到

$$f(x) \sim \frac{1}{2\pi}\int_{-\infty}^{+\infty}\left[\int_{-\infty}^{+\infty} f(t)e^{-i\omega t}\,\mathrm{d}t\right]e^{i\omega x}\,\mathrm{d}\omega.$$

我们称方括号中的函数

$$F(\omega) = \int_{-\infty}^{+\infty} f(x)e^{-i\omega x}\,\mathrm{d}x \quad (\omega \in (-\infty, +\infty))$$

为 $f$ 的 Fourier 变换（或像函数），记为 $\mathcal{F}[f]$，即

$$\mathcal{F}[f](\omega) = \hat{f}(\omega) = \int_{-\infty}^{+\infty} f(x)e^{-i\omega x}\,\mathrm{d}x.$$

而称函数

$$f(x) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} F(\omega)e^{i\omega x}\,\mathrm{d}\omega \quad (x \in (-\infty, +\infty))$$

为 $F$ 的 Fourier 逆变换（或像原函数），记为 $\mathcal{F}^{-1}[F]$，即

$$\mathcal{F}^{-1}[F](x) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} F(\omega)e^{i\omega x}\,\mathrm{d}\omega.$$

注意这里假设了像函数与像原函数的存在性．

我们称函数

$$f(x) = \frac{1}{2\pi}\int_{-\infty}^{+\infty}\mathrm{d}\omega\int_{-\infty}^{+\infty} f(t)e^{-i\omega(t-x)}\,\mathrm{d}t$$

为 $f$ 的 Fourier 积分．容易想到，在一定条件下，它应与 $f(x)$ 相等，但研究这些条件已超出本课程的要求，我们不加证明地给出以下充分条件．

定理 16.4.1

设函数 $f$ 在 $(-\infty, +\infty)$ 上绝对可积，且在 $(-\infty, +\infty)$ 中的任何闭区间上分段可导．则 $f$ 的 Fourier 积分满足：对于任意 $x \in (-\infty, +\infty)$ 成立

$$\frac{1}{2\pi}\int_{-\infty}^{+\infty}\mathrm{d}\omega\int_{-\infty}^{+\infty} f(t)e^{-i\omega(t-x)}\,\mathrm{d}t = \frac{f(x^+) + f(x^-)}{2}.$$
定义 16.4.1（分段可导）

设函数 $f$ 在 $[a, b]$ 上除有限个点 $a = x_0 < x_1 < \cdots < x_N = b$ 外连续（在 $x_0 = a$ 只要求右极限存在，在 $x_N = b$ 只要求左极限存在），并且极限

$$\lim_{h\to 0^-}\frac{f(x_0 + h) - f(x_0^+)}{h} \quad \text{和} \quad \lim_{h\to 0^+}\frac{f(x_0 + h) - f(x_0^+)}{h}$$

都存在，那么称 $f$ 在 $[a, b]$ 上分段可导．

注意，若 $x$ 是 $f$ 的连续点，定理 16.4.1 已蕴含了

$$\frac{1}{2\pi}\int_{-\infty}^{+\infty}\mathrm{d}\omega\int_{-\infty}^{+\infty} f(t)e^{i\omega(x-t)}\,\mathrm{d}t = f(x).$$
例 16.4.1

求孤立矩形波 $F(x) = \begin{cases}h, & |x| \le \delta, \\ 0, & |x| > \delta\end{cases}$（见图 16.4.1）的 Fourier 变换 $\hat{F}(\omega)$ 和 $\hat{F}(\omega)$ 的 Fourier 逆变换．

解

当 $\omega \ne 0$ 时，

$$\hat{F}(\omega) = \int_{-\delta}^\delta h e^{-i\omega x}\,\mathrm{d}x = h\cdot\frac{e^{-i\omega\delta} - e^{i\omega\delta}}{-i\omega} = \frac{2h}{\omega}\sin(\omega\delta).$$

当 $\omega = 0$ 时 $\hat{F}(0) = \int_{-\infty}^{+\infty} F(x)\,\mathrm{d}x = 2h\delta = \lim_{\omega\to 0}\hat{F}(\omega)$．

而利用熟知的结果 $\int_0^{+\infty}\dfrac{\sin ax}{x}\,\mathrm{d}x = \dfrac{\pi}{2}\mathrm{sgn}(a)$，可以求得 $F$ 的逆变换：

$$\mathcal{F}^{-1}[\hat{F}](x) = \frac{1}{2\pi}\int_{-\infty}^{+\infty}\frac{2h\sin(\omega\delta)}{\omega}e^{i\omega x}\,\mathrm{d}\omega = \begin{cases}h, & |x| < \delta, \\ \dfrac{h}{2}, & x = \pm\delta, \\ 0, & |x| > \delta.\end{cases}$$

设 $f(x)$ 在 $(-\infty, +\infty)$ 上连续，且满足定理 16.4.1 的条件，则将 $f$ 的 Fourier 积分的实部和虚部分开，得到 $f(x)$ 的 Fourier 积分的三角形式（也称为实形式）：

$$f(x) = \frac{1}{\pi}\int_0^{+\infty}\mathrm{d}\omega\int_{-\infty}^{+\infty} f(t)\cos\omega(x-t)\,\mathrm{d}t.$$

当 $f(x)$ 本身是偶函数时，上式又可化成

$$f(x) = \frac{2}{\pi}\int_0^{+\infty}\cos\omega x\,\mathrm{d}\omega\int_0^{+\infty} f(t)\cos\omega t\,\mathrm{d}t,$$

它可以看成是由 Fourier 余弦变换

$$\mathcal{F}_c[f] = \hat{f}_c(\omega) = \int_0^{+\infty} f(x)\cos\omega x\,\mathrm{d}x$$

及其逆变换复合而成的．当 $f(x)$ 本身是奇函数时，可以类似地得到由 Fourier 正弦变换

$$\mathcal{F}_s[f] = \hat{f}_s(\omega) = \int_0^{+\infty} f(x)\sin\omega x\,\mathrm{d}x$$

及其逆变换复合而成的公式．

例 16.4.2

求 $f(x) = e^{-x}\sin x$（$x \in [0, +\infty)$）的余弦变换．

解 $$\hat{f}_c(\omega) = \int_0^{+\infty} e^{-x}\sin x\cos\omega x\,\mathrm{d}x = \frac{1}{2}\int_0^{+\infty} e^{-x}[\sin(1+\omega)x + \sin(1-\omega)x]\,\mathrm{d}x$$ $$= \frac{1}{2}\left[\frac{1+\omega}{1+(1+\omega)^2} + \frac{1-\omega}{1+(1-\omega)^2}\right] = \frac{2-\omega^2}{4+\omega^4}.$$

Fourier 变换的性质

Fourier 变换和 Fourier 逆变换的下列性质对于理论分析和实际计算都很有用．

(1) 线性性质

设 $c_1, c_2$ 是常数．若 $f, g$ 的 Fourier 变换存在，则

$$\mathcal{F}[c_1 f + c_2 g] = c_1\mathcal{F}[f] + c_2\mathcal{F}[g].$$

(2) 位移性质

若函数 $f$ 的 Fourier 变换存在，则

$$\mathcal{F}[f(x + x_0)](\omega) = \mathcal{F}[f](\omega)e^{i\omega x_0}.$$
证 $$\mathcal{F}[f(x+x_0)](\omega) = \int_{-\infty}^{+\infty} f(x+x_0)e^{-i\omega x}\,\mathrm{d}x \xlongequal{u = x+x_0} \int_{-\infty}^{+\infty} f(u)e^{-i\omega(u-x_0)}\,\mathrm{d}u = e^{i\omega x_0}\mathcal{F}[f](\omega).$$

(3) 时间尺度性和频率尺度性：

$$\mathcal{F}[f(ax)](\omega) = \frac{1}{|a|}\hat{f}\!\left(\frac{\omega}{a}\right); \quad \mathcal{F}\!\left[\frac{1}{|a|}f\!\left(\frac{x}{a}\right)\right](\omega) = \hat{f}(a\omega).$$

(4) 微分性质

1) 设函数 $f(x)$ 在 $(-\infty, +\infty)$ 上有连续的导数，且 $f(x)$ 与 $f'(x)$ 在 $(-\infty, +\infty)$ 上绝对可积，若 $\lim_{|x|\to+\infty} f(x) = 0$，则有

$$\mathcal{F}[f'] = i\omega\cdot\mathcal{F}[f].$$

2) 若 $f(x)$ 和 $xf(x)$ 在 $(-\infty, +\infty)$ 上绝对可积，则

$$\mathcal{F}[-ix\cdot f] = (\mathcal{F}[f])'.$$
证

1) 由分部积分公式得

$$\mathcal{F}[f'](\omega) = \int_{-\infty}^{+\infty} f'(x)e^{-i\omega x}\,\mathrm{d}x = f(x)e^{-i\omega x}\Big|_{-\infty}^{+\infty} + i\omega\int_{-\infty}^{+\infty} f(x)e^{-i\omega x}\,\mathrm{d}x = i\omega\mathcal{F}[f](\omega).$$

2) 对 $\mathcal{F}[f](\omega)$ 关于 $\omega$ 求导，将求导运算与积分运算交换（其理由请读者自行说明），得

$$(\mathcal{F}[f])'(\omega) = \frac{\mathrm{d}}{\mathrm{d}\omega}\int_{-\infty}^{+\infty} f(x)e^{-i\omega x}\,\mathrm{d}x = \int_{-\infty}^{+\infty} (-ix)f(x)e^{-i\omega x}\,\mathrm{d}x = \mathcal{F}[-ix\cdot f](\omega).$$

证毕

(5) 积分性质

设函数 $f(x)$ 和 $\int_{-\infty}^x f(t)\,\mathrm{d}t$ 在 $(-\infty, +\infty)$ 上绝对可积，则

$$\mathcal{F}\!\left[\int_{-\infty}^x f(t)\,\mathrm{d}t\right](\omega) = \frac{1}{i\omega}\mathcal{F}[f](\omega).$$

卷积

定义 16.4.2（卷积）

设函数 $f$ 和 $g$ 在 $(-\infty, +\infty)$ 上定义，且积分

$$(f * g)(x) = \int_{-\infty}^{+\infty} f(x-t)g(t)\,\mathrm{d}t$$

存在，则称函数 $f * g$ 为 $f$ 和 $g$ 的卷积．显然，卷积具有对称性，即 $f * g = g * f$．

定理 16.4.2（卷积的 Fourier 变换）

设函数 $f$ 和 $g$ 在 $(-\infty, +\infty)$ 上绝对可积，则有

$$\mathcal{F}[f * g] = \mathcal{F}[f]\cdot\mathcal{F}[g].$$
定理 16.4.3（Parseval 等式）

设函数 $f$ 在 $(-\infty, +\infty)$ 上绝对可积，且 $\int_{-\infty}^{+\infty}[f(x)]^2\,\mathrm{d}x$ 收敛．记 $f$ 的 Fourier 变换为 $\hat{f}$，则

$$\int_{-\infty}^{+\infty}[f(x)]^2\,\mathrm{d}x = \frac{1}{2\pi}\int_{-\infty}^{+\infty}|\hat{f}(\omega)|^2\,\mathrm{d}\omega.$$
例 16.4.3

求解微分方程 $u''(x) - u(x) + 2af(x) = 0$（$a > 0$ 为常数，$x \in (-\infty, +\infty)$）．

解

由 Fourier 变换的微分性质得 $\mathcal{F}[u''] = (i\omega)^2\mathcal{F}[u] = -\omega^2\mathcal{F}[u]$．对方程两边作 Fourier 变换，整理后即有

$$\mathcal{F}[u] = \frac{2a}{a^2 + \omega^2}\mathcal{F}[f].$$

利用 $\mathcal{F}[e^{-a|x|}] = \dfrac{2a}{a^2 + \omega^2}$ 和定理 16.4.2 的结论，得到

$$u(x) = \mathcal{F}^{-1}\!\left[\frac{2a}{a^2+\omega^2}\cdot\mathcal{F}[f]\right] = e^{-a|x|} * f(x) = \int_{-\infty}^{+\infty} e^{-a|x-t|}f(t)\,\mathrm{d}t.$$

注 周期函数实际上就是频率为 $\omega_0 = \dfrac{\pi}{T}$ 的振荡函数：Fourier 级数 $f(x) \sim \dfrac{a_0}{2} + \sum_{n=1}^\infty (a_n\cos n\omega_0 x + b_n\sin n\omega_0 x)$ 揭示了 $f(x)$ 可以通过频率为 $\omega_0$（称为基频）的正弦波 $\sin\omega_0 x$ 和余弦波 $\cos\omega_0 x$（称为基波）及其 $n$ 次谐波 $\sin n\omega_0 x, \cos n\omega_0 x$ 叠加来得到，而谐频为 $n\omega_0$ 的谐波的振幅 $\sqrt{a_n^2 + b_n^2} = |c_n|$ 可理解成该谐波在整体中的强度．

§5 快速 Fourier 变换

离散 Fourier 变换

人们刚开始利用无线电技术传输信号时，是将连续信号进行某种调制处理后直接传送的，本质上传送的还是连续信号（也叫模拟信号），这样的传输方式抗干扰能力差，失真严重，尤其是经过长距离传送或多级传递后，信号可能面目全非，质量自然难尽人意．

以后发展了离散的传输方法，它不是传送连续信号本身，而是每隔一段时间 $\Delta t$，从信号中提取一个数值脉冲（称为数值抽样），将连续信号转化成数据序列 $x(0), x(1), x(2), \ldots, x(N-1)$，再经编码后发送．只要抽取的时间间隔足够小，这列数据就能很好地反映原信号，接收方通过逆向处理，可以复原出所传递的信号．这种方法称为数字信号传输，具有抗干扰能力强，信号还原质量高、易于加密和解密等优点，问世后便受到广泛的重视，至今方兴未艾．

在抽样之后需要对数据序列 $x(0), x(1), \ldots, x(N-1)$ 进行简化和压缩．后来经研究发现，若对数据序列施以如下的离散 Fourier 变换

$$X(j) = \sum_{n=0}^{N-1} x(n)e^{-2\pi i jn/N}, \quad j = 0, 1, 2, \ldots, N-1,$$

就可以有效地解决上面的问题．（之所以称它为"离散 Fourier 变换"，在于它可以看成是 Fourier 变换 $\hat{f}(\omega) = \int_{-\infty}^{+\infty} f(x)e^{-i\omega x}\,\mathrm{d}x$ 的一种离散的近似形式的推广．）

利用正交关系式

$$\frac{1}{N}\sum_{k=0}^{N-1} e^{2\pi i(j-n)k/N} = \delta_{jn},$$

可以导出离散 Fourier 逆变换

$$x(k) = \frac{1}{N}\sum_{j=0}^{N-1} X(j)e^{2\pi i jk/N}, \quad k = 0, 1, 2, \ldots, N-1.$$

从变换公式容易看出，变换后的序列中的每个 $X(j)$，都包含了原序列中所有信号的信息．因此，即使丢失了某些 $X(j)$，仍可望由其余数据基本正确地还原出原始数据，这当然使得传输过程的抗干扰能力进一步提高，但更重要的是，这可以让我们通过有意剔除某些模较小的数据而使需传输的序列大为缩短．

快速 Fourier 变换

尽管早就发现离散 Fourier 变换有如此诱人的好处，但在一个相当长的时期中，人们对它基本上只限于纸上谈兵．这是因为，做一次变换需要进行 $N^2$ 次复数乘法和 $N(N-1)$ 次复数加法，实际使用中的 $N$ 总是极为巨大的，相应的高昂代价令人望而却步．

一直到 20 世纪 60 年代中期，Cooley 和 Tukey 发现了计算离散 Fourier 变换的高效方法——快速 Fourier 变换（简称 FFT——Fast Fourier Transform）之后，它才真正获得了生命力．可以毫不夸张地说，基于 FFT 的离散 Fourier 变换技术，是当今信息传输、频谱分析、图像处理、数据压缩等领域中最重要的数学工具之一，目前，国际上任何一个综合的数学软件中，必定含有 FFT 的计算程序．

下面对 FFT 的思想作一简单介绍（由于逆 FFT 的形式与 FFT 完全相同，因此所有的方法和结论都可以平行地用到逆 FFT 上去）：

设 $N = 2m$，将 $j$ 和 $n$ 分别改写成

$$j = m j_0 + j_1, \quad j_0 = 0, 1, \quad j_1 = 0, 1, \ldots, m-1,$$ $$n = 2n_1 + n_0, \quad n_0 = 0, 1, \quad n_1 = 0, 1, \ldots, m-1,$$

记 $W_N = e^{-2\pi i/N}$，则 $W_N^{jn} = W_N^{(m j_0 + j_1)(2n_1 + n_0)} = W_m^{j_1 n_1}(W_N^m)^{j_0 n_0}W_N^{j_1 n_0} = W_m^{j_1 n_1}(-1)^{j_0 n_0}W_N^{j_1 n_0}$．

将上式代入离散 Fourier 变换公式，并记 $X(j)$ 为 $X(j_1, j_0)$：

$$X(j_1, j_0) = \sum_{n_0=0}^1 \left[(-1)^{j_0 n_0}W_N^{j_1 n_0}\sum_{n_1=0}^{m-1} x(2n_1 + n_0)W_m^{j_1 n_1}\right].$$

将方括号中的部分记为 $\tilde{X}(n_0, j_1)$，则计算 $X(j)$（$j = 0, 1, 2, \ldots, N-1$）可分解为两个步骤进行：

$$\tilde{X}(n_0, j_1) = \sum_{n_1=0}^{m-1} x(2n_1 + n_0)W_m^{j_1 n_1}, \quad n_0 = 0, 1, \quad j_1 = 0, 1, \ldots, m-1.$$ $$X(j_1, j_0) = \sum_{n_0=0}^1 (-1)^{j_0 n_0}W_N^{j_1 n_0}\tilde{X}(n_0, j_1).$$

容易推导出，对 $N = 2^m$，执行一个以 2 为底的完整的 FFT，只需要进行 $\dfrac{N}{2}\log_2 N$ 次复数乘法和 $N\log_2 N$ 次复数加法．由于

$$\frac{N^2}{\frac{N}{2}\log_2 N} = \frac{2N}{\log_2 N} \to \infty, \quad N \to \infty,$$

因此它比原来需要 $N^2$ 次运算的直接算法在数量级上有了重大改进，节省的工作量相当惊人．比如，对 $N = 2^{10} = 1024$（对于实际问题来讲，这仅是一个很小的数字），原算法的复数乘法次数就超过 FFT 的 200 倍！

FFT 还为离散 Fourier 变换开拓出了许多新的用途，计算数列的卷积就是一个典型的例子．设 $\{x(k)\}_{k=0}^{N-1}$ 和 $\{y(k)\}_{k=0}^{N-1}$ 都是实的或复的数列，定义它们的卷积为

$$(x * y)(k) = \sum_{n=0}^{N-1} x(n)y(k-n).$$

可以证明，两个数列卷积的离散 Fourier 变换，等于由这两个数列分别的离散 Fourier 变换的对应项乘积构成的数列，即 $\mathcal{F}[x * y] = \mathcal{F}[x]\cdot\mathcal{F}[y]$（其中乘法是逐项乘积）．

因此，计算两个数列的卷积可分三步进行：

  1. 分别做 $\{x(k)\}$ 和 $\{y(k)\}$ 的离散 Fourier 变换 $\{X(j)\}$ 和 $\{Y(j)\}$；
  2. 求 $X(j)Y(j)$，$j = 0, 1, \ldots, N-1$；
  3. 做 $\{X(j)Y(j)\}$ 的离散 Fourier 逆变换，得到 $\{z(k)\}$．

上述过程需要两次离散 Fourier 变换和一次离散 Fourier 逆变换，有了 FFT 之后，总共只需 $4.5N\log_2 N$ 次运算，节省效果相当可观．

由 FFT 方法出发，产生了很大一类基于卷积计算的快速算法．比如，要计算两个 $n$ 次多项式 $P_n(x) = \sum_{k=0}^n a_k x^k$ 和 $Q_n(x) = \sum_{k=0}^n b_k x^k$ 的乘积，若令数列 $\{A(k)\}$ 和 $\{B(k)\}$ 分别为 $A(k) = a_k$，$0 \le k \le n$；$B(k) = b_k$，$0 \le k \le n$，则乘积的系数恰好是 $\{A(k)\}$ 和 $\{B(k)\}$ 的卷积——这就是求多项式乘积的快速算法．
