💡 1. 生活比喻与直觉通俗化

从 Transformer 到 Mamba 的架构进化史：

  • Transformer 注意力机制 (QKV)：每一个词与之前的所有词进行“全对全”相似度对齐打分。精准度极高，但对长文本的计算量呈二次方增长 $\mathcal{O}(N^2)$！
  • HiPPO 矩阵记忆衰减：用勒让德多项式 (Legendre Polynomials) 正交投影压缩历史信息，实现无限历史信号的最优逼近。
  • Mamba 状态空间模型 (SSM)：将控制理论中的连续线性系统 $\dot{x}(t) = Ax(t) + B u(t)$ 进行选择性离散化 (Selective Scanning)，兼具 RNN 的线性推理速度 $\mathcal{O}(N)$ 与 Transformer 的全局关联力！

🧮 2. 严密数学工具与公式推导

Self-Attention 缩放点积公式与连续状态空间方程离散化 (Discretization)：

$$\text{Attention}(Q, K, V) = \operatorname{Softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

连续 SSM 经过零阶保持 (ZOH) 离散化为循环与卷积双重重构形式：

$$\overline{A} = \exp(\Delta A), \quad \overline{B} = (\Delta A)^{-1} (\overline{A} - I) \cdot \Delta B, \quad h_t = \overline{A} h_{t-1} + \overline{B} x_t$$

📄 3. 经典奠基论文核心拆解

论文一：Attention Is All You Need (Vaswani et al., NeurIPS 2017)

核心突破： 划时代的经典！彻底弃用了 RNN 与 CNN，仅靠 Multi-Head Self-Attention 实现了并行训练，奠定了大语言模型 (LLMs) 的通用基础。

论文二：HiPPO: Recurrent Memory with Optimal Polynomial Projections (Gu et al., NeurIPS 2020)

核心突破： 提出了 HiPPO 记忆矩阵，数学上证明了如何通过正交多项式将连续历史信号投影到固定维度的状态向量中，解决了 RNN 长距离记忆遗忘问题。

论文三：Mamba: Linear-Time Sequence Modeling with Selective State Spaces (Gu & Dao, 2023)

核心突破： 提出了Selective SSM (Mamba)，让 SSM 的参数矩阵 $B, C, \Delta$ 随输入内容动态改变，结合硬件感知算子并行 (Hardware-aware Parallel Scan)，实现了线性时间复杂度的超长序列建模。

⚡ 4. AI 核心落地与算子视角

Mamba 选择性离散化与 FlashScan GPU 并行算子：

$$\Delta_t = \text{Softplus}(\text{Parameter} + s_\Delta(x_t)), \quad B_t = s_B(x_t), \quad C_t = s_C(x_t)$$

将步长 $\Delta_t$ 设置为输入的函数，使模型能选择性地“记住”重要信息并“忽略”无用的填充 Token，在 1M+ 极长文本建模中显存仅随长度线性增加。

📚 5. 教材章节导读与自测题

建议阅读 Gu et al. (State Space Models for Deep Learning Chapter 2)。

思考题：为什么说 Transformer 在推理 KV Cache 时的时间复杂度是 $\mathcal{O}(N)$，而 Mamba 的推理复杂度是 $\mathcal{O}(1)$？

A. Transformer 生成新 Token 需要与历史全部 $N$ 个 KV 键值做 Attention；而 Mamba 只需常数时间更新固定尺寸的状态 $h_t$。
B. Transformer 不需要 KV Cache。
