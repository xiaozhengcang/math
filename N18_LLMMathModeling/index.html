  • 自回归高维联合概率分解：世界上所有书籍与代码都可以写为概率联合乘积 $P(x_1, x_2, \dots, x_T) = \prod_{t=1}^T P(x_t | x_{
  • 上下文学习 (In-Context Learning) 的本质：当你在 Prompt 里给大模型提供 3 个示例（Few-Shot）时，Transformer 并没有更新任何模型权重 $\theta$，但其注意力层在正向传播中隐式执行了一次梯度下降更新 (Implicit Gradient Descent)！
  • 注意力机制低秩流形投影：大模型输入为 4096 维词向量，但在 Transformer 各层中，特征向量始终在极低维的线性子空间流形上旋转与转移。

🧮 2. 严密数学工具与公式推导

上下文学习 (ICL) 隐式梯度更新推导（von Oswald et al., 2023）：

$$\text{Attention}(Q, K, V) = (V + \Delta V) K^T Q \approx V K^T Q - \eta \nabla_{W} \mathcal{L}(W) x$$

线性 Transformer 层的前向传播可精确映射为在 Prompt 示例数据上运行一步梯度下降：

$$W_1 = W_0 - \eta (W_0 X_{\text{prompt}} - Y_{\text{prompt}}) X_{\text{prompt}}^T$$

📄 3. 经典奠基论文核心拆解

论文一：Language Models are Few-Shot Learners (GPT-3, Brown et al., NeurIPS 2020)

核心突破： 1750 亿参数的 GPT-3 奠基之作！首次证明了无需微调微调参数，仅仅依靠 Scaling 扩充参数量与 Prompt 上下文学习 (ICL)，模型就能具备涌现式的多任务推理能力。

论文二：Transformers learn in-context by gradient descent (von Oswald et al., ICML 2023)

核心突破： 揭开了 ICL 的数学黑盒！严格证明了单层 Linear Self-Attention 的正向传播与在 Context 示例上求解最小二乘的内步梯度下降 (Inner Gradient Descent) 的代数等价性。

论文三：What Can Transformers Learn In-Context? (Garg et al., NeurIPS 2022)

核心突破： 通过受控实验证明了未微调的 Transformer 可以在 Context 中隐式学会求解线性回归、岭回归、决策树乃至两层神经网络等经典机器学习算法。

思考题：为什么说 Transformer 的 In-Context Learning (ICL) 是一种“隐式梯度下降”？

A. 因为注意力机制的正向计算过程在代数形式上精确同构于在 Prompt 示例上执行了一次带权重的梯度更新。
B. 因为大模型在 Prompt 阶段更新了模型权重 $\theta$。
