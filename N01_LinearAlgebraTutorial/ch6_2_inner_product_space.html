Ch 6.2: 抽象内积空间与傅里叶级数分解

从“纯代数骨架”跃迁至“几何度量世界”：赋予抽象向量以长度、距离与夹角，深入剖析柯西-施瓦茨不等式的极美证明，并见证傅里叶级数如何作为无穷维函数空间上的正交投影，完美统一代数与信号分析。

💡 认知跃迁：当抽象代数注入“几何度量”的灵魂

在 Ch 6.1 抽象向量空间 中，我们建立了令人震撼的“万物皆向量”世界观：只要满足 8 大代数公理，函数、多项式与矩阵都可以线性组合。

然而，纯粹的向量空间只有“代数骨架”——它只知道加法和数乘，却完全不知道向量的“长短”、向量之间的“距离远近”、更无法判断两个向量是否“垂直正交”！

引入内积 (Inner Product) $\langle \mathbf{u}, \mathbf{v} \rangle$，就是为抽象向量空间注入度量几何 (Metric & Geometry) 的决定性跃迁。一旦有了内积：

📏 长度 (Norm)
$\|\mathbf{v}\| = \sqrt{\langle \mathbf{v}, \mathbf{v} \rangle}$

衡量抽象元素（如函数能量、矩阵大小）的绝对模长。

🎯 距离 (Distance)
$d(\mathbf{u}, \mathbf{v}) = \|\mathbf{u} - \mathbf{v}\|$

定义任意两点间的接近程度，支撑最佳逼近与回归。

📐 夹角与垂直 (Orthogonality)
$\langle \mathbf{u}, \mathbf{v} \rangle = 0 \iff \mathbf{u} \perp \mathbf{v}$

正交性让极其繁琐的线性方程解算瞬间化为纯粹的独立投影！

公理基石

1. 严密奠基：抽象内积公理系统 (Real & Complex)

设 $V$ 是实数域 $\mathbb{R}$（或复数域 $\mathbb{C}$）上的向量空间。所谓内积 (Inner Product)，是一个将任意两个向量 $\mathbf{u}, \mathbf{v} \in V$ 映射到标量域的操作，记作 $\langle \mathbf{u}, \mathbf{v} \rangle$。

📐 实内积空间公理 (Real Inner Product Axioms)

对于实向量空间 $V$ 中的任意向量 $\mathbf{u}, \mathbf{v}, \mathbf{w} \in V$ 及标量 $c \in \mathbb{R}$，映射 $\langle \cdot, \cdot \rangle: V \times V \to \mathbb{R}$ 必须严格无条件满足以下 4 条公理：

① 对称性 (Symmetry)
$$\langle \mathbf{u}, \mathbf{v} \rangle = \langle \mathbf{v}, \mathbf{u} \rangle$$

两个实向量的位置互换，内积值恒定保持不变。

② 第一变元加法分配律 (Additivity)
$$\langle \mathbf{u} + \mathbf{v}, \mathbf{w} \rangle = \langle \mathbf{u}, \mathbf{w} \rangle + \langle \mathbf{v}, \mathbf{w} \rangle$$

第一位置的向量和可拆分为各项与目标向量的独立内积之和。

③ 标量数乘齐次性 (Homogeneity)
$$\langle c\mathbf{u}, \mathbf{v} \rangle = c \langle \mathbf{u}, \mathbf{v} \rangle$$

标量因数可自由提至内积括号外（与加法结合统称第一变元线性性）。

④ 正定性 (Positive Definiteness)
$$\langle \mathbf{u}, \mathbf{u} \rangle \ge 0, \quad \langle \mathbf{u}, \mathbf{u} \rangle = 0 \iff \mathbf{u} = \mathbf{0}$$

自内积永远非负；自内积为零当且仅当向量本身是零向量。

🌐 视野拓展：复内积空间与共轭对称性 (Conjugate Symmetry)

若标量域为复数域 $\mathbb{C}$（如量子力学希尔伯特空间），为了保证自身的内积 $\langle \mathbf{u}, \mathbf{u} \rangle$ 仍是非负实数（物理世界中概率与长度必须为实数），公理 1 必须升级为共轭对称性：

$$\langle \mathbf{u}, \mathbf{v} \rangle = \overline{\langle \mathbf{v}, \mathbf{u} \rangle}$$

此时第二变元的标量数乘满足共轭线性：$\langle \mathbf{u}, c\mathbf{v} \rangle = \bar{c}\langle \mathbf{u}, \mathbf{v} \rangle$。实内积空间则是复内积空间在虚部为零时的自然特例。

🔍 逻辑探微：由内积公理严密推导的基础性质
📌 性质 1：零向量与任何向量的内积必恒为零，即 $\langle \mathbf{0}, \mathbf{v} \rangle = 0$

证明： 根据向量空间公理，零向量可写为 $\mathbf{0} = 0 \cdot \mathbf{0}$。应用内积公理 ③（标量齐次性）：

$$\langle \mathbf{0}, \mathbf{v} \rangle = \langle 0 \cdot \mathbf{0}, \mathbf{v} \rangle = 0 \cdot \langle \mathbf{0}, \mathbf{v} \rangle = 0 \quad \blacksquare$$
📌 性质 2：实内积关于第二变元同样具有线性分配性（双线性 Bilinearity）

证明： 应用对称性与第一变元线性性：

$$\langle \mathbf{u}, c\mathbf{v}_1 + d\mathbf{v}_2 \rangle = \langle c\mathbf{v}_1 + d\mathbf{v}_2, \mathbf{u} \rangle = c\langle \mathbf{v}_1, \mathbf{u} \rangle + d\langle \mathbf{v}_2, \mathbf{u} \rangle = c\langle \mathbf{u}, \mathbf{v}_1 \rangle + d\langle \mathbf{u}, \mathbf{v}_2 \rangle \quad \blacksquare$$
诱导几何

2. 几何度量三要素：范数、柯西-施瓦茨与平行四边形律

一旦内积确立，欧几里得空间的所有经典几何概念立即以完全自然的方式推广到任意抽象向量空间：

1. 诱导范数 (Induced Norm)

向量的模长定义为自内积的非负平方根：

$$\|\mathbf{u}\| = \sqrt{\langle \mathbf{u}, \mathbf{u} \rangle}$$

满足非负性、绝对齐次性 $\|c\mathbf{u}\| = |c| \|\mathbf{u}\|$ 以及三角不等式。

2. 诱导距离与夹角 (Metric & Angle)

两向量之间的距离与夹角余弦值：

$$d(\mathbf{u}, \mathbf{v}) = \|\mathbf{u} - \mathbf{v}\|, \quad \cos \theta = \frac{\langle \mathbf{u}, \mathbf{v} \rangle}{\|\mathbf{u}\| \|\mathbf{v}\|}$$

夹角定义成立的前提是分数绝不超过 1，这由柯西-施瓦茨不等式铁律保证！

👑 分析学第一神盾：柯西-施瓦茨不等式 (Cauchy-Schwarz Inequality)

在任意实内积空间 $V$ 中，对任意两向量 $\mathbf{u}, \mathbf{v} \in V$，恒有：

$$|\langle \mathbf{u}, \mathbf{v} \rangle| \le \|\mathbf{u}\| \, \|\mathbf{v}\|$$

等号成立当且仅当 $\mathbf{u}$ 与 $\mathbf{v}$ 线性相关（即其中一个是另一个的标量倍）。

💡 极其优美的“一元二次多项式判别式法”证明（必读核心）

第一步：平凡情况排除

若 $\mathbf{v} = \mathbf{0}$，则不等式两边皆为 $0$，显然等式成立。下设 $\mathbf{v} \neq \mathbf{0}$，从而 $\|\mathbf{v}\|^2 = \langle \mathbf{v}, \mathbf{v} \rangle > 0$。

第二步：构造一元二次非负函数

对任意实数 $t \in \mathbb{R}$，考虑向量 $\mathbf{u} + t\mathbf{v}$ 的范数平方。由正定性公理，范数平方永远大于等于 0：

$$p(t) = \|\mathbf{u} + t\mathbf{v}\|^2 = \langle \mathbf{u} + t\mathbf{v}, \mathbf{u} + t\mathbf{v} \rangle \ge 0$$

第三步：应用双线性性完全展开

$$p(t) = \langle \mathbf{u}, \mathbf{u} \rangle + 2t \langle \mathbf{u}, \mathbf{v} \rangle + t^2 \langle \mathbf{v}, \mathbf{v} \rangle = A t^2 + B t + C \ge 0$$

其中二次项系数 $A = \|\mathbf{v}\|^2 > 0$，$B = 2\langle \mathbf{u}, \mathbf{v} \rangle$，$C = \|\mathbf{u}\|^2$。

第四步：二次方程判别式审判

一个开口向上的二次函数 $p(t) \ge 0$ 对所有实数 $t$ 恒成立，意味着它在坐标系中最多只能与横轴相切，绝不可能有两个不同实根！因此其判别式必须小于等于零：

$$\Delta = B^2 - 4AC = \big(2\langle \mathbf{u}, \mathbf{v} \rangle\big)^2 - 4 \|\mathbf{v}\|^2 \|\mathbf{u}\|^2 \le 0$$ $$\iff 4 \langle \mathbf{u}, \mathbf{v} \rangle^2 \le 4 \|\mathbf{u}\|^2 \|\mathbf{v}\|^2 \iff |\langle \mathbf{u}, \mathbf{v} \rangle| \le \|\mathbf{u}\| \|\mathbf{v}\| \quad \blacksquare$$

🎯 等号讨论：等号成立意味着 $\Delta = 0$，即存在某个唯一的 $t_0$ 使得 $\|\mathbf{u} + t_0 \mathbf{v}\|^2 = 0$。根据正定性公理，必有 $\mathbf{u} + t_0 \mathbf{v} = \mathbf{0}$，即 $\mathbf{u} = -t_0 \mathbf{v}$，两向量严格线性相关！

🔺 三角不等式 (Triangle Inequality)
$$\|\mathbf{u} + \mathbf{v}\| \le \|\mathbf{u}\| + \|\mathbf{v}\|$$

证明概要：$\|\mathbf{u}+\mathbf{v}\|^2 = \|\mathbf{u}\|^2 + 2\langle \mathbf{u}, \mathbf{v} \rangle + \|\mathbf{v}\|^2 \le \|\mathbf{u}\|^2 + 2\|\mathbf{u}\|\|\mathbf{v}\| + \|\mathbf{v}\|^2 = (\|\mathbf{u}\|+\|\mathbf{v}\|)^2$。开平方即得证！

▱ 平行四边形定则 (Parallelogram Law)
$$\|\mathbf{u} + \mathbf{v}\|^2 + \|\mathbf{u} - \mathbf{v}\|^2 = 2\|\mathbf{u}\|^2 + 2\|\mathbf{v}\|^2$$

两条对角线平方和等于四条边平方和。这是检验一个范数能否由内积诱导的充要准则（Jordan-von Neumann 定理）！

名篇博览

3. 典型抽象内积空间四大名篇

内积不仅仅存在于高中平面几何的点积 $\mathbf{u} \cdot \mathbf{v} = x_1 y_1 + x_2 y_2$。在机器学习、图像处理与工程计算中，不同对象拥有完全量身定制的抽象内积：

CASE 1 加权欧氏内积与马氏距离
$$\langle \mathbf{x}, \mathbf{y} \rangle_W = \mathbf{x}^T W \mathbf{y}$$

只要权重矩阵 $W$ 是对称正定矩阵 (SPD)，该公式完美满足全部 4 条内积公理！ 在统计学与机器学习中，当 $W = \Sigma^{-1}$（协方差逆矩阵）时，诱导的距离正是马氏距离 (Mahalanobis Distance)，能消除各特征方差不一及相关性的干扰。

CASE 2 矩阵空间 $M_{m \times n}$ 上的 Frobenius 内积
$$\langle A, B \rangle_F = \operatorname{tr}(A^T B) = \sum_{i=1}^m \sum_{j=1}^n A_{ij} B_{ij}$$

将矩阵视为展平的超大向量做点积。诱导范数即深度学习中常用的权重衰减正则项 Frobenius 范数 $\|A\|_F = \sqrt{\operatorname{tr}(A^T A)} = \sqrt{\sum A_{ij}^2}$。 例如，对称矩阵与反对称矩阵在此内积下严格垂直正交！

CASE 3 连续函数空间 $C[a, b]$ 上的 $L^2$ 内积
$$\langle f, g \rangle = \int_a^b f(x) g(x) dx$$

离散求和 $\sum x_i y_i$ 在无穷维连续区间的直接极限对应！函数的长度 $\|f\| = \sqrt{\int_a^b f(x)^2 dx}$ 对应信号物理系统中的总能量 (Total Energy)。

CASE 4 加权函数内积与正交多项式族
$$\langle f, g \rangle_w = \int_a^b f(x) g(x) w(x) dx \quad (w(x) > 0)$$

引入正权函数 $w(x)$。当 $w(x)=1$ 时施密特正交化产生勒让德多项式 (Legendre)；当 $w(x)=(1-x^2)^{-1/2}$ 时产生切比雪夫多项式 (Chebyshev)。它们是现代数值计算中最高精度的求积基石！

算法应用

4. 函数空间正交化实战：手工打造勒让德多项式 (Legendre)

在多项式空间 $P_2[-1, 1]$ 中，单项式基 $\{1, x, x^2\}$ 极其直观，但它们彼此并不正交（例如 $\langle 1, x^2 \rangle = \int_{-1}^1 x^2 dx = \frac{2}{3} \neq 0$）。 用不正交的基做曲线拟合会导致著名的希尔伯特病态矩阵 (Hilbert Matrix)，数值条件数极度恶化。

现在，我们在区间 $[-1, 1]$ 上利用内积 $\langle f, g \rangle = \int_{-1}^1 f(x)g(x)dx$，对标准基 $\{v_0 = 1, v_1 = x, v_2 = x^2\}$ 执行标准的 Gram-Schmidt 正交化算法：

✍️ 步骤剖析：前三阶勒让德正交基的手工推导

① 第一个基向量：

$$P_0(x) = v_0(x) = 1, \quad \|P_0\|^2 = \int_{-1}^1 1^2 dx = 2$$

② 第二个基向量（投影消除）：

$$P_1(x) = v_1(x) - \frac{\langle v_1, P_0 \rangle}{\|P_0\|^2} P_0(x)$$

由于 $\langle x, 1 \rangle = \int_{-1}^1 x dx = 0$（奇函数在对称区间积分），所以分子为 0！

$$P_1(x) = x - 0 = x, \quad \|P_1\|^2 = \int_{-1}^1 x^2 dx = \left[\frac{x^3}{3}\right]_{-1}^1 = \frac{2}{3}$$

③ 第三个基向量（消除在 $P_0$ 和 $P_1$ 上的投影分量）：

$$P_2(x) = v_2(x) - \frac{\langle v_2, P_0 \rangle}{\|P_0\|^2} P_0(x) - \frac{\langle v_2, P_1 \rangle}{\|P_1\|^2} P_1(x)$$

计算各内积项：

  • $\langle v_2, P_0 \rangle = \int_{-1}^1 x^2 \cdot 1 dx = \frac{2}{3}$
  • $\langle v_2, P_1 \rangle = \int_{-1}^1 x^2 \cdot x dx = \int_{-1}^1 x^3 dx = 0$（奇函数积分）

代入公式：

$$P_2(x) = x^2 - \frac{2/3}{2} \cdot 1 - 0 \cdot x = x^2 - \frac{1}{3}$$

（数学界传统习惯将端点值标准化为 $P_n(1) = 1$，乘以比例常数 $\frac{3}{2}$ 即得标准型 $\frac{1}{2}(3x^2 - 1)$）。

理论巅峰

5. 🎵 傅里叶级数：无穷维函数空间中的正交投影本质

现在，我们揭晓线性代数中最震撼的统一画卷之一：傅里叶级数 (Fourier Series) 本质上正是无穷维函数空间上的正交投影分解！

在欧几里得几何 $\mathbb{R}^3$ 中，如果一组基底 $\{\mathbf{e}_1, \mathbf{e}_2, \mathbf{e}_3\}$ 是两两相互垂直的正交基，我们要把任意向量 $\mathbf{v}$ 分解为坐标组合 $\mathbf{v} = c_1 \mathbf{e}_1 + c_2 \mathbf{e}_2 + c_3 \mathbf{e}_3$，根本不需要做任何高斯消元或求逆矩阵！两边直接与 $\mathbf{e}_k$ 作内积：

$$\langle \mathbf{v}, \mathbf{e}_k \rangle = c_k \langle \mathbf{e}_k, \mathbf{e}_k \rangle \implies c_k = \frac{\langle \mathbf{v}, \mathbf{e}_k \rangle}{\|\mathbf{e}_k\|^2}$$

交叉项全部因为正交性而消失（$\langle \mathbf{e}_i, \mathbf{e}_k \rangle = 0$）。正是正交性让每个坐标的求解完全解耦！

📐 区间 $[-\pi, \pi]$ 上的三角函数正交基族

考虑集合 $\{1, \cos(x), \sin(x), \cos(2x), \sin(2x), \dots, \cos(nx), \sin(nx), \dots\}$，在内积 $\langle f, g \rangle = \int_{-\pi}^\pi f(x)g(x)dx$ 下：

$$\int_{-\pi}^\pi \cos(nx) \sin(mx) dx = 0 \quad (\forall n, m)$$
偶函数 $\times$ 奇函数 = 奇函数，对称积分恒为 0
$$\int_{-\pi}^\pi \cos(nx) \cos(mx) dx = \begin{cases} 0 & n \ne m \\ \pi & n = m \ge 1 \end{cases}$$
同频同相积分长度为 $\sqrt{\pi}$
$$\int_{-\pi}^\pi 1^2 dx = 2\pi \implies \|1\|^2 = 2\pi$$
常数基底的范数平方为 $2\pi$

因此，周期为 $2\pi$ 的任意函数 $f(x)$ 展开为傅里叶级数：

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty \Big( a_n \cos(nx) + b_n \sin(nx) \Big)$$

各个傅里叶系数不过是正交投影在各基底上的坐标标量：

直流均值投影：
$$a_0 = \frac{\langle f, 1 \rangle}{\|1\|^2 / 2} = \frac{1}{\pi} \int_{-\pi}^\pi f(x) dx$$
余弦基正交投影坐标：
$$a_n = \frac{\langle f, \cos(nx) \rangle}{\|\cos(nx)\|^2} = \frac{1}{\pi} \int_{-\pi}^\pi f(x) \cos(nx) dx$$
正弦基正交投影坐标：
$$b_n = \frac{\langle f, \sin(nx) \rangle}{\|\sin(nx)\|^2} = \frac{1}{\pi} \int_{-\pi}^\pi f(x) \sin(nx) dx$$

🎯 最佳平方逼近定理 (Best Approximation)

如果将级数截断到前 $N$ 阶频率，所得部分和 $S_N(x) = \frac{a_0}{2} + \sum_{n=1}^N (a_n \cos nx + b_n \sin nx)$，是在有限维三角多项式子空间 $W_N$ 中，与目标原函数 $f(x)$ 距离 $\|f - S_N\|^2$ 最近的唯一元素！ 垂线距离最短，残差误差向量 $(f - S_N)$ 与子空间中所有基函数严格正交。

⚡ 帕塞瓦尔恒等式：无穷维勾股定理 (Parseval's Identity)

在几何中，三维向量的模长平方等于各直角坐标平方和 $\|v\|^2 = x^2 + y^2 + z^2$。在无穷维希尔伯特空间中，函数的总能量正好等于各频域谐波坐标平方和：

$$\frac{1}{\pi} \int_{-\pi}^\pi |f(x)|^2 dx = \frac{a_0^2}{2} + \sum_{n=1}^\infty (a_n^2 + b_n^2)$$
交互实验

6. 🔬 双视图交互实验台：正交基波形合成与频域投影谱

切换不同周期的目标信号波形，拖动滑块增加谐波项数 $N$。观察左侧时域波形如何逼近目标（以及在间断点处的吉布斯现象 Gibbs Phenomenon），同时在右侧观察其在各正交三角基底上的坐标投影谱：

7. ✍️ 经典题解：方波正交投影系数完整分步积分推导

题目：设周期为 $2\pi$ 的标准对称方波在 $[-\pi, \pi]$ 上定义为：

$$f(x) = \begin{cases} -1, & -\pi \le x < 0 \\ +1, & 0 \le x < \pi \end{cases}$$

求其傅里叶正交投影级数。

第一步：利用对称性简化内积计算

注意到 $f(-x) = -f(x)$，原函数是严格的奇函数。 由于常数 $1$ 与余弦函数 $\cos(nx)$ 均为偶函数，奇函数与偶函数的乘积仍为奇函数，在关于原点对称的区间 $[-\pi, \pi]$ 上积分恒等于零！

$$a_0 = \frac{1}{\pi} \int_{-\pi}^\pi f(x) dx = 0, \quad a_n = \frac{1}{\pi} \int_{-\pi}^\pi f(x) \cos(nx) dx = 0 \quad (\forall n \ge 1)$$

因此该函数在直流基与所有余弦正交基上的投影分量完全为零！

第二步：计算在正弦正交基上的投影坐标 $b_n$

奇函数 $\times$ 奇函数 $\sin(nx)$ = 偶函数。利用对称区间的偶函数积分性质：

$$b_n = \frac{1}{\pi} \int_{-\pi}^\pi f(x) \sin(nx) dx = \frac{2}{\pi} \int_0^\pi (+1) \cdot \sin(nx) dx = \frac{2}{\pi} \left[ -\frac{\cos(nx)}{n} \right]_0^\pi = \frac{2}{n\pi} \big( 1 - \cos(n\pi) \big)$$

第三步：奇偶谐波分情况讨论

因为 $\cos(n\pi) = (-1)^n$：

  • 当 $n$ 为偶数时，$\cos(n\pi) = 1$，分子 $1 - 1 = 0 \implies b_n = 0$；
  • 当 $n$ 为奇数时，$\cos(n\pi) = -1$，分子 $1 - (-1) = 2 \implies b_n = \frac{4}{n\pi}$。

第四步：写出最终正交投影坐标级数

$$f(x) = \frac{4}{\pi} \left( \sin x + \frac{1}{3}\sin(3x) + \frac{1}{5}\sin(5x) + \frac{1}{7}\sin(7x) + \dots \right)$$

💡 副产物大惊喜（莱布尼茨 $\pi$ 公式）：令 $x = \frac{\pi}{2}$，此时 $f(\frac{\pi}{2}) = 1$，$\sin(\frac{n\pi}{2}) = 1, 0, -1, 0, \dots$。 代入即得著名的级数 $1 = \frac{4}{\pi} (1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \dots) \implies \frac{\pi}{4} = 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \dots$！

8. 💻 科学计算实战：NumPy 矩阵内积与 SciPy 连续积分投影

以下代码涵盖了从离散矩阵 Frobenius 内积到连续函数高精度数值积分，并检验帕塞瓦尔能量守恒的完整工业级实现： 

import numpy as np
import scipy.integrate as integrate

# ==========================================
# 1. 矩阵空间上的 Frobenius 抽象内积与夹角
# ==========================================
def matrix_inner_product(A, B):
    """计算矩阵空间的 Frobenius 内积 ⟨A, B⟩ = tr(A^T B)"""
    return np.trace(A.T @ B)

A = np.array([[1.0, 2.0], [3.0, 4.0]])
B = np.array([[2.0, -1.0], [0.0, 1.0]])

inner_AB = matrix_inner_product(A, B)
norm_A = np.sqrt(matrix_inner_product(A, A))  # 等价于 np.linalg.norm(A, 'fro')
norm_B = np.sqrt(matrix_inner_product(B, B))
cos_theta = inner_AB / (norm_A * norm_B)

print(f"=== 矩阵 Frobenius 内积 ===")
print(f"内积 ⟨A, B⟩: {inner_AB:.4f}")
print(f"||A||_F: {norm_A:.4f}, ||B||_F: {norm_B:.4f}")
print(f"两矩阵夹角余弦 cos(theta): {cos_theta:.4f} (角度: {np.degrees(np.arccos(cos_theta)):.2f}°)\n")

# ==========================================
# 2. 连续函数空间 L^2 高精度数值正交投影
# ==========================================
def compute_fourier_coeffs(f_func, N=5):
    """利用 SciPy 数值积分计算函数 f 在 [-pi, pi] 上的前 N 阶傅里叶正交投影坐标"""
    # a0 坐标: (1/pi) * integral(f(x) dx)
    a0, _ = integrate.quad(f_func, -np.pi, np.pi)
    a0 /= np.pi
    
    an = np.zeros(N)
    bn = np.zeros(N)
    for n in range(1, N + 1):
        an_val, _ = integrate.quad(lambda x: f_func(x) * np.cos(n * x), -np.pi, np.pi)
        bn_val, _ = integrate.quad(lambda x: f_func(x) * np.sin(n * x), -np.pi, np.pi)
        an[n - 1] = an_val / np.pi
        bn[n - 1] = bn_val / np.pi
    return a0, an, bn

# 测试对称方波: x < 0 时为 -1, x >= 0 时为 1
square_func = lambda x: 1.0 if x >= 0 else -1.0
a0, an, bn = compute_fourier_coeffs(square_func, N=5)

print(f"=== 方波正交投影傅里叶坐标 ===")
print(f"a0 (直流分量): {a0:.6f}")
for n in range(1, 6):
    print(f"谐波阶数 n={n}: an={an[n-1]:.4f}, bn={bn[n-1]:.4f} (理论值 4/(n*pi): {4/(n*np.pi) if n%2==1 else 0:.4f})")

# ==========================================
# 3. 帕塞瓦尔恒等式能量守恒验证
# ==========================================
total_energy, _ = integrate.quad(lambda x: square_func(x)**2, -np.pi, np.pi)
total_energy /= np.pi  # (1/pi) * integral(f^2 dx) = 2.0

reconstructed_energy = 0.5 * (a0**2) + np.sum(an**2 + bn**2)
print(f"\n=== 帕塞瓦尔能量守恒对比 ===")
print(f"原时域信号能量: {total_energy:.4f}")
print(f"前 5 阶频域谐波能量累加: {reconstructed_energy:.4f} (能量捕获率: {reconstructed_energy/total_energy * 100:.2f}%)")
