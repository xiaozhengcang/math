向量与矩阵范数、算子理论与摄动分析

在经典线性代数中，我们通过坐标与基底探讨向量空间的代数结构；而在矩阵分析（Matrix Analysis）中，我们必须为空间赋予长度、距离与连续性拓扑。从测量信号大小的向量 $L_p$ 范数，到衡量线性系统最大拉伸倍率的诱导算子范数，再到量化矩阵低秩稀疏性的核范数与数值稳定性的条件数——范数是连接代数、连续分析与现代凸优化的第一基石。

1. 从几何长度到抽象度量：范数三公理

在任意实向量空间 $V$（如 $\mathbb{R}^n$ 或矩阵空间 $\mathbb{R}^{m \times n}$）中，一个函数 $\|\cdot\|: V \to \mathbb{R}$ 要成为合法的范数 (Norm)，必须且只需无条件满足以下三大公理：

① 正定性 (Positivity)

$\|x\| \ge 0$ 恒成立，且：

$\|x\| = 0 \iff x = \mathbf{0}$

非零物体的“尺度”必定严格为正，只有绝对虚无的零向量长度才为零。

② 绝对齐次性 (Absolute Homogeneity)

对任意标量 $\alpha \in \mathbb{R}$ 与向量 $x \in V$：

$\|\alpha x\| = |\alpha| \cdot \|x\|$

向量被拉伸 $\alpha$ 倍，其度量尺度严格以 $|\alpha|$ 倍同比缩放。

③ 三角不等式 (Subadditivity)

对任意向量 $x, y \in V$：

$\|x + y\| \le \|x\| + \|y\|$

“两点之间线段最短”的纯代数推广，也是度量诱导凸集的核心保证。

1.1 经典向量 $L_p$ 范数家族

对任意实数 $p \ge 1$，$\mathbb{R}^n$ 上的 $L_p$ 范数严格定义为：

$$ \|x\|_p = \left( \sum_{i=1}^n |x_i|^p \right)^{1/p} $$ 三大核心极限特例：
  • 曼哈顿范数 ($L_1$)：$\|x\|_1 = \sum_{i=1}^n |x_i|$，网格街区折线距离；在机器学习中诱导稀疏解（Lasso 回归）。
  • 欧几里得范数 ($L_2$)：$\|x\|_2 = \sqrt{\sum_{i=1}^n x_i^2} = \sqrt{x^T x}$，经典物理刚体直尺距离。
  • 切比雪夫范数 ($L_\infty$)：$\|x\|_\infty = \lim_{p \to \infty} \|x\|_p = \max_{1 \le i \le n} |x_i|$，最大分量绝对值。
⚠️ 致命陷阱：为什么当 $0 \lt p \lt 1$ 时不能称为范数？

当 $p \lt 1$ 时，函数破坏了三角不等式！例如在 $\mathbb{R}^2$ 中取 $x = (1, 0)^T, y = (0, 1)^T$，在 $p = 0.5$ 下： $\|x\|_{0.5} = (1^{0.5} + 0)^{2} = 1$，$\|y\|_{0.5} = 1$。但 $\|x + y\|_{0.5} = (1^{0.5} + 1^{0.5})^2 = 4 \gt \|x\|_{0.5} + \|y\|_{0.5} = 2$。其单位球是向内凹陷的“星形”，不是凸集！

3. 对偶范数 (Dual Norm) 与极值支撑

对任意赋范向量空间 $(\mathbb{R}^n, \|\cdot\|)$，其对偶范数 (Dual Norm) $\|\cdot\|_*$ 衡量了一个线性泛函在该范数单位球上的最大可能投影：

$$ \|y\|_* \triangleq \sup_{x \ne \mathbf{0}} \frac{y^T x}{\|x\|} = \sup_{\|x\| \le 1} y^T x $$ 核心共轭对偶定理： 若 $1 \le p, q \le \infty$ 且满足共轭倒数关系 $\frac{1}{p} + \frac{1}{q} = 1$，则： $$ (\|\cdot\|_p)_* = \|\cdot\|_q $$
  • $L_2$ 范数是自对偶的：$\frac{1}{2} + \frac{1}{2} = 1 \implies (\|\cdot\|_2)_* = \|\cdot\|_2$；
  • $L_1$ 与 $L_\infty$ 互为对偶：$(\|\cdot\|_1)_* = \|\cdot\|_\infty$，且 $(\|\cdot\|_\infty)_* = \|\cdot\|_1$；
  • 推广的 Hölder 不等式：对任意 $x, y$，恒有 $|x^T y| \le \|x\| \cdot \|y\|_*$。

4. 矩阵诱导算子范数 (Induced Operator Norm)

当矩阵 $A \in \mathbb{R}^{m \times n}$ 作为一个线性映射 $x \mapsto Ax$ 时，我们最关心的是：该算子最多能将原向量拉伸放大多少倍？ 这就自然引出了由向量范数诱导出的算子范数：

$$ \|A\|_{p, q} \triangleq \sup_{x \ne \mathbf{0}} \frac{\|Ax\|_q}{\|x\|_p} = \sup_{\|x\|_p = 1} \|Ax\|_q $$ 通常两端采用相同的向量范数，记为 $\|A\|_p \equiv \|A\|_{p, p}$。三大核心算子范数拥有优美的代数闭式：
1-算子范数 (列和范数)

$\|A\|_1 = \max_{1 \le j \le n} \sum_{i=1}^m |a_{ij}|$

几何意义：矩阵所有列向量的 $L_1$ 模长之最大值（最大列绝对值和）。

2-算子范数 (谱范数)

$\|A\|_2 = \sigma_{\max}(A) = \sqrt{\lambda_{\max}(A^T A)}$

几何意义：单位欧氏超球被 $A$ 扭曲为超椭球后的最大半长轴长度（最大奇异值）。

$\infty$-算子范数 (行和范数)

$\|A\|_\infty = \max_{1 \le i \le m} \sum_{j=1}^n |a_{ij}|$

几何意义：矩阵所有行向量的 $L_1$ 模长之最大值（最大行绝对值和）。

4.1 谱范数 $\|A\|_2 = \sigma_{\max}(A)$ 严格数学证明

证明目标：证明 $\|A\|_2 = \sup_{\|x\|_2 = 1} \|Ax\|_2$ 严格等于 $A$ 的最大奇异值 $\sigma_{\max}$。

  1. 由欧几里得模长与转置点积性质： $$ \|Ax\|_2^2 = (Ax)^T (Ax) = x^T (A^T A) x $$
  2. 因为 $A^T A \in \mathbb{R}^{n \times n}$ 必然是实对称半正定矩阵，根据谱分解定理，存在正交矩阵 $Q = [q_1, \dots, q_n]$ 与实特征值 $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_n \ge 0$，使得 $A^T A = Q \Lambda Q^T$。
  3. 设 $y = Q^T x$。由于 $Q$ 保持欧氏长度不变，$\|y\|_2 = \|x\|_2 = 1$。代入得： $$ x^T (A^T A) x = y^T \Lambda y = \sum_{i=1}^n \lambda_i y_i^2 \le \lambda_1 \sum_{i=1}^n y_i^2 = \lambda_1 = \lambda_{\max}(A^T A) $$
  4. 当且仅当取 $x = q_1$（最大特征值对应的特征向量）时，等号严格成立！
  5. 因此，$\|A\|_2 = \sqrt{\sup_{\|x\|_2 = 1} x^T A^T A x} = \sqrt{\lambda_{\max}(A^T A)} = \sigma_{\max}(A)$。证毕。

5. 元素型范数、核范数与 Schatten 谱系

除了把矩阵视作拉伸算子，我们还可以把矩阵直接视作 $\mathbb{R}^{m \times n}$ 空间中的“大长向量”，或者通过矩阵的全部奇异值谱系进行度量：

范数类型 数学定义 与奇异值的深层联系 主要应用场景
Frobenius 范数 $\|A\|_F = \sqrt{\sum_{i=1}^m \sum_{j=1}^n a_{ij}^2}$ $\|A\|_F = \sqrt{\operatorname{tr}(A^T A)} = \sqrt{\sum_{i=1}^r \sigma_i^2}$ 最小二乘误差度量、数值逼近、深度学习权重衰减
核范数 / 迹范数 (Nuclear Norm) $\|A\|_* = \operatorname{tr}(\sqrt{A^T A})$ $\|A\|_* = \sum_{i=1}^r \sigma_i$ (奇异值之和) 低秩矩阵恢复、压缩感知、Netflix 电影推荐矩阵补全
Schatten $p$-范数 $\|A\|_{S_p} = \left( \sum_{i=1}^r \sigma_i^p \right)^{1/p}$ 当 $p=1$ 为核范数；$p=2$ 为 F 范数；$p=\infty$ 为谱范数 量子信息理论、非交换几何、多准则正则化优化
🔥 核心思想升华：核范数为什么是“秩函数”的最佳凸松弛？

在向量优化中，求非零元素个数的 $\operatorname{card}(x) = \|x\|_0$ 是 NP-hard 的非凸问题，其在单位球内的凸包 (Convex Envelope) 恰好是 $L_1$ 范数 $\|x\|_1$；
同理，在矩阵优化中，矩阵的秩 $\operatorname{rank}(A)$ 等于非零奇异值的个数。在谱范数单位球内，$\operatorname{rank}(A)$ 的最优凸近似正是核范数 $\|A\|_* = \sum \sigma_i$！这使得极其困难的非凸低秩优化，能被转化为凸半定规划 (SDP) 在多项式时间内完美求解！

6. 矩阵条件数与方程组摄动界 (Perturbation Bounds)

在实际计算中，浮点数舍入或物理观测误差不可避免。假设精确线性系统为 $Ax = b$，当系数矩阵与右端项存在微小噪声扰动时： $$ (A + \Delta A)(x + \Delta x) = b + \Delta b $$ 误差解 $\Delta x$ 会被放大多少？答案完全取决于矩阵的条件数 (Condition Number)：

$$ \kappa(A) \triangleq \|A\| \cdot \|A^{-1}\| $$ 在 2-范数下，条件数直接由矩阵的最大奇异值与最小奇异值决定： $$ \kappa_2(A) = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)} \ge 1 $$ 经典摄动界定理 (Perturbation Bound)：若 $\|\Delta A\| \cdot \|A^{-1}\| \lt 1$，则相对误差满足严格界： $$ \frac{\|\Delta x\|}{\|x\|} \le \frac{\kappa(A)}{1 - \kappa(A) \frac{\|\Delta A\|}{\|A\|}} \left( \frac{\|\Delta A\|}{\|A\|} + \frac{\|\Delta b\|}{\|b\|} \right) $$

物理直觉：如果 $\kappa(A) \approx 1$（如正交矩阵），误差完全不被放大，称为良态 (Well-conditioned)；如果 $\kappa(A) = 10^8$，输入端百万分之一的微小噪声就会导致输出解产生 $100\%$ 的荒谬震荡，此时矩阵接近奇异，称为病态 (Ill-conditioned)。

7. Python NumPy / SciPy 高精度代码实战

以下代码演示了如何使用 NumPy 与 SciPy 计算各类向量/算子/Schatten 范数，并实测病态 Hilbert 矩阵在微小扰动下的解发散实验： 

import numpy as np
from scipy.linalg import hilbert

# 1. 构造一个测试矩阵 A
A = np.array([[3.0, 1.0],
              [1.0, 2.0]])

# 2. 算子范数计算
norm_1 = np.linalg.norm(A, 1)          # 列和范数
norm_inf = np.linalg.norm(A, np.inf)   # 行和范数
norm_2 = np.linalg.norm(A, 2)          # 谱范数 (最大奇异值)
norm_fro = np.linalg.norm(A, 'fro')    # Frobenius 范数

# 奇异值分解验证谱范数与核范数
U, S, Vt = np.linalg.svd(A)
norm_nuclear = np.sum(S)               # 核范数: 奇异值之和

print(f"||A||_1 (列和): {norm_1:.4f}")
print(f"||A||_inf (行和): {norm_inf:.4f}")
print(f"||A||_2 (谱范数/最大奇异值): {norm_2:.4f} (验证: S_max = {S[0]:.4f})")
print(f"||A||_F (Frobenius): {norm_fro:.4f}")
print(f"||A||_* (核范数): {norm_nuclear:.4f}")

# 3. 病态矩阵扰动实验 (以 6 阶 Hilbert 矩阵为例)
H = hilbert(6)
cond_H = np.linalg.cond(H, 2)
print(f"\n6 阶 Hilbert 矩阵的条件数 κ(H): {cond_H:.2e}")

# 精确方程 Hx = b
x_true = np.ones(6)
b = H @ x_true

# 添加 10^-8 量级的极小扰动
delta_b = np.random.randn(6) * 1e-8
b_perturbed = b + delta_b

# 求解扰动系统
x_perturbed = np.linalg.solve(H, b_perturbed)
rel_error = np.linalg.norm(x_perturbed - x_true) / np.linalg.norm(x_true)
print(f"输入端扰动 ||Δb||/||b||: {np.linalg.norm(delta_b)/np.linalg.norm(b):.2e}")
print(f"输出解相对误差 ||Δx||/||x||: {rel_error:.2e} (发散了 {rel_error / (np.linalg.norm(delta_b)/np.linalg.norm(b)):.1f} 倍!)")
