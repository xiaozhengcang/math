高阶分析篇 MA 06 全微分迹技巧与高阶凸优化

矩阵微积分、全微分迹技巧与高阶凸优化

在深度学习反向传播、统计学极大似然估计与现代凸优化中，变量常常是高维矩阵（如神经网络权重矩阵、高斯协方差矩阵）。如果逐个对矩阵元素 $x_{ij}$ 偏导再拼接，过程极易混乱且失去代数结构。本章我们将介绍矩阵求导的终极利器——全微分迹技巧 (Trace Trick Method)：以一阶微分 $df = \operatorname{tr}((\nabla f)^T dX)$ 为统帅，配合迹的循环置换性质，瞬间推导包括 $\ln\operatorname{det}(X)$、二次型与矩阵逆在内的复杂闭式导数！

1. 布局约定规范与全微分迹技巧 (Trace Trick)

在矩阵微积分中，最大的混乱来源是分子布局 (Numerator Layout) 与分母布局 (Denominator Layout) 的转置争议。在现代机器学习与优化理论中，我们严格采用分母布局（Gradient 视角）：

分母布局黄金法则：标量函数 $f(X)$ 对矩阵 $X \in \mathbb{R}^{m \times n}$ 的导数，其形状严格保持与自变量矩阵 $X$ 一致： $$ \frac{\partial f}{\partial X} \in \mathbb{R}^{m \times n}, \quad \left( \frac{\partial f}{\partial X} \right)_{ij} = \frac{\partial f}{\partial x_{ij}} $$

1.1 为什么全微分法是唯一不会出错的求导方法？

无论维度多么复杂，一阶全微分 $df$ 永远是一个纯标量。利用矩阵内积与迹的恒等式，多元全微分严格等价于：

$$ df = \sum_{i=1}^m \sum_{j=1}^n \frac{\partial f}{\partial x_{ij}} dx_{ij} = \operatorname{tr}\left( \left( \frac{\partial f}{\partial X} \right)^T dX \right) $$ 迹技巧三步求导心法：
  1. 对标量函数 $f(X)$ 两边直接求全微分 $df$；
  2. 如果结果不是迹形式，在最外层套上迹算子（因为标量的迹等于其自身：$df = \operatorname{tr}(df)$）；
  3. 利用矩阵迹的循环移位不变性 $\operatorname{tr}(ABC) = \operatorname{tr}(BCA) = \operatorname{tr}(CAB)$，将微分项 $dX$ 稳稳挪移到最右端： $$ df = \operatorname{tr}(M \cdot dX) $$ 对比定义式立即得出：$\left( \frac{\partial f}{\partial X} \right)^T = M \implies \frac{\partial f}{\partial X} = M^T$！绝无转置混淆！

2. 矩阵常用全微分公式表

在计算全微分 $df$ 时，以下基本运算法则是求导大厦的积木：

原矩阵函数 全微分公式 $d(\cdot)$ 证明核心要点
线性项 $A X B$ $d(A X B) = A (dX) B$ 微分算子的线性性，$A, B$ 为常数矩阵
矩阵乘积 $X Y$ $d(XY) = (dX)Y + X(dY)$ 莱布尼茨乘积法则，注意保持非交换顺序
逆矩阵 $X^{-1}$ $d(X^{-1}) = -X^{-1} (dX) X^{-1}$ 微分恒等式 $d(X X^{-1}) = d(I) = \mathbf{0} \implies (dX)X^{-1} + X d(X^{-1}) = \mathbf{0}$
行列式 $\operatorname{det}(X)$ $d(\operatorname{det} X) = \operatorname{det}(X) \operatorname{tr}(X^{-1} dX)$ Jacobi 公式，由代数余子式展开求导获得
对数行列式 $\ln\operatorname{det}(X)$ $d(\ln\operatorname{det} X) = \operatorname{tr}(X^{-1} dX)$ 链式法则：$d(\ln u) = \frac{du}{u} = \frac{\operatorname{det}(X) \operatorname{tr}(X^{-1} dX)}{\operatorname{det}(X)}$

3. 工业级经典导数无跳步推导

3.1 二次型求导：$f(x) = x^T A x$

推导：

$$ df = d(x^T) A x + x^T A (dx) = (dx)^T A x + x^T A dx $$ 由于 $(dx)^T A x$ 是标量，其转置等于自身：$( (dx)^T A x )^T = x^T A^T dx$。代入得： $$ df = x^T A^T dx + x^T A dx = x^T (A + A^T) dx = \left( (A + A^T) x \right)^T dx $$ 由定义 $df = (\nabla f)^T dx$，直接对照得出： $$ \frac{\partial (x^T A x)}{\partial x} = (A + A^T)x $$ 若 $A$ 是对称矩阵（$A = A^T$），则结果优美地退化为标量二次导数的对应物：$2Ax$！

3.2 矩阵逆的迹求导：$f(X) = \operatorname{tr}(X^{-1})$

推导：

$$ df = d(\operatorname{tr}(X^{-1})) = \operatorname{tr}(d(X^{-1})) = \operatorname{tr}(-X^{-1} (dX) X^{-1}) $$ 利用迹的循环移位性质，将右端的 $X^{-1}$ 旋转到最左侧： $$ df = \operatorname{tr}\left( (-X^{-1} X^{-1}) dX \right) = \operatorname{tr}\left( (-X^{-2}) dX \right) $$ 根据全微分对照式 $df = \operatorname{tr}(M \cdot dX) \implies \frac{\partial f}{\partial X} = M^T$： $$ \frac{\partial \operatorname{tr}(X^{-1})}{\partial X} = -(X^{-2})^T = -(X^{-T})^2 $$

3.3 统计学之王：$f(X) = \ln\operatorname{det}(X)$ 对矩阵求导

推导：

由 Jacobi 公式全微分： $$ df = \operatorname{tr}(X^{-1} dX) $$ 此时 $dX$ 已经在最右侧！前面的矩阵是 $M = X^{-1}$。因此其转置为： $$ \frac{\partial \ln\operatorname{det}(X)}{\partial X} = (X^{-1})^T = X^{-T} $$ 若 $X$ 为对称正定矩阵（协方差矩阵），则直接有：$\frac{\partial \ln\operatorname{det}(X)}{\partial X} = X^{-1}$！这使得求解高斯极大似然估计在一步之内完成！

4. 现代应用：多元高斯极大似然估计 (Gaussian MLE) 全推导

设观测到 $N$ 个独立同分布的零均值多元高斯样本 $y_1, \dots, y_N \in \mathbb{R}^p$。样本协方差矩阵为 $S = \frac{1}{N} \sum_{i=1}^N y_i y_i^T$。求高斯分布真实协方差矩阵 $\Sigma \succ 0$ 的极大似然估计：

目标函数：对数似然函数为：

$$ \ell(\Sigma) = -\frac{N p}{2} \ln(2\pi) - \frac{N}{2} \ln\operatorname{det}(\Sigma) - \frac{N}{2} \operatorname{tr}(\Sigma^{-1} S) $$ 我们对未知协方差矩阵 $\Sigma$ 求全微分：
  1. 第一项常数微分 $d(\text{const}) = 0$；
  2. 第二项利用对数行列式微分：$d(-\frac{N}{2} \ln\operatorname{det}\Sigma) = -\frac{N}{2} \operatorname{tr}(\Sigma^{-1} d\Sigma)$；
  3. 第三项利用逆矩阵微分：$d(-\frac{N}{2} \operatorname{tr}(\Sigma^{-1} S)) = -\frac{N}{2} \operatorname{tr}( -\Sigma^{-1} (d\Sigma) \Sigma^{-1} S ) = \frac{N}{2} \operatorname{tr}( \Sigma^{-1} S \Sigma^{-1} d\Sigma )$；
  4. 合并全微分： $$ d\ell = \operatorname{tr}\left( \left[ -\frac{N}{2} \Sigma^{-1} + \frac{N}{2} \Sigma^{-1} S \Sigma^{-1} \right] d\Sigma \right) $$
  5. 令导数等于零矩阵： $$ -\frac{N}{2} \Sigma^{-1} + \frac{N}{2} \Sigma^{-1} S \Sigma^{-1} = \mathbf{0} \implies \Sigma^{-1} = \Sigma^{-1} S \Sigma^{-1} $$
  6. 两边左右同乘以 $\Sigma$，直接得到无可辩驳的经典大一统结论： $$ \hat{\Sigma}_{\text{MLE}} = S = \frac{1}{N} \sum_{i=1}^N y_i y_i^T $$

5. Python 实战：符号推导与数值差分梯度双重验证

import numpy as np

# 目标函数: f(X) = ln(det(X)) + tr(A @ X^-1)
n = 3
np.random.seed(42)
X = np.random.randn(n, n)
X = X @ X.T + 2 * np.eye(n) # 保证正定
A = np.random.randn(n, n)

def f(M):
    return np.log(np.linalg.det(M)) + np.trace(A @ np.linalg.inv(M))

# 1. 理论解析梯度 (由迹技巧推导):
# ∇f(X) = X^-T - (X^-1 @ A @ X^-1)^T
X_inv = np.linalg.inv(X)
grad_analytical = X_inv.T - (X_inv @ A @ X_inv).T

# 2. 有限差分数值梯度 (Numerical Gradient)
eps = 1e-6
grad_numerical = np.zeros_like(X)
for i in range(n):
    for j in range(n):
        X_pos = X.copy(); X_pos[i, j] += eps
        X_neg = X.copy(); X_neg[i, j] -= eps
        grad_numerical[i, j] = (f(X_pos) - f(X_neg)) / (2 * eps)

# 3. 对比理论导数与数值模拟导数的吻合度
rel_error = np.linalg.norm(grad_analytical - grad_numerical) / np.linalg.norm(grad_analytical)
print(f"解析梯度与数值差分梯度的相对误差: {rel_error:.2e}")
assert rel_error < 1e-5
print("矩阵迹技巧求导公式 100% 验证精确无误！")
