Ch 4.3: 子空间与四大基本子空间剖析

核心概念

1. 什么是子空间？三大检验公理与几何本质

设 $V$ 是 $\mathbb{R}^n$ 的子集，若 $V$ 在向量加法与标量乘法下依然保持封闭，则 $V$ 称为 $\mathbb{R}^n$ 的一个子空间 (Subspace)：

公理 1：包含零向量

$\mathbf{0} \in V$。任何脱离原点锚定的几何体都绝不是向量子空间！

公理 2：加法封闭性

$\forall \mathbf{u}, \mathbf{v} \in V \implies \mathbf{u} + \mathbf{v} \in V$。平行四边形对角线不逃逸。

公理 3：数乘封闭性

$\forall \mathbf{u} \in V, c \in \mathbb{R} \implies c\mathbf{u} \in V$。射线双向无限伸缩依然在集合内。

🧪 典型反例：为什么直线 $x + y = 1$ 不是子空间？

取 $\mathbf{u} = \begin{bmatrix} 1 \\ 0 \end{bmatrix} \in L$ 和 $\mathbf{v} = \begin{bmatrix} 0 \\ 1 \end{bmatrix} \in L$，相加得 $\mathbf{u} + \mathbf{v} = \begin{bmatrix} 1 \\ 1 \end{bmatrix}$。代入方程 $1 + 1 = 2 \neq 1$，逃出直线！取 $c=0$ 得 $0\mathbf{u} = \mathbf{0} \notin L$。不过原点的平面/直线称为仿射子空间 (Affine Subspace)，而非向量子空间。

王牌架构

2. 矩阵四大基本子空间 (Four Fundamental Subspaces)

对于任意 $m \times n$ 矩阵 $A$（秩为 $r$），Gilbert Strang 提出的四大基本子空间勾勒出线性映射的完整几何蓝图：

1. 列空间 $\text{Col}(A)$

位于 $\mathbb{R}^m$ 中，维度为 $r = \text{Rank}(A)$。包含所有可能的输出向量 $A\mathbf{x}$。

2. 零空间 $\text{Null}(A)$

位于 $\mathbb{R}^n$ 中，维度为 $n - r$。被 $A$ 压缩坍塌到零向量的所有输入解集。

3. 行空间 $\text{Row}(A) = \text{Col}(A^T)$

位于 $\mathbb{R}^n$ 中，维度为 $r$。由 $A$ 的所有行向量转置张成。

4. 左零空间 $\text{Null}(A^T)$

位于 $\mathbb{R}^m$ 中，维度为 $m - r$。方程 $A^T \mathbf{y} = \mathbf{0}$ 的所有解的集合。

📐 正交补大定理 (Orthogonal Complements)

$$\text{Row}(A) \perp \text{Null}(A) \quad \text{在输入空间 } \mathbb{R}^n \text{ 中构成正交直和分解: } \mathbb{R}^n = \text{Row}(A) \oplus \text{Null}(A)$$ $$\text{Col}(A) \perp \text{Null}(A^T) \quad \text{在输出空间 } \mathbb{R}^m \text{ 中构成正交直和分解: } \mathbb{R}^m = \text{Col}(A) \oplus \text{Null}(A^T)$$
手算示范

3. ✍️ 求解四大基本子空间基底

求 $A = \begin{bmatrix} 1 & 2 & 0 \\ 0 & 0 & 1 \end{bmatrix}$ 的四大基本子空间

1. Col(A)： 主元在第 1、3 列 $\implies$ 基为 $\left\{\begin{bmatrix}1\\0\end{bmatrix}, \begin{bmatrix}0\\1\end{bmatrix}\right\} = \mathbb{R}^2$，维度 2。

2. Null(A)： $x_2=t$ 为自由变量 $\implies$ 基为 $\left\{\begin{bmatrix}-2\\1\\0\end{bmatrix}\right\}$，维度 1。

3. Row(A)： 非零行 $\implies$ 基为 $\left\{\begin{bmatrix}1\\2\\0\end{bmatrix}, \begin{bmatrix}0\\0\\1\end{bmatrix}\right\}$，维度 2。

4. Null($A^T$)： 维度 $m - r = 2 - 2 = 0 \implies \{\mathbf{0}\}$。

Python 实战

4. 💻 SymPy 求解四大子空间

import sympy as sp

A = sp.Matrix([[1, 2, 0],
              [0, 0, 1]])

print("Col(A) 列空间基:", A.columnspace())
print("Null(A) 零空间基:", A.nullspace())
print("Row(A) 行空间基:", A.rowspace())
print("Null(A^T) 左零空间基:", A.T.nullspace())

📝 习题 97, 98, 99 & 100：线性变换象空间、原象空间与和空间

【题目 97 & 98】 设 $T: \mathbb{R}^n \to \mathbb{R}^m$ 为线性变换。
(a) 证明：若 $V$ 是 $\mathbb{R}^n$ 的子空间，则其象集 $T(V) = \{T(\mathbf{u}) : \mathbf{u} \in V\}$ 是 $\mathbb{R}^m$ 的子空间；
(b) 证明：若 $W$ 是 $\mathbb{R}^m$ 的子空间，则其原象集 $T^{-1}(W) = \{\mathbf{u} \in \mathbb{R}^n : T(\mathbf{u}) \in W\}$ 是 $\mathbb{R}^n$ 的子空间。
【证明】
• (a) ① $\mathbf{0} \in V \implies T(\mathbf{0}) = \mathbf{0} \in T(V)$；② 任取 $T(\mathbf{u}_1), T(\mathbf{u}_2) \in T(V)$，由于 $V$ 是子空间，$\mathbf{u}_1+\mathbf{u}_2 \in V$，故 $T(\mathbf{u}_1) + T(\mathbf{u}_2) = T(\mathbf{u}_1+\mathbf{u}_2) \in T(V)$；③ $c T(\mathbf{u}) = T(c\mathbf{u}) \in T(V)$。三步准则全部满足，故 $T(V)$ 必为子空间。
• (b) ① $T(\mathbf{0}) = \mathbf{0} \in W \implies \mathbf{0} \in T^{-1}(W)$；② 若 $\mathbf{u}_1, \mathbf{u}_2 \in T^{-1}(W)$，则 $T(\mathbf{u}_1+\mathbf{u}_2) = T(\mathbf{u}_1)+T(\mathbf{u}_2) \in W$，故和向量在原象集中；③ 同理数乘封闭。原象集亦必为子空间。

【题目 99 & 100】
(a) 设 $A, B \in M_{m \times n}$，证明集合 $V = \{\mathbf{v} \in \mathbb{R}^n : A\mathbf{v} = B\mathbf{v}\}$ 是子空间；
(b) 设 $V$ 与 $W$ 是 $\mathbb{R}^n$ 的子空间，证明和空间 $V + W = \{\mathbf{v} + \mathbf{w} : \mathbf{v} \in V, \mathbf{w} \in W\}$ 是子空间。
【证明】
• (a) 等式移项即为 $(A - B)\mathbf{v} = \mathbf{0}$。因此 $V$ 恰好是矩阵 $A - B$ 的零空间 $\text{Null}(A - B)$！任何矩阵的零空间必定是良定义的子空间。
• (b) 验证三步准则：① $\mathbf{0} = \mathbf{0} + \mathbf{0} \in V + W$；② 任取 $(\mathbf{v}_1+\mathbf{w}_1) + (\mathbf{v}_2+\mathbf{w}_2) = (\mathbf{v}_1+\mathbf{v}_2) + (\mathbf{w}_1+\mathbf{w}_2) \in V + W$（由各自封闭性）；③ $c(\mathbf{v}+\mathbf{w}) = (c\mathbf{v}) + (c\mathbf{w}) \in V + W$。故和空间是包含 $V \cup W$ 的最小子空间。

📝 习题 83 & 84：行空间与零空间正交补分解与维数基底并集

【题目 83】 设 $A$ 是 $m \times n$ 矩阵。
(a) 证明：$\mathbf{u}^T \mathbf{u} = 0 \iff \mathbf{u} = \mathbf{0}$；
(b) 证明：若 $\mathbf{u} \in \text{Row}(A)$ 且 $\mathbf{v} \in \text{Null}(A)$，则 $\mathbf{u}^T \mathbf{v} = 0$（二者严格正交）；
(c) 证明：行空间与零空间的交集只有零向量，即 $\text{Row}(A) \cap \text{Null}(A) = \{\mathbf{0}\}$。
【证明 83】
• (a) $\mathbf{u}^T \mathbf{u} = u_1^2 + \dots + u_n^2 = \|\mathbf{u}\|^2$。实数平方和为 0 当且仅当每个分量均为 0，即 $\mathbf{u} = \mathbf{0}$。
• (b) 因为 $\mathbf{u} \in \text{Row}(A)$，存在 $\mathbf{y} \in \mathbb{R}^m$ 使 $\mathbf{u} = A^T \mathbf{y}$。因此 $\mathbf{u}^T \mathbf{v} = (A^T \mathbf{y})^T \mathbf{v} = \mathbf{y}^T (A\mathbf{v})$。而 $\mathbf{v} \in \text{Null}(A) \implies A\mathbf{v} = \mathbf{0}$，故 $\mathbf{u}^T \mathbf{v} = \mathbf{y}^T \mathbf{0} = 0$！
• (c) 若向量 $\mathbf{x} \in \text{Row}(A) \cap \text{Null}(A)$，根据 (b) 的结论，$\mathbf{x}$ 必须与自身正交，即 $\mathbf{x}^T \mathbf{x} = 0$！由 (a) 立即迫使 $\mathbf{x} = \mathbf{0}$！故交集仅含平凡零元。

【题目 84（全空间直和基定理）】 证明：对任意 $m \times n$ 矩阵 $A$，$\text{Row}(A)$ 的一组基与 $\text{Null}(A)$ 的一组基的并集必定构成全空间 $\mathbb{R}^n$ 的一组基！
【证明 84】
设 $\mathcal{B}_{\text{Row}} = \{\mathbf{r}_1, \dots, \mathbf{r}_r\}$ 为行空间的基（$r = \text{rank}(A)$），$\mathcal{B}_{\text{Null}} = \{\mathbf{n}_1, \dots, \mathbf{n}_k\}$ 为零空间的基（$k = \text{nullity}(A) = n - r$）。
① 向量总数：$r + k = r + (n - r) = n$，向量总数恰好等于全空间维数；
② 线性无关性检验：设 $\sum a_i \mathbf{r}_i + \sum b_j \mathbf{n}_j = \mathbf{0} \implies \sum a_i \mathbf{r}_i = -\sum b_j \mathbf{n}_j$。
左边属于 $\text{Row}(A)$，右边属于 $\text{Null}(A)$。该向量同时属于两空间交集，由题 83(c) 知该向量必须为 $\mathbf{0}$！
因此 $\sum a_i \mathbf{r}_i = \mathbf{0} \implies a_1 = \dots = a_r = 0$；同理 $\sum b_j \mathbf{n}_j = \mathbf{0} \implies b_1 = \dots = b_k = 0$。
故这 $n$ 个向量完全线性无关，根据基定理，它们必定构成 $\mathbb{R}^n$ 的一组基！证毕。
