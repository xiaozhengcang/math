Ch 4.4: 基底、维数定理与秩-零度定理

核心概念

1. 基底与维数 (Basis & Dimension)

📐 基底 (Basis) 的两大黄金条件与唯一坐标定理

子空间 $V$ 的一组向量集合 $\mathcal{B} = \{\mathbf{v}_1, \dots, \mathbf{v}_k\}$ 称为 $V$ 的一组基底 (Basis)，当且仅当它同时满足：

  1. 高效性（无冗余）：$\mathcal{B}$ 是线性无关的。
  2. 完备性（全覆盖）：$\mathcal{B}$ 能够张成整个空间：$\text{Span}(\mathcal{B}) = V$。

唯一坐标定理： $\mathcal{B}$ 是基底，当且仅当对于 $V$ 中任意向量 $\mathbf{v}$，存在唯一一组标量系数使得 $\mathbf{v} = \sum c_i \mathbf{v}_i$。基底中向量的个数 $k$ 恒定不变，称为维数 (Dimension)，记作 $\dim(V) = k$。

王牌定理

2. 👑 基定理与秩-零度定理 (Rank-Nullity Theorem)

👑 基定理 (Basis Theorem) 与基扩展定理

  • 基定理： 设 $\dim(V) = n$。在 $V$ 中取任意 $n$ 个向量：若它们线性无关，则它们自动张成 $V$（必为基）；反之，若它们张成 $V$，则它们自动线性无关（必为基）！只需检验其中一个条件！
  • 基扩展定理 (Basis Extension)： $V$ 中的任意线性无关向量组都可以通过添加新向量扩充为 $V$ 的一组完整基底。

👑 秩-零度定理 (Rank-Nullity Theorem)

$$\text{Rank}(A) + \text{Nullity}(A) = n \quad (\text{矩阵总列数 / 输入空间维度})$$

能量守恒视角： 矩阵输入的 $n$ 维自由度被完全拆分成两部分：一部分坍缩在零空间中（$\text{Nullity}(A)$），另一部分成功输出到列空间中（$\text{Rank}(A)$）！

行秩等于列秩定理：$$\text{Rank}(A) = \text{Rank}(A^T)$$

不论长瘦还是扁胖矩阵，行空间与列空间的维度永远奇迹般地完全相等！

手算示范

3. ✍️ 判定向量组是否构成基底

判定 $\mathbf{v}_1 = \begin{bmatrix}1\\1\\0\end{bmatrix}, \mathbf{v}_2 = \begin{bmatrix}0\\1\\1\end{bmatrix}, \mathbf{v}_3 = \begin{bmatrix}1\\0\\1\end{bmatrix}$ 是否为 $\mathbb{R}^3$ 的一组基

计算由这 3 个向量构成的矩阵行列式：

$$\det \begin{bmatrix} 1 & 0 & 1 \\ 1 & 1 & 0 \\ 0 & 1 & 1 \end{bmatrix} = 1(1 - 0) + 1(1 - 0) = 2 \neq 0$$

行列式不为 0 $\implies$ 3 个向量线性无关 $\implies$ 由基定理，它们构成 $\mathbb{R}^3$ 的一组基底！

Python 实战

4. 💻 NumPy 验证基底与秩-零度定理

import numpy as np

A = np.array([[1, 2, 0, 1],
              [0, 1, 1, 0],
              [1, 3, 1, 1]], dtype=float)

rank = np.linalg.matrix_rank(A)
n = A.shape[1]
nullity = n - rank

print(f"矩阵列数 n = {n}")
print(f"秩 Rank(A) = {rank}")
print(f"零度 Nullity(A) = {nullity}")
print(f"Rank + Nullity = {rank + nullity} == {n}")
