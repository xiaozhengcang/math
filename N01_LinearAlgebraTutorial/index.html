线性代数 (Linear Algebra 2022 Fall)

面向初学者的 100% 穷尽式几何直觉、全定理推导与 Python 实战教程

本平台基于国立台湾大学李宏毅老师 (Prof. Hung-yi Lee) Linear Algebra 2022 Fall 全部 84 份讲义与课题重构。完全遵循官方课程主页 2022-fall.html 的教学时间轴顺序，注重将抽象公理化代数转化为直观的空间几何图像，提供完全无遗漏的数学推导（列对应定理、可逆矩阵 10 条件闭环、伴随矩阵求逆公式、克莱姆法则、基扩展定理、Cayley-Hamilton定理、微积分算子矩阵化、PageRank 幂法、Gram-Schmidt/QR、SVD 奇异值分解与超越向量空间），并附带 Python / NumPy 代码实战。

✨ 课程五大核心亮点

👁️ 几何直觉优先 (Geometric Intuition)

拒绝死记硬背公式！将矩阵乘法理解为空间网格扭曲，将行列式理解为有向体积放缩因子，将特征向量理解为变换中的不旋转主轴，将 SVD 理解为旋转-拉伸-旋转三步曲。

✍️ 100% 穷尽式详细推导 (Full Proofs)

从列对应定理 (Column Correspondence Theorem) 到可逆矩阵 10 条件闭环，从伴随矩阵求逆公式到 Cauchy-Schwarz 不等式与广义伪逆 $A^+$，逻辑无缝衔接。

🌱 零基础与历史故事 (Beginner & History)

从《九章算术》“禾谷计数”方程术引出高斯消元历史；使用“在 Span 耍废的 Vector”等生动比喻降低理解门槛。

💻 Python / NumPy 代码实战 (Python Labs)

每个模块均配套 Python/NumPy 工业级代码示例（`np.linalg.solve`, `inv`, `qr`, `eig`, `svd`, `pinv`），学以致用。

📚 课程模块列表 (8 大章节)

Module 01
向量、矩阵与线性方程组
对应讲义 1-1 至 1-5。线性方程组定义与非线性反例；向量点积与几何表示；矩阵基本运算与特殊矩阵（对角、单位、对称、三角）；$A\mathbf{x}$ 列组合视角。
进入 Module 1 →
Module 02
求解方程组、RREF 与列对应定理
对应讲义 1-6 至 1-7。线性组合与 Span 空间；解结构 $\mathbf{x}=\mathbf{x}_p+\mathbf{x}_n$；线性无关判定；高斯消元与 RREF 唯一性；列对应定理 (Column Correspondence) 完整推导。
进入 Module 2 →
Module 03
矩阵四大视角与可逆大一统定理
对应讲义 2-1 至 2-4。矩阵乘法 4 种解读视角；线性变换几何网格扭曲；初等矩阵与求逆；可逆矩阵 10 大等价条件闭环定理；里昂惕夫投入产出模型。
进入 Module 3 →
Module 04
子空间、基与四大基本子空间
对应 Chapter 4-(1) 讲义。子空间 3 大检验条件；Subspace vs Span；基 (Basis) 与维数 (Dimension) 定理；四大基本子空间与秩-零化度定理 ($\text{rank}+\text{nullity}=n$)。
进入 Module 4 →
Module 05
行列式体积、余子式与克莱姆法则
对应 Chapter 3 讲义。行列式 Signed Volume 几何放缩率；三大基本性质；余子式展开；伴随矩阵公式 $A^{-1}=\frac{1}{\det A}\text{adj}(A)$；克莱姆法则 (Cramer's Rule)。
进入 Module 5 →
Module 06
坐标系统与基变换矩阵
对应 Chapter 4-(2) 讲义。选择基作为观察网格；笛卡尔与非笛卡尔坐标转换；坐标变换矩阵 $P_{B\to C}$；不同坐标系下描述线性算子 $B=P^{-1}AP$；微积分求导算子矩阵化。
进入 Module 6 →
Module 07
特征值、PageRank 与矩阵对角化
对应 Chapter 5 讲义。特征值/向量几何不旋转主轴；特征多项式 $\det(A-\lambda I)=0$；Google PageRank 幂法算法；矩阵对角化 $A=PDP^{-1}$ 判定与 $A^k$ 极速计算。
进入 Module 7 →
Module 08
正交投影、SVD 与超越向量空间
对应 Chapter 7 & 6 讲义。几何三大不等式；Gram-Schmidt 正交化与 QR 分解；正交投影矩阵 $P=A(A^TA)^{-1}A^T$；实对称矩阵谱定理；SVD 3 步分解与 Moore-Penrose 广义伪逆 $A^+$；超越向量空间。
进入 Module 8 →
