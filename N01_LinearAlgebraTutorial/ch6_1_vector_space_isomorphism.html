Chapter 6: 抽象向量空间

Ch 6.1: 抽象向量空间 8 大公理与同构定理

核心概念

1. 原来万物皆向量！抽象向量空间的 8 大公理

李宏毅老师在 Chapter 6 中提出了一个极具哲学深度的视角：向量不仅仅是箭头或实数数组，只要一个对象集合定义了“加法”与“数乘”，并且满足以下 8 大公理，它就是货真价实的向量空间 (Vector Space)！

📐 向量空间 8 大公理 (8 Axioms of Vector Space)

【加法 4 大公理】
  1. 交换律：$\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$
  2. 结合律：$(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$
  3. 零元存在：存在 $\mathbf{0}$ 满足 $\mathbf{u} + \mathbf{0} = \mathbf{u}$
  4. 逆元存在：存在 $-\mathbf{u}$ 满足 $\mathbf{u} + (-\mathbf{u}) = \mathbf{0}$
【数乘 4 大公理】
  1. 数乘标量分配律：$c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$
  2. 向量标量分配律：$(c + d)\mathbf{u} = c\mathbf{u} + d\mathbf{u}$
  3. 标量结合律：$(cd)\mathbf{u} = c(d\mathbf{u})$
  4. 单位标量乘：$1 \cdot \mathbf{u} = \mathbf{u}$

🌌 经典抽象向量空间实例

  • 多项式空间 $\mathcal{P}_n$：所有次数不超过 $n$ 的实多项式集合。
  • 连续函数空间 $C[a, b]$：区间 $[a, b]$ 上所有连续函数的集合（无穷维向量空间！）。
  • 矩阵空间 $\mathcal{M}_{m \times n}$：所有 $m \times n$ 实矩阵构成的空间。
同构定理

2. 👑 向量空间同构定理 (Isomorphism Theorem)

👑 有限维实向量空间同构定理

任何维数为 $n$ 的实向量空间 $V$，在代数结构上都严格与 $\mathbb{R}^n$ 同构 ($V \cong \mathbb{R}^n$)！

意义： 无论研究的是三次多项式 $\mathcal{P}_3$、对称矩阵空间还是微分方程解空间，只要取定一组基底，所有的抽象元素都可以无损映射为 $\mathbb{R}^n$ 中的列向量，所有之前学过的矩阵乘法、RREF、特征值理论全部可以直接应用！

手算示范

3. ✍️ 抽象多项式基底判定

判定 $\mathcal{P}_2$ 中的多项式组 $\{1 + x, x + x^2, 1 + x^2\}$ 是否构成基底

在标准基 $\{1, x, x^2\}$ 下写出它们的坐标向量：

$$[p_1] = \begin{bmatrix}1\\1\\0\end{bmatrix}, \quad [p_2] = \begin{bmatrix}0\\1\\1\end{bmatrix}, \quad [p_3] = \begin{bmatrix}1\\0\\1\end{bmatrix}$$

计算坐标矩阵行列式：$\det \begin{bmatrix} 1 & 0 & 1 \\ 1 & 1 & 0 \\ 0 & 1 & 1 \end{bmatrix} = 2 \neq 0$。

结论： 由同构定理，坐标向量线性无关 $\implies$ 原多项式组构成 $\mathcal{P}_2$ 的一组基底！

Python 实战

4. 💻 SymPy 符号化多项式基底同构计算

import sympy as sp

x = sp.symbols('x')
p1 = 1 + x
p2 = x + x**2
p3 = 1 + x**2

# 构造标准基 [1, x, x^2] 坐标矩阵
M = sp.Matrix([[1, 0, 1],
               [1, 1, 0],
               [0, 1, 1]])

print("多项式坐标矩阵行列式:", M.det()) # 2
print("是否构成抽象空间基底:", M.det() != 0)
