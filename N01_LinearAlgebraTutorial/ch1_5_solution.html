Chapter 1: 线性系统与求解基础

Ch 1.5: 相容性与解集几何结构 (x=xp+xn)

核心概念

1. 解集分类与相容性秩判定定理

对于任意线性方程组 $A\mathbf{x} = \mathbf{b}$（$A$ 为 $m \times n$ 矩阵），其解集只有以下三种可能，绝无第四种可能：

1. 无解 (Inconsistent)

$\mathbf{b} \notin \text{Col}(A)$，且 $\text{rank}(A) < \text{rank}([A \mid \mathbf{b}])$。消元出现 $[0 \dots 0 \mid c]$ ($c \neq 0$)。

2. 唯一解 (Unique Solution)

$\mathbf{b} \in \text{Col}(A)$ 且 $\text{rank}(A) = \text{rank}([A \mid \mathbf{b}]) = n$（满列秩，无自由变量，$\text{Null}(A) = \{\mathbf{0}\}$）。

3. 无穷多解 (Infinitely Many)

$\mathbf{b} \in \text{Col}(A)$ 且 $\text{rank}(A) = \text{rank}([A \mid \mathbf{b}]) < n$（存在 $n - \text{rank}(A)$ 个自由变量）。

通解结构

2. 通解结构定理：$\mathbf{x} = \mathbf{x}_p + \mathbf{x}_n$ 的仿射几何平移

👑 非齐次线性方程组通解结构定理

设 $\mathbf{x}_p$ 是非齐次方程 $A\mathbf{x} = \mathbf{b}$ 的任意一个特解 (Particular Solution)，$A\mathbf{x}_p = \mathbf{b}$。则方程的完整通解集为：

$$\mathbf{x} = \mathbf{x}_p + \mathbf{x}_n, \quad \text{其中 } \mathbf{x}_n \in \text{Null}(A) \ (A\mathbf{x}_n = \mathbf{0})$$

严密代数证明：

  • 一方面，若 $\mathbf{x} = \mathbf{x}_p + \mathbf{x}_n$，则 $A\mathbf{x} = A(\mathbf{x}_p + \mathbf{x}_n) = A\mathbf{x}_p + A\mathbf{x}_n = \mathbf{b} + \mathbf{0} = \mathbf{b}$，确为方程的解。
  • 另一方面，设 $\mathbf{x}_1, \mathbf{x}_2$ 为任意两个非齐次特解，则 $A(\mathbf{x}_1 - \mathbf{x}_2) = A\mathbf{x}_1 - A\mathbf{x}_2 = \mathbf{b} - \mathbf{b} = \mathbf{0}$。因此两解之差必定落在齐次零空间 $\text{Null}(A)$ 内！ $\blacksquare$

💡 核心几何洞察

非齐次方程组的解集是一个仿射子空间 (Affine Subspace)：它在几何上与零空间 $\text{Null}(A)$ 完美平行，只是被特解向量 $\mathbf{x}_p$ 整体“顶”离了原点！

手算示范

3. ✍️ 齐次解与特解求解全流程

例题：求 $\begin{bmatrix} 1 & 2 & 0 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} = \begin{bmatrix} 4 \\ 3 \end{bmatrix}$ 的通解

步骤 1：识别主元与自由变量

第 1、3 列为主元列，第 2 列无主元，因此 $x_2 = t$ 是自由变量。

步骤 2：写出方程关系

$$x_1 + 2t = 4 \implies x_1 = 4 - 2t$$ $$x_3 = 3$$

步骤 3：拆解为 $\mathbf{x}_p + t \mathbf{v}_1$

$$\begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} = \begin{bmatrix} 4 - 2t \\ t \\ 3 \end{bmatrix} = \underbrace{\begin{bmatrix} 4 \\ 0 \\ 3 \end{bmatrix}}_{\mathbf{x}_p \text{ (特解)}} + t \underbrace{\begin{bmatrix} -2 \\ 1 \\ 0 \end{bmatrix}}_{\mathbf{x}_n \text{ (零空间基底)}}$$
Python 实战

4. 💻 SymPy 符号化求零空间与特解

import sympy as sp

A = sp.Matrix([[1, 2, 0], [0, 0, 1]])
b = sp.Matrix([4, 3])

# 求解 Ax = b 的特解与零空间
system = A.row_join(b)
rref_mat, pivots = system.rref()
print("增广矩阵 RREF:\n", rref_mat)
print("主元列索引:", pivots)

# 零空间基底
null_basis = A.nullspace()
print("零空间基向量 Null(A):", null_basis)
