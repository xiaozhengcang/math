Ch 3.1 专题深度探究

📐 行列式几何底蕴：二维面积推导、减法项直觉与法向量构造全解析

为什么二维面积公式是 $x_1 y_2 - x_2 y_1$？中间的“减法”究竟减去了什么？为什么解垂直方程组得到的法向量模长恰好等于底面积？本专题带你从初等几何、空间投影、外代数到德古阿定理，彻底打通代数计算与空间直觉的桥梁。

基础几何

1. 二维平面平行四边形面积公式的三大严格推导

设平面上有两个向量 $\mathbf{u} = (x_1, y_1)$ 与 $\mathbf{v} = (x_2, y_2)$，由它们张成的平行四边形面积为：

$$\text{Area} = |x_1 y_2 - x_2 y_1| = \left| \det \begin{bmatrix} x_1 & x_2 \\ y_1 & y_2 \end{bmatrix} \right|$$

🔹 视角一：点积与解析三角法

平行四边形面积等于底乘高： $$\text{Area} = \|\mathbf{u}\| \|\mathbf{v}\| \sin\theta = \|\mathbf{u}\| \|\mathbf{v}\| \sqrt{1 - \cos^2\theta}$$ 两边平方并利用点积定义 $\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\| \|\mathbf{v}\| \cos\theta$： $$\text{Area}^2 = \|\mathbf{u}\|^2 \|\mathbf{v}\|^2 - (\mathbf{u} \cdot \mathbf{v})^2$$ 代入坐标展开计算： $$= (x_1^2 + y_1^2)(x_2^2 + y_2^2) - (x_1 x_2 + y_1 y_2)^2$$ $$= (x_1^2 x_2^2 + x_1^2 y_2^2 + y_1^2 x_2^2 + y_1^2 y_2^2) - (x_1^2 x_2^2 + 2x_1 x_2 y_1 y_2 + y_1^2 y_2^2)$$ $$= x_1^2 y_2^2 - 2x_1 x_2 y_1 y_2 + y_1^2 x_2^2 = (x_1 y_2 - x_2 y_1)^2$$ 开方即得：$\text{Area} = |x_1 y_2 - x_2 y_1|$。

🔮 视角二：外接矩形“割补法”

设向量位于第一象限，用一个宽为 $x_1 + x_2$、高为 $y_1 + y_2$ 的外接大矩形包围该平行四边形： $$S_{\text{大矩形}} = (x_1 + x_2)(y_1 + y_2) = x_1 y_1 + x_1 y_2 + x_2 y_1 + x_2 y_2$$ 周围多余面积包含：

  • 两个底 $x_1$ 高 $y_1$ 的三角形：面积共 $x_1 y_1$
  • 两个底 $x_2$ 高 $y_2$ 的三角形：面积共 $x_2 y_2$
  • 两个宽 $x_2$ 高 $y_1$ 的小矩形：面积共 $2x_2 y_1$
大矩形减去多余区域： $$\text{Area} = S_{\text{大矩形}} - (x_1 y_1 + x_2 y_2 + 2x_2 y_1) = x_1 y_2 - x_2 y_1$$

🌱 视角三：极坐标极角差展开

设 $\mathbf{u} = (r_1 \cos\alpha, r_1 \sin\alpha)$，$\mathbf{v} = (r_2 \cos\beta, r_2 \sin\beta)$，两向量夹角 $\theta = \beta - \alpha$： $$\text{Area} = r_1 r_2 \sin(\beta - \alpha) = r_1 r_2 (\sin\beta \cos\alpha - \cos\beta \sin\alpha)$$ $$= (r_1 \cos\alpha)(r_2 \sin\beta) - (r_1 \sin\alpha)(r_2 \cos\beta) = x_1 y_2 - y_1 x_2$$

深度几何直觉与图解

2. 减法项 $x_1 y_2 - x_2 y_1$ 的 4 大深层几何直觉与图形辅助解析

为什么行列式中必须是“两项相减”？这个减法到底在几何上减去了什么？以下通过几何图解与 4 种视角为你逐一揭秘：

💡 直觉 1：外接矩形严密割补 —— 为什么结果刚好是 $x_1 y_2 - x_2 y_1$？

设 $\mathbf{u} = (x_1, y_1)$，$\mathbf{v} = (x_2, y_2)$。右图展示了严格按坐标比例绘制的外接大矩形割补剖分（宽 $x_1+x_2$，高 $y_1+y_2$）：
• 大矩形总面积：$S_{\text{总}} = (x_1 + x_2)(y_1 + y_2) = x_1 y_1 + x_1 y_2 + x_2 y_1 + x_2 y_2$；
• 两对直角三角形（蓝色与紫色）： 上下两个底 $x_1$ 高 $y_1$ 的三角形面积和为 $x_1 y_1$； 左右两个底 $x_2$ 高 $y_2$ 的三角形面积和为 $x_2 y_2$；
• 两个角部小矩形（红色区域）： 左上角与右下角各有一个宽 $x_2$ 高 $y_1$ 的小矩形，面积共 $2 x_2 y_1$。
• 大矩形减去所有周围区域： $$\text{平行四边形面积} = S_{\text{总}} - (x_1 y_1 + x_2 y_2 + 2 x_2 y_1) = x_1 y_2 - x_2 y_1$$ 👉 减法本质：交叉项 $x_2 y_1$ 在外围出现了 2 次，大矩形中只有 1 次，相减后留下 $-x_2 y_1$！

💡 直觉 2：两个向量“斜率坡度差”的量度（张开分离度）

计算两向量从原点出发的斜率坡度： $k_1 = \frac{y_1}{x_1}$（向量 $\mathbf{u}$ 的倾斜度），$k_2 = \frac{y_2}{x_2}$（向量 $\mathbf{v}$ 的倾斜度）。
观察两者的斜率之差： $$k_2 - k_1 = \frac{y_2}{x_2} - \frac{y_1}{x_1} = \frac{x_1 y_2 - x_2 y_1}{x_1 x_2} \implies x_1 x_2 (k_2 - k_1) = x_1 y_2 - x_2 y_1$$ • 减法衡量张角大小：当 $k_2 = k_1$（两向量斜率完全一致，共线重叠）时，减法结果 $x_1 y_2 - x_2 y_1 = 0$，面积被彻底减光退化为 0；
• 坡度差越大，平行四边形张得越开，面积越大。

💡 直觉 3：微积分矢径回路中的“正向扫掠 － 反向回拉”

在格林公式（Green's Theorem）与极坐标微积分中，平面闭合区域的面积等于矢径 $\mathbf{r}=(x, y)$ 沿边界扫过的微元线积分： $$A = \frac{1}{2} \oint (x dy - y dx)$$ 对平行四边形边界运动离散化：
• $+x_1 y_2$：沿底边水平跨度 $x_1$ 配合对边垂直上升 $y_2$，逆时针扫出了正向面积；
• $-x_2 y_1$：返回原点时垂直位移 $y_1$ 配合水平位移 $x_2$ 产生顺时针反向回拉补偿；
• 两式相减，正是闭合曲线内部净圈定的有向真实几何面积。

代数与几何统一

3. 三维法向量构造与代数余子式的严密消元证明

设三维空间中底面由 $\mathbf{v}_2 = (x_2, y_2, z_2)$ 与 $\mathbf{v}_3 = (x_3, y_3, z_3)$ 张成。底面法向量 $\mathbf{n} = (n_1, n_2, n_3)$ 必须同时垂直于这两个向量：

① $\mathbf{v}_2 \cdot \mathbf{n} = x_2 n_1 + y_2 n_2 + z_2 n_3 = 0$
② $\mathbf{v}_3 \cdot \mathbf{n} = x_3 n_1 + y_3 n_2 + z_3 n_3 = 0$

消元求解过程：
将 ① 乘 $y_3$、② 乘 $y_2$ 两式相减消去 $n_2$： $$(x_2 y_3 - x_3 y_2) n_1 = (y_2 z_3 - z_2 y_3) n_3$$ 将 ① 乘 $x_3$、② 乘 $x_2$ 两式相减消去 $n_1$： $$(x_2 y_3 - x_3 y_2) n_2 = -(x_2 z_3 - z_2 x_3) n_3$$ 为了得到不含分母的最简整式解，令 $n_3 = x_2 y_3 - x_3 y_2 = C_{13}$，即可得到解：

$$n_1 = y_2 z_3 - z_2 y_3 = C_{11}, \quad n_2 = -(x_2 z_3 - z_2 x_3) = C_{12}, \quad n_3 = x_2 y_3 - x_3 y_2 = C_{13}$$ $$\implies \mathbf{n} = \mathbf{v}_2 \times \mathbf{v}_3 = \begin{pmatrix} C_{11} \\ C_{12} \\ C_{13} \end{pmatrix}$$
模长之谜

4. 为什么算出的法向量模长必定等于底面积？

⚖️ 体积公式中的完美代数抵消

平行六面体体积等于底面积乘高：$V = S_{\text{base}} \times h$。
高 $h$ 是顶向量 $\mathbf{v}_1$ 向单位法向量 $\hat{\mathbf{n}} = \frac{\mathbf{n}}{\|\mathbf{n}\|}$ 的投影长度：$h = \mathbf{v}_1 \cdot \frac{\mathbf{n}}{\|\mathbf{n}\|}$。
因此： $$V = S_{\text{base}} \cdot \left( \mathbf{v}_1 \cdot \frac{\mathbf{n}}{\|\mathbf{n}\|} \right) = \mathbf{v}_1 \cdot \left( \frac{S_{\text{base}}}{\|\mathbf{n}\|} \mathbf{n} \right)$$ 为了让展开式 $\det(A) = \mathbf{v}_1 \cdot \mathbf{n} = a_{11}C_{11} + a_{12}C_{12} + a_{13}C_{13}$ 能够直接成立，系数必须满足 $\frac{S_{\text{base}}}{\|\mathbf{n}\|} = 1$，即 $\|\mathbf{n}\| \equiv S_{\text{base}}$！

高维几何

5. 选取 $n_3 = x_2 y_3 - x_3 y_2$ 的深层玄机与德古阿定理

看似消元时挑选 $n_3 = x_2 y_3 - x_3 y_2$ 只是为了去分母，但实际上它在背后触发并锁定了三大深层几何法则：

1️⃣ 边界条件锚定（平躺真实面积）：
当底面平躺在 X-Y 面上时（$z_2=0, z_3=0$），底面实际总面积就是 $S_{xy} = x_2 y_3 - x_3 y_2$。此时法向量只能垂直沿 Z 轴朝上 $(0, 0, n_3)$。为了满足 $\|\mathbf{n}\| = S_{\text{base}}$，$n_3$ 必须且只能等于 $x_2 y_3 - x_3 y_2$！
2️⃣ 空间手性（定向）绑定：
$x_2 y_3 - x_3 y_2 > 0$ 严格对应从 $\mathbf{v}_2$ 到 $\mathbf{v}_3$ 的逆时针旋转，计算出的 $n_3 > 0$ 严格保证了法向量指向 Z 轴正方向，自然绑定了右手定则。
3️⃣ 德古阿定理（三维空间勾股定理）：
$C_{11}, C_{12}, C_{13}$ 的真实几何身份正是底面在 Y-Z、X-Z、X-Y 坐标面上的投影面积 $S_{yz}, S_{xz}, S_{xy}$。
由空间勾股定理：倾斜底面的总面积平方等于三个正交投影面积的平方和： $$S_{\text{base}}^2 = S_{yz}^2 + S_{xz}^2 + S_{xy}^2 = C_{11}^2 + C_{12}^2 + C_{13}^2 = \|\mathbf{n}\|^2$$ 两边开方即可严格证明：$\|\mathbf{n}\| = S_{\text{base}}$！
