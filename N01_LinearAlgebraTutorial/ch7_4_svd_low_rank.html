Ch 7.4: 奇异值分解 SVD、伪逆与图像低秩压缩

核心概念

1. 奇异值分解 (SVD)：线性代数的最高巅峰

特征值分解只能处理方阵，且不一定可对角化。而 奇异值分解 (Singular Value Decomposition, SVD) 适用于任何形状 ($m \times n$) 的实数矩阵！

👑 奇异值分解定理 (SVD Theorem)

任意 $m \times n$ 实矩阵 $A$ 都可以分解为：

$$A = U \Sigma V^T = \sum_{i=1}^r \sigma_i \mathbf{u}_i \mathbf{v}_i^T$$
  • $U$ 是 $m \times m$ 正交矩阵，列向量 $\mathbf{u}_i$ 为左奇异向量 (Left Singular Vectors)（$A A^T$ 的正交特征向量）。
  • $\Sigma$ 是 $m \times n$ 对角矩形矩阵，主对角线元素 $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0$ 为奇异值（$\sigma_i = \sqrt{\lambda_i(A^T A)}$）。
  • $V$ 是 $n \times n$ 正交矩阵，列向量 $\mathbf{v}_i$ 为右奇异向量 (Right Singular Vectors)（$A^T A$ 的正交特征向量）。

几何三步曲： 任何矩阵变换都可以精确解构为：输入空间正交旋转 ($V^T$) $\to$ 沿坐标轴拉伸伸缩 ($\Sigma$) $\to$ 输出空间正交旋转 ($U$)！

工程奇迹

2. 🖼️ Eckart-Young 低秩逼近定理与 Moore-Penrose 伪逆

取前 $k$ 个最大奇异值构造截断矩阵 $A_k = \sum_{i=1}^k \sigma_i \mathbf{u}_i \mathbf{v}_i^T$。根据 Eckart-Young-Mirsky 定理，$A_k$ 是在谱范数与 Frobenius 范数意义下对原矩阵 $A$ 的全局理论最优秩-$k$ 逼近：

$$\|A - A_k\|_2 = \sigma_{k+1}, \quad \|A - A_k\|_F = \sqrt{\sum_{j=k+1}^r \sigma_j^2}$$

👑 广义 Moore-Penrose 伪逆 ($A^+$)

对于任意矩阵 $A = U \Sigma V^T$，其广义伪逆定义为：

$$A^+ = V \Sigma^+ U^T$$

其中 $\Sigma^+$ 将非零奇异值取倒数 $\frac{1}{\sigma_i}$ 并转置。对于任意线性系统 $A\mathbf{x} = \mathbf{b}$，$\hat{\mathbf{x}} = A^+ \mathbf{b}$ 永远给出最小二乘极小范数最优解！

手算示范

3. ✍️ 2×2 SVD 分解手算演练

求 $A = \begin{bmatrix} 3 & 0 \\ 0 & -2 \end{bmatrix}$ 的 SVD

计算 $A^T A = \begin{bmatrix} 9 & 0 \\ 0 & 4 \end{bmatrix} \implies \lambda_1 = 9, \lambda_2 = 4$。

奇异值：$\sigma_1 = \sqrt{9} = 3, \sigma_2 = \sqrt{4} = 2$。

右奇异向量：$\mathbf{v}_1 = \begin{bmatrix}1\\0\end{bmatrix}, \mathbf{v}_2 = \begin{bmatrix}0\\1\end{bmatrix} \implies V = I$。

左奇异向量 $\mathbf{u}_i = \frac{1}{\sigma_i} A \mathbf{v}_i$：

$$\mathbf{u}_1 = \frac{1}{3} \begin{bmatrix}3\\0\end{bmatrix} = \begin{bmatrix}1\\0\end{bmatrix}, \quad \mathbf{u}_2 = \frac{1}{2} \begin{bmatrix}0\\-2\end{bmatrix} = \begin{bmatrix}0\\-1\end{bmatrix}$$ $$A = \begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix} \begin{bmatrix} 3 & 0 \\ 0 & 2 \end{bmatrix} \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}^T$$
Python 实战

4. 💻 NumPy SVD 伪逆与低秩压缩

import numpy as np

# 构造一个 100x100 的模拟图像矩阵
img = np.random.randn(100, 100)

# SVD 分解
U, s, Vt = np.linalg.svd(img)

# 截断秩-10 逼近
k = 10
compressed_img = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]

# 伪逆计算
A_pinv = np.linalg.pinv(img)

print(f"原矩阵大小: {img.size} 参数")
print(f"压缩后存储: {k*(U.shape[0] + Vt.shape[0] + 1)} 参数")
print("Moore-Penrose 伪逆尺寸:", A_pinv.shape)
