矩阵函数、谱映射与微分动力系统

在实微积分中，$e^x$ 与 $\sin x$ 描述了连续增长与周期震荡。那么当自变量是一个矩阵时，$e^A$ 或 $\cos A$ 究竟代表什么？绝不是将每个元素分别取指数！矩阵函数连接了纯代数与物理动力学：它将矩阵的离散谱映射为连续演化算子，是求解连续线性微分方程组 $\frac{dx}{dt} = Ax$ 的绝对核心。本章我们将通过 Cayley-Hamilton 降次、矩阵指数与相空间流场，为整个矩阵分析系列画上恢弘的终极句号。

1. 矩阵函数 $f(A)$ 的三位一体严格定义

设方阵 $A \in \mathbb{C}^{n \times n}$，标量全纯函数 $f(z)$ 在包含 $A$ 的全部特征值 $\sigma(A)$ 的开区域上有定义。数学上有三种等价方式严格定义矩阵函数 $f(A)$：

① Taylor 级数展开法

若 $f(z) = \sum_{k=0}^\infty c_k z^k$ 的收敛半径 $R \gt \rho(A)$，则直接定义：

$$ f(A) \triangleq \sum_{k=0}^\infty c_k A^k $$

经典例：$e^A = I + A + \frac{A^2}{2!} + \frac{A^3}{3!} + \dots$ 处处绝对收敛。

② 谱分解 / 相似对角化法

若 $A$ 可对角化 $A = P \Lambda P^{-1}$，其中 $\Lambda = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$：

$$ f(A) \triangleq P \begin{bmatrix} f(\lambda_1) & & \\ & \ddots & \\ & & f(\lambda_n) \end{bmatrix} P^{-1} $$

几何直觉：在特征基底坐标系下，矩阵函数就是各主轴的标量映射。

③ Cauchy 围道积分法

对于不可对角化的任意亏损方阵，利用预解式 (Resolvent)：

$$ f(A) \triangleq \frac{1}{2\pi i} \oint_\Gamma f(z) (zI - A)^{-1} dz $$

围道 $\Gamma$ 紧密包裹 $A$ 的全部特征值，复变分析与泛函分析的普适基石。

2. Cayley-Hamilton 定理与最小多项式矩阵降次

凯莱-哈密顿定理 (Cayley-Hamilton Theorem)：
任何方阵 $A \in \mathbb{C}^{n \times n}$ 必然无条件满足自身的特征多项式方程！即若 $p(\lambda) = \operatorname{det}(\lambda I - A) = \lambda^n + c_{n-1} \lambda^{n-1} + \dots + c_0$，则： $$ p(A) = A^n + c_{n-1} A^{n-1} + \dots + c_1 A + c_0 I = \mathbf{O} $$

2.1 终极降次法：任意矩阵函数均可表示为不超过 $n-1$ 次的多项式

由多项式带余除法，任何解析函数 $f(z)$ 都可以写成 $f(z) = q(z) p(z) + r(z)$，其中余式 $r(z) = \alpha_{n-1} z^{n-1} + \dots + \alpha_0$ 的阶数至多为 $n-1$。将 $A$ 代入后，由于 $p(A) = \mathbf{O}$，高阶项全灭： $$ f(A) = r(A) = \alpha_{n-1} A^{n-1} + \alpha_{n-2} A^{n-2} + \dots + \alpha_1 A + \alpha_0 I $$ 无论计算矩阵指数 $e^A$、正弦 $\sin A$ 还是任意高次幂 $A^{1000}$，都只需待定系数求出 $n$ 个标量 $\alpha_i$ 即可！

3. 矩阵指数 $e^{At}$ 与连续线性动力系统

考虑物理与工程中无处不在的连续时间常微分方程组 (ODE)： $$ \frac{dx(t)}{dt} = A x(t), \quad x(0) = x_0 $$ 其中 $x(t) \in \mathbb{R}^n$ 为状态向量，$A \in \mathbb{R}^{n \times n}$ 为系统转移矩阵。

动力系统的唯一解析解： $$ x(t) = e^{At} x_0 $$ 其中状态转移矩阵 $e^{At} = \sum_{k=0}^\infty \frac{t^k}{k!} A^k$ 拥有核心代数性质：
  1. $e^{A \cdot 0} = I$；
  2. $(e^{At})^{-1} = e^{-At}$；
  3. $\frac{d}{dt} e^{At} = A e^{At} = e^{At} A$；
  4. 当且仅当 $A$ 与 $B$ 可交换（$AB = BA$）时，指数可加性才成立：$e^{(A+B)t} = e^{At} e^{Bt}$。

5. Python SciPy 实战：矩阵指数与微分方程组数值解

import numpy as np
import scipy.linalg as la
from scipy.integrate import solve_ivp

# 1. 连续线性动力系统 dx/dt = A x
# 阻尼振荡系统矩阵 A
A = np.array([[-0.5,  2.0],
              [-2.0, -0.5]])

print("系统特征值 (复共轭复数):", la.eigvals(A))

# 2. 计算矩阵指数 e^(A * t) 在 t = 2.0 时的值
t = 2.0
exp_At = la.expm(A * t)
print(f"\n矩阵指数 e^(A*{t}):\n", exp_At)

# 3. 解析解与 ODE 数值积分比对
x0 = np.array([1.0, 0.5])
# 矩阵指数闭式解析解: x(t) = e^(At) x0
x_analytical = exp_At @ x0

# SciPy 龙格-库塔数值积分
def system_ode(t_curr, x_curr):
    return A @ x_curr

sol = solve_ivp(system_ode, [0, t], x0, t_eval=[t], rtol=1e-9)
x_numerical = sol.y[:, 0]

print("\n解析解 x(t=2):", x_analytical)
print("数值积分 x(t=2):", x_numerical)
print(f"解的绝对吻合误差: {np.linalg.norm(x_analytical - x_numerical):.2e}")
