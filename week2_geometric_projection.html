0 思维跃迁：为什么我们需要“几何投影”？

从中学代数的“死胡同”说起

在初中和高中阶段，我们习惯了求解形如 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 的方程组。当时的思维模式是二元非黑即白的：

📚
传统代数视角（理想世界）
2 个未知数，2 个方程：解出唯一的 $(x_1, x_2)$。精确命中，皆大欢喜。
⚠️
遇到现实数据（真实世界）
测量了 100 个带噪声的数据点，试图用直线 $y = kx + b$ 拟合（100 个方程，2 个未知数）。代数老师会告诉你：“方程组无解！”

工程现实的呼唤：难道“无解”就放弃了吗？

显然不能！在机器学习、自动驾驶、计算机视觉和金融量化中，数据点永远远多于模型参数（超定系统 Overdetermined System），且每个测量值都有微小噪声。如果直接说“无解”，整个现代数据科学就无法运转了。

🚀
思维跃迁（The Geometric Leap）：
既然目标点 $\mathbf{z}$ 不在矩阵能够精准表达的平面上，我们就退而求其次 —— 在该平面上寻找一个离目标点 $\mathbf{z}$ 欧氏距离最近的点 $\hat{\mathbf{z}}$。
而在欧几里得几何中，从一点向一个平面引出的线段中，垂线段最短！这个垂足 $\hat{\mathbf{z}}$，就是 $\mathbf{z}$ 在子空间上的正交投影（Orthogonal Projection）。

1 概念基石：向量、线性组合、张成空间 (Span) 与列空间

为了理解投影，我们必须先搞清楚：矩阵到底能生成什么样的空间？它的“射程范围”在哪里？

1.1 什么是线性组合（Linear Combination）？

在线性代数中，我们只允许对一组向量做两种基本操作：标量缩放（乘常数）与向量相加。

给定 $K$ 个 $N$ 维向量 $\mathbf{r}_1, \mathbf{r}_2, \dots, \mathbf{r}_K \in \mathbb{R}^N$，它们的线性组合定义为：

线性组合数学表达式
$$\mathbf{v} = w_1 \mathbf{r}_1 + w_2 \mathbf{r}_2 + \cdots + w_K \mathbf{r}_K = \sum_{k=1}^K w_k \mathbf{r}_k \quad (w_k \in \mathbb{R})$$

1.2 什么是张成空间（Span）？从 1D 到 3D 渐进理解

张成空间（Span）就是所有可能的线性组合汇聚成的集合。想象一下：你拥有这几个向量作为方向舵，通过调节权重 $w_k$，你能在空间中到达哪些位置？

1️⃣
1 个向量 $\text{Span}\{\mathbf{r}_1\}$
只能前后伸缩：$w_1 \mathbf{r}_1$。
👉 几何形态：一条穿过原点的无限 1D 直线。
2️⃣
2 个不共线向量 $\text{Span}\{\mathbf{r}_1, \mathbf{r}_2\}$
两方向自由合成：$w_1 \mathbf{r}_1 + w_2 \mathbf{r}_2$。
👉 几何形态：一个穿过原点的无限 2D 平面。
3️⃣
$K$ 个线性无关向量 $\text{Span}\{\dots\}$
$K$ 个自由度线性合成。
👉 几何形态：嵌入在 $\mathbb{R}^N$ 空间中的一个 $K$ 维超子空间（Subspace）。

1.3 矩阵乘法的“列视角”与列空间 $\text{Col}(\mathbf{R})$

把这 $K$ 个列向量水平拼成一个 $N \times K$ 的矩阵 $\mathbf{R} = [\mathbf{r}_1 \ \mathbf{r}_2 \ \cdots \ \mathbf{r}_K]$。此时，矩阵乘以向量 $\mathbf{R}\mathbf{w}$ 的真正含义是什么？

矩阵向量乘法的列视角本质
$$\mathbf{R}\mathbf{w} = \begin{bmatrix} \mid & \mid & & \mid \\ \mathbf{r}_1 & \mathbf{r}_2 & \cdots & \mathbf{r}_K \\ \mid & \mid & & \mid \end{bmatrix} \begin{bmatrix} w_1 \\ w_2 \\ \vdots \\ w_K \end{bmatrix} = w_1 \mathbf{r}_1 + w_2 \mathbf{r}_2 + \cdots + w_K \mathbf{r}_K$$
🎯
一语道破天机：
$\mathbf{R}\mathbf{w}$ 本质上就是用权重向量 $\mathbf{w}$ 对矩阵 $\mathbf{R}$ 的各个列向量进行线性加权！
因此，矩阵 $\mathbf{R}$ 所有可能输出构成的集合，正是各列向量的张成空间，被称为 列空间（Column Space，记作 $\text{Col}(\mathbf{R})$）。
💡 直观心智模型：$\text{Col}(\mathbf{R})$ 就是矩阵 $\mathbf{R}$ 的“全部射程范围”。

2 方程 $\mathbf{R}\mathbf{w} = \mathbf{z}$ 的三种命运与几何全貌

当我们面对线性方程组 $\mathbf{R}\mathbf{w} = \mathbf{z}$ 时，我们在问什么？

根据上面的列视角，这其实是在问：“目标向量 $\mathbf{z}$ 是否落在矩阵 $\mathbf{R}$ 的射程范围 $\text{Col}(\mathbf{R})$ 之内？”

代数状态 几何判定条件 直观几何场景 应对处理策略
① 唯一精确解 $\mathbf{z} \in \text{Col}(\mathbf{R})$ 且 $\mathbf{R}$ 各列线性无关 目标点 $\mathbf{z}$ 刚好落在平面上，且基底坐标轴没有多余冗余 精确命中 $\mathbf{w}^* = (\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T\mathbf{z}$
② 无精确解（超定） $\mathbf{z} \notin \text{Col}(\mathbf{R})$（通常 $N > K$） 目标点 $\mathbf{z}$ 悬浮在平面外（空中），无论怎么调整 $\mathbf{w}$ 都在平面上够不着 正交投影 寻找平面上离 $\mathbf{z}$ 最近的垂足 $\hat{\mathbf{z}}$
③ 无穷多解 $\mathbf{z} \in \text{Col}(\mathbf{R})$ 但 $\mathbf{R}$ 各列线性相关（退化） 子空间维度退化（如两向量共线），有冗余自由度，存在非零零空间 $\text{Null}(\mathbf{R})$ 自由平移 $\mathbf{w} = \mathbf{w}_0 + t\mathbf{n}$，所有解映射到同一个点

深度剖析：为什么“无穷多解”时投影依然唯一？

很多初学者会困惑：既然有无穷多组解 $\mathbf{w}$，为什么拟合出来的点 $\hat{\mathbf{z}}$ 却是唯一确定的？

参数空间（$\mathbf{w}$ 空间，$\mathbb{R}^K$）
因为列之间存在冗余（例如 $\mathbf{r}_2 = 2\mathbf{r}_1$），使得存在非零向量 $\mathbf{n} = \begin{bmatrix}-2\\1\end{bmatrix}$ 满足 $\mathbf{R}\mathbf{n} = -2\mathbf{r}_1 + 1\mathbf{r}_2 = \mathbf{0}$。这个 $\mathbf{n}$ 属于零空间 $\text{Null}(\mathbf{R})$。
你可以任意加上 $t\mathbf{n}$，$\mathbf{w} = \mathbf{w}_0 + t\mathbf{n}$ 有无数个！
物理输出空间（$\hat{\mathbf{z}}$ 空间，$\mathbb{R}^N$）
计算物理投影点： $$\mathbf{R}\mathbf{w} = \mathbf{R}(\mathbf{w}_0 + t\mathbf{n}) = \mathbf{R}\mathbf{w}_0 + t(\mathbf{R}\mathbf{n}) = \mathbf{R}\mathbf{w}_0 + \mathbf{0} = \mathbf{R}\mathbf{w}_0$$ 看到了吗？虽然你的配方（系数 $\mathbf{w}$）有无穷多种调配方式，但烘焙出来的成品（几何位置 $\hat{\mathbf{z}}$）在物理空间中只有一个！

3 正交投影与法方程（Normal Equation）：从 1D 到高维的保姆级推导

3.1 初阶启蒙：1D 向量点向直线的投影

在推导高维矩阵之前，我们先看初中几何就熟悉的 1 维情况：给定一条过原点的直线方向 $\mathbf{a} \in \mathbb{R}^N$，以及空间中任意一点 $\mathbf{b} \in \mathbb{R}^N$，求 $\mathbf{b}$ 在直线 $\mathbf{a}$ 上的投影点 $\hat{\mathbf{b}}$。

1. 表达投影点：因为 $\hat{\mathbf{b}}$ 在直线 $\mathbf{a}$ 上，它一定是 $\mathbf{a}$ 的倍数，记作 $\hat{\mathbf{b}} = \hat{x} \mathbf{a}$（其中 $\hat{x}$ 是待求的标量系数）。

2. 残差误差向量：连接 $\mathbf{b}$ 与 $\hat{\mathbf{b}}$ 的误差向量为 $\mathbf{e} = \mathbf{b} - \hat{\mathbf{b}} = \mathbf{b} - \hat{x}\mathbf{a}$。

3. 正交条件（核心！）：根据垂线段最短，误差 $\mathbf{e}$ 必须垂直于直线方向 $\mathbf{a}$，即两者的点积（内积）必须为 0：

$$\mathbf{a}^T \mathbf{e} = 0 \implies \mathbf{a}^T (\mathbf{b} - \hat{x}\mathbf{a}) = 0$$ $$\mathbf{a}^T \mathbf{b} - \hat{x} \mathbf{a}^T \mathbf{a} = 0 \implies \hat{x} = \frac{\mathbf{a}^T \mathbf{b}}{\mathbf{a}^T \mathbf{a}}$$

4. 带回得到投影点与 1D 投影矩阵：

$$\hat{\mathbf{b}} = \mathbf{a} \hat{x} = \mathbf{a} \frac{\mathbf{a}^T \mathbf{b}}{\mathbf{a}^T \mathbf{a}} = \left( \frac{\mathbf{a} \mathbf{a}^T}{\mathbf{a}^T \mathbf{a}} \right) \mathbf{b}$$
注意分子与分母的维度区别：
分母 $\mathbf{a}^T \mathbf{a} = \|\mathbf{a}\|^2$ 是一个纯标量（数字）；
分子 $\mathbf{a} \mathbf{a}^T$ 是外积，是一个 $N \times N$ 的矩阵！
因此，$\mathbf{P}_{1D} = \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T\mathbf{a}}$ 就是 1D 投影矩阵。

3.2 高阶推广：高维子空间 $\text{Col}(\mathbf{R})$ 的正交投影

现在，我们将直线 $\mathbf{a}$ 升级为由 $K$ 个基底向量张成的子空间平面 $\mathbf{R} = [\mathbf{r}_1, \mathbf{r}_2, \dots, \mathbf{r}_K]$。目标是将向量 $\mathbf{z} \in \mathbb{R}^N$ 投影到该平面上，得到拟合点 $\hat{\mathbf{z}} = \mathbf{R}\mathbf{w}$。

❓
核心思考：高维情况下，残差向量 $\tilde{\mathbf{z}} = \mathbf{z} - \mathbf{R}\mathbf{w}$ 需要满足什么几何性质？
答：残差向量必须垂直于子空间平面内的每一根基底向量 $\mathbf{r}_1, \mathbf{r}_2, \dots, \mathbf{r}_K$！
直觉证明：假设残差与某根基底向量 $\mathbf{r}_1$ 不垂直（夹角不是 90°），那么你在该基底方向上稍微走动一点点，就能让距离更近。只有当残差与平面内所有可能方向都垂直时，才达到全局欧氏距离最短！

3.3 四步手把手推导法方程（Normal Equation）

  1. 写出每个基底向量的正交等式：
    残差 $\tilde{\mathbf{z}} = \mathbf{z} - \mathbf{R}\mathbf{w}$ 与第 $j$ 个基向量 $\mathbf{r}_j$ 垂直，其内积为 0： $$\mathbf{r}_1^T (\mathbf{z} - \mathbf{R}\mathbf{w}) = 0, \quad \mathbf{r}_2^T (\mathbf{z} - \mathbf{R}\mathbf{w}) = 0, \quad \dots, \quad \mathbf{r}_K^T (\mathbf{z} - \mathbf{R}\mathbf{w}) = 0$$
  2. 将 $K$ 个等式垂直打包成矩阵乘法：
    把每一行 $\mathbf{r}_j^T$ 叠起来，正好就是转置矩阵 $\mathbf{R}^T$！ $$\begin{bmatrix} \mathbf{r}_1^T \\ \mathbf{r}_2^T \\ \vdots \\ \mathbf{r}_K^T \end{bmatrix} (\mathbf{z} - \mathbf{R}\mathbf{w}) = \begin{bmatrix} 0 \\ 0 \\ \vdots \\ 0 \end{bmatrix} \implies \mathbf{R}^T (\mathbf{z} - \mathbf{R}\mathbf{w}) = \mathbf{0}$$
  3. 利用矩阵分配律拆开括号： $$\mathbf{R}^T \mathbf{z} - \mathbf{R}^T \mathbf{R} \mathbf{w} = \mathbf{0}$$
  4. 移项得到闻名遐迩的“法方程（Normal Equation）”：
    法方程（Normal Equation）
    $$\mathbf{R}^T \mathbf{R} \mathbf{w} = \mathbf{R}^T \mathbf{z}$$
💡
几何美感：
原来看似玄妙的法方程 $\mathbf{R}^T \mathbf{R}\mathbf{w} = \mathbf{R}^T\mathbf{z}$，没有任何高深莫测的魔法，它仅仅是“垂线垂直于平面内的每一根基准线”用矩阵语言书写出来的一句话而已！

4 投影矩阵 $\mathbf{P}$（Hat Matrix）的数学本质与避坑指南

4.1 解出最优系数 $\mathbf{w}^*$ 与构造投影矩阵 $\mathbf{P}$

当 $\mathbf{R}$ 的列线性无关时，矩阵 $\mathbf{R}^T\mathbf{R}$ 是一个 $K \times K$ 的对称正定可逆方阵。我们在法方程两边同时左乘逆矩阵 $(\mathbf{R}^T\mathbf{R})^{-1}$：

$$\mathbf{w}^* = (\mathbf{R}^T\mathbf{R})^{-1} \mathbf{R}^T \mathbf{z}$$

将求出的最优加权系数 $\mathbf{w}^*$ 代回到拟合值 $\hat{\mathbf{z}} = \mathbf{R}\mathbf{w}^*$ 中：

投影矩阵（Projection Matrix / Hat Matrix）
$$\hat{\mathbf{z}} = \mathbf{R} \left[ (\mathbf{R}^T\mathbf{R})^{-1} \mathbf{R}^T \mathbf{z} \right] = \underbrace{\left[ \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T \right]}_{\mathbf{P}} \mathbf{z} = \mathbf{P}\mathbf{z}$$ $$\mathbf{P} = \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T$$

在统计学中，$\mathbf{P}$ 也被称为 Hat Matrix（帽子矩阵），因为它是把 $z$ 戴上帽子变成 $\hat{z}$ 的算子。

🚨
初学者致命陷阱：为什么不能直接拆括号？
很多初学者在草稿纸上推导时会这样写：
$\mathbf{P} = \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T = \mathbf{R} \mathbf{R}^{-1} (\mathbf{R}^T)^{-1} \mathbf{R}^T = \mathbf{I} \cdot \mathbf{I} = \mathbf{I}$ （❌ 严重错误！）
问：错在哪里？
答：因为 $\mathbf{R}$ 是一个 $N \times K$ 的长方形瘦高矩阵（$N > K$）！长方矩阵根本不存在普通逆矩阵 $\mathbf{R}^{-1}$！只有当方阵满秩时 $(AB)^{-1} = B^{-1}A^{-1}$ 的分配法则才成立。虽然 $\mathbf{R}^T\mathbf{R}$ 是 $K \times K$ 的可逆方阵，但绝不能拆开成单个非方阵的逆。

4.2 投影矩阵 $\mathbf{P}$ 的两大核心几何性质

1️⃣
对称性（Symmetric）：$\mathbf{P}^T = \mathbf{P}$
代数验证： $$\begin{aligned} \mathbf{P}^T &= \left[ \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T \right]^T \\ &= (\mathbf{R}^T)^T [(\mathbf{R}^T\mathbf{R})^{-1}]^T \mathbf{R}^T \\ &= \mathbf{R} [(\mathbf{R}^T\mathbf{R})^T]^{-1} \mathbf{R}^T \\ &= \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T = \mathbf{P} \quad \checkmark \end{aligned}$$ 👉 几何含义：正交投影没有扭曲与旋转剪切。
2️⃣
幂等性（Idempotent）：$\mathbf{P}^2 = \mathbf{P}$
代数验证： $$\begin{aligned} \mathbf{P}^2 &= \left[ \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T \right] \cdot \left[ \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T \right] \\ &= \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1} \underbrace{(\mathbf{R}^T\mathbf{R}) (\mathbf{R}^T\mathbf{R})^{-1}}_{\mathbf{I}} \mathbf{R}^T \\ &= \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T = \mathbf{P} \quad \checkmark \end{aligned}$$ 👉 几何含义（熨斗原理）：把一件衣服熨平到桌面上后，再拿熨斗熨一次，衣服位置绝不会再改变！

4.3 正交补空间与高维勾股定理

空间中的任意向量 $\mathbf{z}$ 都可以唯一正交分解为子空间分量 $\hat{\mathbf{z}}$ 与正交补空间分量（残差）$\tilde{\mathbf{z}}$：

$$\mathbf{z} = \hat{\mathbf{z}} + \tilde{\mathbf{z}} = \mathbf{P}\mathbf{z} + (\mathbf{I} - \mathbf{P})\mathbf{z}$$ $$\tilde{\mathbf{z}} = (\mathbf{I} - \mathbf{P})\mathbf{z} \quad (\mathbf{I} - \mathbf{P} \text{ 是向正交补空间的投影矩阵})$$

由于 $\hat{\mathbf{z}} \perp \tilde{\mathbf{z}}$，勾股定理（毕达哥拉斯定理）在高维空间依然严格成立：

高维毕达哥拉斯正交分解定理
$$\|\mathbf{z}\|^2 = \|\hat{\mathbf{z}}\|^2 + \|\tilde{\mathbf{z}}\|^2 \iff \|\mathbf{z}\|^2 = \|\mathbf{P}\mathbf{z}\|^2 + \|(\mathbf{I}-\mathbf{P})\mathbf{z}\|^2$$

5 实战手算演练：Step-by-Step 完整算一遍！

理论懂了，只有亲手一步步算一次具体的数字，才能彻底建立肌肉记忆。我们用一个经典的 3D 空间例子：

【题目设定】
在 3 维空间 $\mathbb{R}^3$ 中，给定平面基底向量 $\mathbf{r}_1 = \begin{bmatrix}1\\1\\0\end{bmatrix}, \mathbf{r}_2 = \begin{bmatrix}0\\1\\1\end{bmatrix}$，拼成矩阵 $\mathbf{R} = \begin{bmatrix}1 & 0\\1 & 1\\0 & 1\end{bmatrix}$。
目标向量为悬浮在空中的点 $\mathbf{z} = \begin{bmatrix}1\\2\\2\end{bmatrix}$。
请计算：最优加权系数 $\mathbf{w}$、平面上的拟合点 $\hat{\mathbf{z}}$、残差向量 $\tilde{\mathbf{z}}$，并验证正交性与勾股定理。
👉 第一步：计算转置乘积 $\mathbf{R}^T\mathbf{R}$ 与 $\mathbf{R}^T\mathbf{z}$
$$\mathbf{R}^T\mathbf{R} = \begin{bmatrix}1 & 1 & 0\\0 & 1 & 1\end{bmatrix} \begin{bmatrix}1 & 0\\1 & 1\\0 & 1\end{bmatrix} = \begin{bmatrix}1\cdot 1 + 1\cdot 1 + 0 & 1\cdot 0 + 1\cdot 1 + 0\\0 + 1\cdot 1 + 0 & 0 + 1\cdot 1 + 1\cdot 1\end{bmatrix} = \begin{bmatrix}2 & 1\\1 & 2\end{bmatrix}$$ $$\mathbf{R}^T\mathbf{z} = \begin{bmatrix}1 & 1 & 0\\0 & 1 & 1\end{bmatrix} \begin{bmatrix}1\\2\\2\end{bmatrix} = \begin{bmatrix}1\cdot 1 + 1\cdot 2 + 0\\0 + 1\cdot 2 + 1\cdot 2\end{bmatrix} = \begin{bmatrix}3\\4\end{bmatrix}$$
👉 第二步：求 $2\times 2$ 矩阵逆 $(\mathbf{R}^T\mathbf{R})^{-1}$ 并解出 $\mathbf{w}^*$
矩阵行列式 $\det(\mathbf{R}^T\mathbf{R}) = 2\times 2 - 1\times 1 = 3$。
根据二阶矩阵求逆公式 $\begin{bmatrix}a & b\\c & d\end{bmatrix}^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d & -b\\-c & a\end{bmatrix}$： $$(\mathbf{R}^T\mathbf{R})^{-1} = \frac{1}{3} \begin{bmatrix}2 & -1\\-1 & 2\end{bmatrix}$$ 最优解 $\mathbf{w}^*$ 为： $$\mathbf{w}^* = (\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T\mathbf{z} = \frac{1}{3}\begin{bmatrix}2 & -1\\-1 & 2\end{bmatrix}\begin{bmatrix}3\\4\end{bmatrix} = \frac{1}{3}\begin{bmatrix}2\cdot 3 - 1\cdot 4\\-1\cdot 3 + 2\cdot 4\end{bmatrix} = \frac{1}{3}\begin{bmatrix}2\\5\end{bmatrix} = \begin{bmatrix}2/3\\5/3\end{bmatrix}$$
👉 第三步：计算投影拟合点 $\hat{\mathbf{z}} = \mathbf{R}\mathbf{w}^*$
$$\hat{\mathbf{z}} = \mathbf{R}\mathbf{w}^* = \frac{2}{3}\mathbf{r}_1 + \frac{5}{3}\mathbf{r}_2 = \frac{2}{3}\begin{bmatrix}1\\1\\0\end{bmatrix} + \frac{5}{3}\begin{bmatrix}0\\1\\1\end{bmatrix} = \begin{bmatrix}2/3\\7/3\\5/3\end{bmatrix}$$
👉 第四步：计算残差向量 $\tilde{\mathbf{z}}$ 并验证正交性
残差向量： $$\tilde{\mathbf{z}} = \mathbf{z} - \hat{\mathbf{z}} = \begin{bmatrix}1\\2\\2\end{bmatrix} - \begin{bmatrix}2/3\\7/3\\5/3\end{bmatrix} = \begin{bmatrix}1/3\\-1/3\\1/3\end{bmatrix}$$ 检验正交性（残差是否垂直于平面上的每一个基向量？）： $$\mathbf{r}_1^T \tilde{\mathbf{z}} = \begin{bmatrix}1 & 1 & 0\end{bmatrix} \begin{bmatrix}1/3\\-1/3\\1/3\end{bmatrix} = \frac{1}{3} - \frac{1}{3} + 0 = 0 \quad \checkmark$$ $$\mathbf{r}_2^T \tilde{\mathbf{z}} = \begin{bmatrix}0 & 1 & 1\end{bmatrix} \begin{bmatrix}1/3\\-1/3\\1/3\end{bmatrix} = 0 - \frac{1}{3} + \frac{1}{3} = 0 \quad \checkmark$$ 正交条件完全成立！证明我们找到的确实是严格的垂足。
👉 第五步：验证勾股定理长度关系
$$\|\mathbf{z}\|^2 = 1^2 + 2^2 + 2^2 = 9 = \frac{81}{9}$$ $$\|\hat{\mathbf{z}}\|^2 = (2/3)^2 + (7/3)^2 + (5/3)^2 = \frac{4 + 49 + 25}{9} = \frac{78}{9}$$ $$\|\tilde{\mathbf{z}}\|^2 = (1/3)^2 + (-1/3)^2 + (1/3)^2 = \frac{1 + 1 + 1}{9} = \frac{3}{9}$$ $$\|\hat{\mathbf{z}}\|^2 + \|\tilde{\mathbf{z}}\|^2 = \frac{78}{9} + \frac{3}{9} = \frac{81}{9} = 9 = \|\mathbf{z}\|^2 \quad \checkmark$$ 高维勾股定理丝毫不差！

7 工业应用与知识地图：从这里通向何方？

📈
1. 最小二乘法 (OLS)
机器学习中最经典的线性回归（Linear Regression）损失函数最小化：$\min_{\mathbf{w}} \|\mathbf{X}\mathbf{w} - \mathbf{y}\|^2$，求导等于 0 得到的正是 $\mathbf{X}^T\mathbf{X}\mathbf{w} = \mathbf{X}^T\mathbf{y}$！
📉
2. 主成分分析 (PCA)
高维数据降维的本质，就是寻找一个低维正交子空间，使得数据在投影到该子空间后的重构误差（残差平方和）最小。
🤖
3. Attention (QKV) 机制
大模型中的 Attention 矩阵计算，本质是 Query 向量向各个 Key 向量所张成的语义子空间进行内积投影与注意力打分匹配。

第2周核心知识卡片速查表

核心概念 代数符号 几何直观与心智模型
张成空间 Span $\text{Span}\{\mathbf{r}_1,\dots,\mathbf{r}_K\}$ 给定基向量所有可能线性伸缩相加能达到的全部空间
列空间 Col $\text{Col}(\mathbf{R})$ 矩阵各列张成的子空间，即矩阵输出的“全部射程”
残差向量 $\tilde{\mathbf{z}} = \mathbf{z} - \hat{\mathbf{z}} = \mathbf{z} - \mathbf{R}\mathbf{w}$ 目标点到子空间垂足的垂线段，垂直于平面内所有向量
法方程 $\mathbf{R}^T\mathbf{R}\mathbf{w} = \mathbf{R}^T\mathbf{z}$ 正交条件 $\mathbf{R}^T(\mathbf{z}-\mathbf{R}\mathbf{w})=\mathbf{0}$ 展开后的核心方程
投影矩阵 $\mathbf{P} = \mathbf{R}(\mathbf{R}^T\mathbf{R})^{-1}\mathbf{R}^T$ 把空间任意向量正交“拍平”到列空间上的算子，满足 $\mathbf{P}^T=\mathbf{P}, \mathbf{P}^2=\mathbf{P}$
零空间自由度 $\mathbf{R}\mathbf{n} = \mathbf{0} \implies \mathbf{w} = \mathbf{w}_0 + t\mathbf{n}$ 冗余基底导致参数配方不唯一，但物理合成结果 $\mathbf{R}\mathbf{w}$ 唯一
