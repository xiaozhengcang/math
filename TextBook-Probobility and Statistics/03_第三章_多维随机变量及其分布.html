第三章 多维随机变量及其分布

在实际工程和科学研究中，许多随机现象需要同时用多个随机变量来综合刻画. 例如，气象预报中需要同时观测气温、湿度、气压和风速；体检时要同时测量身高和体重；打靶试验中炮弹落点的位置由二维平面坐标 $(X, Y)$ 共同决定. 此外，这些变量之间往往存在着某种内在的相互关联或制约关系. 本章我们将从一维随机变量推广到多维随机变量（特别是二维随机变量），研究联合分布、边缘分布、条件分布以及随机变量的相互独立性.

第一节 多维随机变量及其联合分布

一、二维随机变量与联合分布函数

📌 定义 3.1：二维随机变量与联合分布函数

设 $E$ 为随机试验，样本空间为 $\Omega$. 设 $X = X(\omega)$ 和 $Y = Y(\omega)$ 是定义在 $\Omega$ 上的两个随机变量，由它们构成的向量 $(X, Y)$ 称为二维随机变量（或二维随机向量）.

对任意实数 $x, y$，二元实值函数： $$F(x, y) = P(X \le x, Y \le y), \qquad -\infty < x < +\infty, \; -\infty < y < +\infty$$ 称为二维随机变量 $(X, Y)$ 的联合分布函数（Joint Cumulative Distribution Function）.

💡 定理 3.1：联合分布函数的四大基本性质
  1. 单调不减性：$F(x, y)$ 分别对 $x$ 和 $y$ 单调不减；
  2. 有界性与极限性质：对任意实数 $x, y$，有 $0 \le F(x, y) \le 1$，且： $$F(-\infty, y) = 0, \quad F(x, -\infty) = 0, \quad F(-\infty, -\infty) = 0, \quad F(+\infty, +\infty) = 1$$
  3. 偏右连续性：$F(x, y)$ 分别关于 $x$ 和关于 $y$ 均为右连续函数；
  4. 矩形不等式（概率非负性充要准则）：对于任意实数 $x_1 < x_2, y_1 < y_2$，随机点 $(X, Y)$ 落在矩形区域 $(x_1, x_2] \times (y_1, y_2]$ 的概率为： $$P(x_1 < X \le x_2, \; y_1 < Y \le y_2) = F(x_2, y_2) - F(x_1, y_2) - F(x_2, y_1) + F(x_1, y_1) \ge 0$$

二、二维离散型随机变量及其联合分布律

📌 定义 3.2：二维离散型联合分布律

如果二维随机变量 $(X, Y)$ 的全部可能取值对是有限个或无限可列个对点 $(x_i, y_j)$，且取这些值的概率为： $$P(X = x_i, Y = y_j) = p_{ij}, \qquad i, j = 1, 2, \dots$$

则称 $(X, Y)$ 为二维离散型随机变量，$p_{ij}$ 称为其联合概率分布律.

充要性质：(1) $p_{ij} \ge 0$； (2) $\sum_i \sum_j p_{ij} = 1$.

三、二维连续型随机变量及其联合概率密度

📌 定义 3.3：二维连续型随机变量与联合概率密度（Joint PDF）

对于二维随机变量 $(X, Y)$ 的联合分布函数 $F(x, y)$，如果存在非负可积函数 $f(x, y)$，使得对任意实数 $x, y$，都有： $$F(x, y) = \int_{-\infty}^x \int_{-\infty}^y f(u, v) \, du \, dv$$

则称 $(X, Y)$ 为二维连续型随机变量，$f(x, y)$ 称为其联合概率密度函数.

💡 定理 3.2：联合概率密度的性质
  1. 非负性：$f(x, y) \ge 0$；
  2. 全平面二重积分归一性：$$\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) \, dx \, dy = 1$$
  3. 任意平面平面区域 $D$ 的概率计算： $$P((X, Y) \in D) = \iint_D f(x, y) \, dx \, dy$$
  4. 偏导数关系：在 $f(x, y)$ 的连续点处，有： $$\frac{\partial^2 F(x, y)}{\partial x \, \partial y} = f(x, y)$$

第二节 常用的多维分布

一、二维均匀分布

设 $D$ 为平面上有界区域，其面积为 $S_D > 0$. 若 $(X, Y)$ 的联合概率密度为： $$f(x, y) = \begin{cases} \frac{1}{S_D}, & (x, y) \in D \\ 0, & \text{其他} \end{cases}$$ 则称 $(X, Y)$ 在区域 $D$ 上服从二维均匀分布.

二、二维正态分布

📌 定义 3.4：二维正态分布

若二维连续型随机变量 $(X, Y)$ 的联合概率密度函数为： $$f(x, y) = \frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}} \exp\left\{ -\frac{1}{2(1-\rho^2)} \left[ \frac{(x-\mu_1)^2}{\sigma_1^2} - 2\rho\frac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2} \right] \right\}$$ 其中 $\mu_1, \mu_2 \in \mathbb{R}, \sigma_1 > 0, \sigma_2 > 0, -1 < \rho < 1$，则称 $(X, Y)$ 服从参数为 $\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho$ 的二维正态分布，记作： $$(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$$

第三节 边缘分布与随机变量的独立性

一、边缘分布函数

由联合分布函数求分量 $X$ 或 $Y$ 各自的分布函数，称为边缘分布函数： $$F_X(x) = P(X \le x) = P(X \le x, Y < +\infty) = F(x, +\infty)$$ $$F_Y(y) = P(Y \le y) = P(X < +\infty, Y \le y) = F(+\infty, y)$$

二、离散型与连续型的边缘分布

1. 二维离散型的边缘分布律（按行/按列求和）： $$p_{i\cdot} = P(X = x_i) = \sum_{j=1}^\infty p_{ij}, \qquad p_{\cdot j} = P(Y = y_j) = \sum_{i=1}^\infty p_{ij}$$

2. 二维连续型的边缘概率密度（对另一变量积分）： $$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy, \qquad f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

💡 定理 3.3：二维正态变量的边缘分布必然是一维正态分布

若 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则其两个分量的边缘分布分别服从一维正态分布： $$X \sim N(\mu_1, \sigma_1^2), \qquad Y \sim N(\mu_2, \sigma_2^2)$$

特别提醒（重要考点）：反之不成立！两个分量分别服从正态分布，它们的联合分布不一定是二维正态分布！

三、随机变量的相互独立性

📌 定义 3.5：随机变量的独立性

设 $(X, Y)$ 为二维随机变量，如果对任意实数 $x, y$，都有： $$F(x, y) = F_X(x) \cdot F_Y(y)$$ 则称随机变量 $X$ 与 $Y$ 相互独立.

等价判别法则：

  • 离散型独立充要条件：对所有的 $i, j$，有 $p_{ij} = p_{i\cdot} \times p_{\cdot j}$；
  • 连续型独立充要条件：在平面上除面积为 0 的点集外，有： $$f(x, y) = f_X(x) \cdot f_Y(y)$$
💡 定理 3.4：二维正态分布中“独立”与“不相关”完全等价

若 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则： $$X \text{ 与 } Y \text{ 相互独立} \iff \rho = 0$$

在一般随机变量中，“独立”可以推出“不相关（$\rho=0$）”，但“不相关”推不出“独立”；唯独在正态分布的优良性质下，独立与不相关完全等价！

第四节 条件分布

一、离散型条件分布律

设 $(X, Y)$ 为离散型随机变量，若 $P(Y = y_j) = p_{\cdot j} > 0$，则在给定 $Y = y_j$ 的条件下 $X$ 的条件分布律为： $$P(X = x_i \mid Y = y_j) = \frac{P(X = x_i, Y = y_j)}{P(Y = y_j)} = \frac{p_{ij}}{p_{\cdot j}}, \qquad i = 1, 2, \dots$$

二、连续型条件概率密度

设 $(X, Y)$ 为连续型随机变量，联合密度为 $f(x, y)$，边缘密度为 $f_X(x), f_Y(y)$. 若在点 $y$ 处 $f_Y(y) > 0$，则在条件 $Y = y$ 下 $X$ 的条件概率密度函数为： $$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)}$$ 类似地，在条件 $X = x$ 下 $Y$ 的条件概率密度为： $$f_{Y|X}(y|x) = \frac{f(x, y)}{f_X(x)}$$

第五节 二维随机变量函数的分布

一、两独立随机变量之和的分布（卷积公式）

💡 定理 3.5：连续型和的分布卷积公式（Convolution）

设 $X$ 和 $Y$ 是两个相互独立的连续型随机变量，其概率密度分别为 $f_X(x)$ 和 $f_Y(y)$，则和变量 $Z = X + Y$ 的概率密度函数为： $$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z - x) \, dx = \int_{-\infty}^{+\infty} f_X(z - y) f_Y(y) \, dy$$ 该积分运算称为 $f_X$ 与 $f_Y$ 的卷积，记作 $f_Z = f_X * f_Y$.

💡 定理 3.6：正态变量和的可加性（再生性）

若 $X_1 \sim N(\mu_1, \sigma_1^2), X_2 \sim N(\mu_2, \sigma_2^2)$ 且 $X_1, X_2$ 相互独立，则它们的线性组合仍服从正态分布： $$a X_1 + b X_2 + c \sim N(a\mu_1 + b\mu_2 + c, \; a^2\sigma_1^2 + b^2\sigma_2^2)$$

二、最大值与最小值的分布（极值分布）

💡 定理 3.7：独立变量极值分布公式

设 $X$ 与 $Y$ 相互独立，分布函数分别为 $F_X(x)$ 与 $F_Y(y)$：

1. 最大值 $M = \max(X, Y)$ 的分布函数： $$F_{\max}(z) = P(\max(X, Y) \le z) = P(X \le z, Y \le z) = F_X(z) \cdot F_Y(z)$$ 推广到 $n$ 个独立变量：$F_{\max}(z) = \prod_{i=1}^n F_{X_i}(z)$；若同分布，则 $F_{\max}(z) = [F(z)]^n$.

2. 最小值 $L = \min(X, Y)$ 的分布函数： $$F_{\min}(z) = P(\min(X, Y) \le z) = 1 - P(X > z, Y > z) = 1 - [1 - F_X(z)][1 - F_Y(z)]$$ 推广到 $n$ 个独立同分布变量： $$F_{\min}(z) = 1 - [1 - F(z)]^n$$

📝 例 15：串联与并联系统寿命分析

设某并联冗余电路由两个相互独立工作的相同元件组成，元件寿命服从参数为 $\lambda$ 的指数分布 $E(\lambda)$. 求该系统正常工作寿命 $T$ 的概率密度.

【解】 并联系统寿命 $T = \max(T_1, T_2)$. 单个元件的分布函数为 $F(t) = 1 - e^{-\lambda t}$ ($t > 0$).

由最大值分布公式： $$F_T(t) = [F(t)]^2 = (1 - e^{-\lambda t})^2 = 1 - 2e^{-\lambda t} + e^{-2\lambda t}, \qquad (t > 0)$$

两边求导得系统寿命概率密度： $$f_T(t) = F_T'(t) = 2\lambda e^{-\lambda t} - 2\lambda e^{-2\lambda t} = 2\lambda e^{-\lambda t}(1 - e^{-\lambda t}), \qquad (t > 0)$$

本章小结与复习指南

📚 本章核心考点脉络

1. 联合分布 vs 边缘分布：联合分布包含全部信息，求边缘分布离散型是按行/列求和，连续型是对另一变量在 $(-\infty, +\infty)$ 上积分；

2. 独立性的核心判据：$F(x, y) = F_X(x)F_Y(y)$ 或 $f(x, y) = f_X(x)f_Y(y)$；

3. 正态独立性特权：二维正态变量中 $\rho = 0$ 是独立的充要条件；

4. 和的卷积公式：$Z = X + Y \implies f_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x) \, dx$；

5. 极值分布：$\max$ 是分布函数直接乘积，$\min$ 是通过“全不发生”利用余事件转为 $1 - \prod [1 - F(z)]$.
