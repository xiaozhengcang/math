第四章 随机变量的数字特征

在前面的章节中，我们学习了用分布律、分布函数或概率密度来完整描述随机变量的统计特征. 然而在许多实际应用中，由于客观条件的限制，我们可能无法或不需要知道随机变量的完整分布形态，而只需要掌握能够集中反映随机变量核心特性的若干个关键数值指标——例如平均水平、波动离散程度、变量间的关联程度等. 这类在概率统计中起关键作用的常数，统称为随机变量的数字特征.

第一节 数学期望

一、数学期望的定义

数学期望（Mathematical Expectation）简称为期望，又称均值，它是刻画随机变量取值集中趋势的最重要位置特征.

📌 定义 4.1：离散型随机变量的数学期望

设离散型随机变量 $X$ 的分布律为 $P(X = x_k) = p_k$ ($k = 1, 2, \dots$). 如果级数 $$\sum_{k=1}^\infty x_k p_k$$ 绝对收敛，即 $\sum_{k=1}^\infty |x_k| p_k < +\infty$，则称该级数的和为随机变量 $X$ 的数学期望，记作 $E(X)$ 或 $\mu$，即： $$E(X) = \sum_{k=1}^\infty x_k p_k$$

📌 定义 4.2：连续型随机变量的数学期望

设连续型随机变量 $X$ 的概率密度函数为 $f(x)$. 如果广义反常积分 $$\int_{-\infty}^{+\infty} x f(x) \, dx$$ 绝对收敛，即 $\int_{-\infty}^{+\infty} |x| f(x) \, dx < +\infty$，则称该积分的值为连续型随机变量 $X$ 的数学期望，记作： $$E(X) = \int_{-\infty}^{+\infty} x f(x) \, dx$$

📘 为什么必须强调“绝对收敛”？（柯西分布的期望不存在）

如果级数或积分不是绝对收敛，根据微积分黎曼重排定理，级数重排顺序后会产生歧义甚至发散. 著名的反例是柯西分布（Cauchy Distribution），其概率密度为 $f(x) = \frac{1}{\pi(1+x^2)}$，虽然图形对称，但 $\int_{-\infty}^{+\infty} |x|f(x)\,dx = \infty$，因此柯西分布的数学期望不存在！

二、随机变量函数的数学期望定理

💡 定理 4.1：随机变量函数的期望公式（无需先求函数本身的分布）

(1) 一维情形：设 $Y = g(X)$ 为随机变量 $X$ 的函数：

  • 若 $X$ 为离散型，分布律为 $P(X = x_k) = p_k$，则当级数绝对收敛时： $$E[g(X)] = \sum_k g(x_k) p_k$$
  • 若 $X$ 为连续型，概率密度为 $f(x)$，则当积分绝对收敛时： $$E[g(X)] = \int_{-\infty}^{+\infty} g(x) f(x) \, dx$$

(2) 二维情形：设 $Z = g(X, Y)$ 为二维随机变量 $(X, Y)$ 的函数：

  • 离散型：$$E[g(X, Y)] = \sum_i \sum_j g(x_i, y_j) p_{ij}$$
  • 连续型：$$E[g(X, Y)] = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} g(x, y) f(x, y) \, dx \, dy$$

三、数学期望的基本性质

💡 定理 4.2：数学期望的四大线性性质
  1. 常数的期望等于自身：设 $c$ 为常数，则 $E(c) = c$；
  2. 常数因子可提至期望符号外：设 $c$ 为常数，则 $E(cX) = cE(X)$；
  3. 线性可加性（无条件成立）：对任意两个随机变量 $X, Y$（不论它们是否相互独立），恒有： $$E(X \pm Y) = E(X) \pm E(Y)$$ 推广到任意有限个随机变量：$E\left(\sum_{i=1}^n c_i X_i\right) = \sum_{i=1}^n c_i E(X_i)$；
  4. 乘积的可乘性（独立条件）：如果随机变量 $X$ 与 $Y$ 相互独立，则： $$E(XY) = E(X) \cdot E(Y)$$

四、常见随机变量的数学期望速查

  • $0\text{-}1$ 分布 $X \sim B(1, p)$：$E(X) = p$；
  • 二项分布 $X \sim B(n, p)$：$E(X) = np$（分解为 $n$ 个独立两点变量 $X = \sum X_i$ 直接得 $n \times p$）；
  • 泊松分布 $X \sim P(\lambda)$：$E(X) = \lambda$；
  • 几何分布 $X \sim G(p)$：$E(X) = \frac{1}{p}$；
  • 均匀分布 $X \sim U(a, b)$：$E(X) = \frac{a + b}{2}$；
  • 指数分布 $X \sim E(\lambda)$：$E(X) = \frac{1}{\lambda}$；
  • 正态分布 $X \sim N(\mu, \sigma^2)$：$E(X) = \mu$.

第二节 方差和标准差

一、方差和标准差的定义

数学期望给出了随机变量取值的平均中心位置，但无法反映随机变量取值在其中心周围的分散或波动程度. 例如两只股票平均年收益均为 10%，但一只波动范围在 8%~12% 之间，另一只在 -30%~50% 之间剧烈震荡，两者的风险迥然不同. 为衡量这种波动性，引出方差.

📌 定义 4.3：方差与标准差

设 $X$ 为随机变量，若 $E\{[X - E(X)]^2\}$ 存在，则称偏差平方的数学期望为 $X$ 的方差（Variance），记作 $D(X)$ 或 $\mathrm{Var}(X)$ 或 $\sigma^2$，即： $$D(X) = E\{[X - E(X)]^2\}$$

方差的算术平方根 $\sigma(X) = \sqrt{D(X)}$ 称为随机变量 $X$ 的标准差（Standard Deviation），其量纲与随机变量 $X$ 本身一致.

💡 定理 4.3：方差的最实用化简计算公式

在实际解题和理论推导中，方差几乎总是使用下列公式展开计算： $$D(X) = E(X^2) - [E(X)]^2$$

【推导证明】 令 $\mu = E(X)$ 为常数，展开平方得： $$\begin{aligned} D(X) &= E[(X - \mu)^2] = E(X^2 - 2\mu X + \mu^2) \\ &= E(X^2) - 2\mu E(X) + \mu^2 = E(X^2) - 2\mu^2 + \mu^2 \\ &= E(X^2) - \mu^2 = E(X^2) - [E(X)]^2 \qquad \blacksquare \end{aligned}$$

二、方差的基本性质

💡 定理 4.4：方差的性质
  1. 常数的方差为 0：$D(c) = 0$；反之，$D(X) = 0 \iff P(X = c) = 1$（$X$ 几乎处处为常数）；
  2. 常数因子的平方倍法则：设 $a, b$ 为常数，则： $$D(aX + b) = a^2 D(X)$$ （平移量 $b$ 不改变离散波动幅度，故方差对常数平移不敏感）；
  3. 一般和的方差公式：对任意随机变量 $X, Y$： $$D(X \pm Y) = D(X) + D(Y) \pm 2 \mathrm{Cov}(X, Y)$$
  4. 独立变量的方差可加性：若 $X$ 与 $Y$ 相互独立（或不相关），则： $$D(X \pm Y) = D(X) + D(Y)$$ 推广到 $n$ 个独立变量：$D\left(\sum_{i=1}^n a_i X_i\right) = \sum_{i=1}^n a_i^2 D(X_i)$.

三、标准化随机变量

📌 定义 4.4：标准化变量

设随机变量 $X$ 的均值为 $\mu = E(X)$，方差为 $\sigma^2 = D(X) > 0$. 构造无量纲的新随机变量： $$X^* = \frac{X - E(X)}{\sqrt{D(X)}} = \frac{X - \mu}{\sigma}$$ 称 $X^*$ 为 $X$ 的标准化随机变量（Standardized Random Variable），其必然满足： $$E(X^*) = 0, \qquad D(X^*) = 1$$

四、常见随机变量的方差速查

  • $0\text{-}1$ 分布 $X \sim B(1, p)$：$D(X) = p(1-p) = pq$；
  • 二项分布 $X \sim B(n, p)$：$D(X) = np(1-p) = npq$；
  • 泊松分布 $X \sim P(\lambda)$：$D(X) = \lambda$（泊松分布的期望等于方差！）；
  • 均匀分布 $X \sim U(a, b)$：$D(X) = \frac{(b - a)^2}{12}$；
  • 指数分布 $X \sim E(\lambda)$：$D(X) = \frac{1}{\lambda^2}$（标准差等于期望：$\sigma = \mu = \frac{1}{\lambda}$）；
  • 正态分布 $X \sim N(\mu, \sigma^2)$：$D(X) = \sigma^2$.

第三节 协方差和相关系数

一、协方差的定义与性质

📌 定义 4.5：协方差

对二维随机变量 $(X, Y)$，称数值 $$\mathrm{Cov}(X, Y) = E\{[X - E(X)][Y - E(Y)]\}$$ 为随机变量 $X$ 与 $Y$ 的协方差（Covariance）.

协方差展开实用公式： $$\mathrm{Cov}(X, Y) = E(XY) - E(X)E(Y)$$

协方差的基本性质：

  1. 对称性：$\mathrm{Cov}(X, Y) = \mathrm{Cov}(Y, X)$；
  2. 自协方差即方差：$\mathrm{Cov}(X, X) = D(X)$；
  3. 常数性质：$\mathrm{Cov}(aX, bY) = ab \,\mathrm{Cov}(X, Y)$；$\mathrm{Cov}(X + c, Y) = \mathrm{Cov}(X, Y)$；
  4. 双线性可加性：$\mathrm{Cov}(X_1 + X_2, Y) = \mathrm{Cov}(X_1, Y) + \mathrm{Cov}(X_2, Y)$；
  5. 如果 $X$ 与 $Y$ 独立，则 $E(XY) = E(X)E(Y)$，故 $\mathrm{Cov}(X, Y) = 0$.

二、相关系数

由于协方差带有量纲，其绝对值大小不仅取决于变量间的关联程度，还强烈受到变量单位尺度的影响（例如把长度单位从米改成毫米，协方差会膨胀 $10^6$ 倍）. 为了消除量纲干扰，必须进行标准化无量纲化处理，由此定义相关系数.

📌 定义 4.6：相关系数

设 $D(X) > 0, D(Y) > 0$，称数值 $$\rho_{XY} = \frac{\mathrm{Cov}(X, Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$ 为随机变量 $X$ 与 $Y$ 的相关系数（Correlation Coefficient，通常简记为 $\rho$）.

相关系数本质上正是标准化随机变量 $X^*$ 与 $Y^*$ 的协方差：$$\rho_{XY} = \mathrm{Cov}(X^*, Y^*) = E(X^* Y^*)$$

💡 定理 4.5：相关系数的两大核心定理（柯西-施瓦茨不等式推论）
  1. 有界性：$|\rho_{XY}| \le 1$，即 $$-1 \le \rho_{XY} \le 1$$
  2. 线性相关判定定理：$|\rho_{XY}| = 1$ 的充分必要条件是：存在常数 $a \ne 0$ 和 $b$，使得 $$P(Y = aX + b) = 1$$ 即 $X$ 与 $Y$ 之间几乎处处存在严格的线性关系：
    • 当 $\rho_{XY} = 1$ 时，为严格正相关（$a > 0$）；
    • 当 $\rho_{XY} = -1$ 时，为严格负相关（$a < 0$）.

三、不相关与相互独立的辩证关系

📘 核心考点辨析：不相关 vs 相互独立

当 $\rho_{XY} = 0$（即 $\mathrm{Cov}(X, Y) = 0$ 或 $E(XY) = E(X)E(Y)$）时，称 $X$ 与 $Y$ 不相关.

1. 概念层级不同：

  • “独立”是一个强概念，它要求任意函数均无关系（$P(AB)=P(A)P(B)$，包含线性与一切非线性关系）；
  • “不相关”是一个较弱的概念，它仅仅说明两者之间不存在线性关系，但可能存在非常强烈的非线性函数关系（如圆周方程 $X^2 + Y^2 = 1$）！

2. 逻辑推导链条： $$X, Y \text{ 相互独立} \implies X, Y \text{ 不相关} (\rho = 0)$$ 但反之不成立：$$X, Y \text{ 不相关} \;\; \not\!\!\!\implies X, Y \text{ 相互独立}$$

3. 唯一特例：如果 $(X, Y)$ 服从二维正态分布，则独立与不相关完全等价！

第四节 其他数字特征

一、矩的概念

📌 定义 4.7：原点矩与中心矩

设 $X$ 和 $Y$ 为随机变量，$k, l$ 为正整数：

  • $k$ 阶原点矩：$\alpha_k = E(X^k)$（特别地，一阶原点矩就是数学期望 $\alpha_1 = E(X)$）；
  • $k$ 阶中心矩：$\mu_k = E\{[X - E(X)]^k\}$（特别地，一阶中心矩恒为 0，二阶中心矩就是方差 $\mu_2 = D(X)$）；
  • $k+l$ 阶混合原点矩：$\alpha_{k+l} = E(X^k Y^l)$；
  • $k+l$ 阶混合中心矩：$\mu_{k+l} = E\{[X - E(X)]^k [Y - E(Y)]^l\}$（特别地，$\mu_{1+1} = \mathrm{Cov}(X, Y)$ 即为协方差）.

二、分位数与中位数

📌 定义 4.8：分位数（Quantile）与中位数（Median）

设连续型随机变量 $X$ 的分布函数为 $F(x)$，对于给定的概率值 $\alpha \in (0, 1)$：

  • 满足 $F(x_\alpha) = P(X \le x_\alpha) = \alpha$ 的实数 $x_\alpha$ 称为 $X$ 的 $\alpha$ 分位数（下侧分位数）；
  • 满足 $P(X > z_\alpha) = 1 - F(z_\alpha) = \alpha$ 的实数 $z_\alpha$ 称为 $X$ 的上侧 $\alpha$ 分位数（数理统计常用）；
  • 当 $\alpha = 0.5$ 时的分位数 $m = x_{0.5}$ 满足 $P(X \le m) = P(X \ge m) = 0.5$，称为随机变量 $X$ 的中位数.
